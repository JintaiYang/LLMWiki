# 商业模式

> 「采购—酿造—贮存—勾兑—销售」，五年出酒，长周期锁定稀缺。

## 经营闭环 [S2025AR, p.8]

```
采购原料 → 制曲 → 制酒 → 贮存 → 勾兑 → 包装 → 销售
```

- 原料：高粱（"公司+地方政府+供应商+合作社或农户"）、小麦（"公司+供应商+合作社或农场"）、包装材料集中采购。
- 生产周期：至少五年。茅台酒从生产到出厂至少五年；每年需留存基酒。 [S2025AR, p.16]
- 销售渠道：直销（自营店 + i茅台）+ 批发代理（经销商 + 商超 + 电商）。 [S2025AR, p.8]

## 关键特征

- **极高毛利率**：茅台酒93.53%，系列酒76.11%。 [S2025AR, p.10]
- **双渠道并行**：2025年直销收入845.43亿 vs 批发代理842.32亿，收入占比约50:50；直销毛利率94.58%显著高于批发代理87.86%。 [S2025AR, p.10]
- **i茅台**：2025年销售收入130.31亿，同比-34.92%，毛利率94.47%。 [S2025AR, p.17]
- **系列酒承压**：收入-9.76%，毛利率降3.76pp至76.11%。 [S2025AR, p.10]
- **产能释放滞后**：新增基酒产能于当年10-12月投产，次年释放。2025年茅台酒基酒实际产能58,473.16吨，同比+3.91%。 [S2025AR, p.15]
