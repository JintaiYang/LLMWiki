# 风险与证伪

> 每项风险按**概率×影响**分级，并与核心命题的证伪条件挂钩。

### R1：飞天批价持续下行

| 维度 | 分析 |
|---|---|
| 风险描述 | 飞天茅台批价跌破2,000元并持续低迷，反映供需失衡 |
| 概率 | 中（20-30%） |
| 影响 | 极高——直接证伪[[命题一 品牌与定价权]] |

| 早期信号 | 批价跌破2,200元；经销商库存积压；黄牛出货加速 |
| 证伪关联 | → [[命题一 品牌与定价权]]证伪条件1 |
| 数据来源 | ⚠️尚未建立批价数据源 |
