# 核心投资命题

> 投资茅台的多头逻辑建立在三条命题之上，每条命题独立可证伪。

## 各命题概要

### 命题一：品牌与定价权 [T1]

**主张**：茅台品牌护城河支撑持续定价权，即使行业调整也能维持高毛利

- 核心验证：飞天批价≥2,000元、茅台酒毛利率≥93%
- 当前状态：毛利率达标✅，但批发吨价下降❌
- 证伪条件：批价<1,800元持续3个月 / 毛利率连续两年<92%
- → [[命题一 品牌与定价权]]

### 命题二：渠道重构 [T2]

**主张**：直销占比提升释放被经销商截取的价值，长期提升综合毛利率

- 核心验证：直销占比持续提升至55%+、综合毛利率≥91%
- 当前状态：直销占比50.09%✅，但i茅台-35%❌
- 证伪条件：直销占比连续两年下降 / 经销商大面积退网
- → [[命题二 渠道重构]]

### 命题三：增长中枢 [T3]

**主张**：长期收入CAGR 5-8%，由产能释放+渠道优化驱动

- 核心验证：茅台酒销量增速≥2%、系列酒收入恢复正增长
- 当前状态：销量+0.73%❌、系列酒-9.76%❌
- 证伪条件：销量连续两年零增长 / 收入CAGR连续3年<3%
- → [[命题三 增长中枢]]

## 命题依赖关系

```
命题一（定价权）── 必要条件 ──→ 命题三（增长中枢）
```
