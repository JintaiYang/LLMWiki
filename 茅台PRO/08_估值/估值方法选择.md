# 估值方法选择

## 为什么选择DCF而非PE？

| 方法 | 优势 | 劣势 | 适用性 |
|---|---|---|---|
| DCF（自由现金流折现） | 反映现金流本质；可拆分假设 | 敏感于终值假设 | ✅首选——茅台FCF可预测性高 |
| PE相对估值 | 简单可比 | 受利润波动和资本结构影响 | ⚠️辅助——用于交叉验证 |
| 股息率法 | 直观反映回报 | 假设分红比率稳定 | ⚠️辅助——茅台分红率有明确指引 |
| EV/EBITDA | 剔除资本结构影响 | 茅台零负债，意义不大 | ❌不适用 |

## 估值框架

### 核心模型：两阶段DCF

```
企业价值 = Σ FCF_t/(1+WACC)^t + 终值/(1+WACC)^10

其中：
FCF = 扣除财务公司影响后的经营现金流 - 维持性资本开支
WACC = 茅台零有息负债 → WACC ≈ 股权成本 = Rf + β×ERP
终值 = FCF_10 × (1+g) / (WACC - g)
```

### 关键假设与来源

| 假设 | 基准值 | 来源/依据 |
|---|---|---|
| 无风险利率 | ~2.5% | 中国10年期国债 |
| β | ~0.7 | 消费品低beta特征 |
| 股权风险溢价 | ~5% | 新兴市场ERP |
| WACC | ~6.0% | 计算 |
| 永续增长率g | 3.0% | 介于名义GDP和行业增速之间 |
| 预测期 | 10年 | 覆盖产能释放周期 |

### 辅助验证

1. **PE交叉验证**：基于归母净利润和合理PE倍数（20-30x）
2. **股息率验证**：75%分红率下，当前股息率与历史分位比较
3. **反向DCF**：当前股价隐含的增长率是多少？→ [[反向估值]]
