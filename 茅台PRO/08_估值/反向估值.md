# 反向估值

> **核心思路**：不从假设推导价值，而是从当前市场定价反推隐含假设，判断市场预期是否合理。

## 方法

```
当前股价 → 隐含FCF路径 → 隐含收入CAGR → 对照命题验证

若隐含CAGR < 基准情景CAGR → 市场过度悲观 → 潜在机会
若隐含CAGR > 乐观情景CAGR → 市场过度乐观 → 潜在风险
```

## 隐含增长率推算模板

假设当前股价为P：

| 股价假设 | 隐含永续FCF(亿) | 隐含收入CAGR | 对标情景 |
|---|---|---|---|
| 1,500元 | ~1,050 | ~8% | 乐观 |
| 1,200元 | ~840 | ~6% | 基准偏上 |
| 1,000元 | ~700 | ~4% | 基准偏下 |
| 800元 | ~560 | ~2% | 悲观 |

> WACC=6%, g=3%, 以上为粗估。精确计算需获取实时数据后进行。

## 与命题的交叉验证

- 若市场隐含CAGR ~6%：与[[命题三 增长中枢]]基准情景一致，市场定价合理
- 若市场隐含CAGR <4%：市场定价已反映[[命题一 品牌与定价权]]部分证伪
- 若市场隐含CAGR >8%：市场定价需要乐观情景兑现
