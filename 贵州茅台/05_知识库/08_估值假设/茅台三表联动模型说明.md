# 茅台三表联动模型说明

> 模型文件：[[茅台三表联动模型_2025A.xlsx]]（`08_估值假设/茅台三表联动模型_2025A.xlsx`）
> 规范：china-3-statement-model 技能（CAS 中国会计准则适配）

## 一、模型结构

| 工作表 | 内容 |
|---|---|
| 假设与情景 | 市场与股本、2025A 锚定比率、三情景驱动参数。**B=悲观 C=中性 D=乐观 E=备注**（黄底蓝字=可修改输入） |
| 利润表 | 2023A-2025A 历史 + 2026E-2030E × 三情景（悲观 E-I / 中性 J-N / 乐观 O-S） |
| 资产负债表 | 同上，期末值口径 |
| 现金流量表 | 间接法简化，历史含倒挤调节项 |
| 情景对比 | 三情景关键结果并排（营收/净利/EPS/DPS/OCF/FCF/ROE/隐含PE/PB） |
| 检查 | 资产负债平衡、CF-IS 联动、现金勾稽、税率区间 |
| 数据底稿 | 2021A-2026H1 原始数据与口径说明 |

单位统一为**亿元**（2 位小数），每股指标为元。

## 二、联动机制（改任何假设自动传导）

1. **利润表 → 现金流量表**：净利润为间接法起点
2. **现金流量表 → 资产负债表**：期末现金池 = BS 现金类资产
3. **资产负债表 → 利润表**：财务费用 = −期初现金池 × 利息净收益率（茅台无有息负债，利息净收益为收入项；营业利润中"−财务费用"对负数费用即加回，已用 2025A 报表恒等式精确验证）
4. **RE 滚动**：期末未分配利润 = 期初 + 归母净利 − 分红 − 回购 − 盈余公积提取
5. **固定资产滚动**：原值 += CapEx；累计折旧 += 折旧率×期初原值 + 摊销
6. **情景边界规则**：每个情景区第一年（2026E）的基数固定为 **D 列（2025A 实际值）**，此后用左邻列——防止跨情景误用上一情景区末年做基数
7. **循环引用说明**：IS 财务费用用**期初**（上期末）现金池计算，避免 Excel 循环引用，属标准简化处理

## 三、口径说明（重要）

1. **现金类资产池** = 货币资金 + 拆出资金 + 买入返售 + 一年内到期非流动资产 + 债权投资 + 其他债权投资。宽于报表"现金及现金等价物"（差约 200-400 亿，含存放央行款项、受限资金），因为茅台合并了财务公司，其金融资产同样产生利息收益。
2. **利息净收益率 0.45%**：2025 年利息净收益 8.15 亿 / 平均现金池。
3. **盈余公积提取率 4.75%**：法定 10% × 母公司报表净利（约为归母净利的 47.5%）。
4. **资产分项残差**：2023/2024 年分别有 5.4/23.2 亿科目缺失（新浪接口 2024 年未单列应收款项融资），已并入"其他资产"并在检查页标注。
5. **历史 CF"其他调整"行**：新浪接口不提供间接法补充资料明细，用报表实际 OCF 倒挤，预测年为 0。
6. **利润表恒等式**（2025A 验证，残差 1.73 亿为倒挤小项）：营业利润 = 营业总收入 − 营业成本 − 税金及附加 − 销售费用 − 管理费用 − 研发费用 − 财务费用 + 其他收益类。利息收入 32.16 亿计入营业总收入（财务公司收入），与财务费用科目不重复。

## 五、三情景预测结果（已通过独立公式求值器 100% 数值验证）

| 情景 | 2026E 归母(亿) | 2030E 归母(亿) | 2026E 现金池(亿) | 2030E 现金池(亿) | 2030E 归母权益(亿) |
|---|---:|---:|---:|---:|---:|
| 悲观 | 797.7 | 823.5 | 2,101 | 2,903 | 3,457 |
| 中性 | 845.8 | 1,004.7 | 2,044 | 2,621 | 3,266 |
| 乐观 | 870.2 | 1,142.9 | 2,020 | 2,481 | 3,205 |

> 假设：营收增速悲观 -2%→+1%、中性 +2%→+5%、乐观 +4%→+8%；分红率 75%/78%/80%；回购 0/40/50 亿；CapEx 30/40/50 亿。悲观情景现金池反而积累最多（分红回购支出少），ROE 由 33% 降至约 24%——茅台的"现金堰塞湖"特征在低增长情景下更突出。

## 六、质检方法与结果

模型经过**三层验证**（区别于仅比对公式字符串）：
1. **语义校验**：解析每个公式的引用指向，确认假设表行列映射正确（B/C/D 参数列、E 列备注文字绝不进入公式）
2. **独立公式求值器**：自写 Excel 公式解释器（分词→递归下降求值→跨表引用解析），对 1,246 个公式**真实计算**，与 Python 独立复算基准逐格对照（三情景 × 5 年 × 5 关键科目 = 75 个检查点）
3. **报表恒等式验证**：利润表/资产负债表用 2025A 实际数据锚定，残差归零

最终结果：**求值错误 0、文本算术 0、数值对照 75/75 通过**。

## 七、与 DCF 模型的关系

- 三表模型给出 FCF 路径（OCF−CapEx），可作为 [[茅台估值假设]] DCF 的 FCF 基期来源：中性 2026E 简化 FCF ≈ 995 亿（OCF 1,035 − CapEx 40），vs DCF 模型当前用的 804 亿（净利×98%）。差异主要来自 DCF 口径扣除了净再投资，而简化 FCF 受财务公司营运资本波动影响；两者证据等级相同，方向一致。
- 三表模型是**经营口径**，DCF 是**估值口径**；前者驱动后者的 FCF 与 BVPS 假设。
