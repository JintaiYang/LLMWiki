# 运营效率

## 一句话判断

茅台总资产周转率从 0.34 升至 0.56（平均口径），资产利用效率有所改善；存货周转天数超长（约 1200-1500 天）系白酒生产工艺特征（基酒窖藏 3-5 年），并非效率问题；现金循环周期为大正数，不可声称为负。

## 事实

### 总资产周转率

> 总资产周转率 = 营业收入 / 平均总资产，采用期初期末平均口径，2016 因缺少 2015 期末数使用期末余额。

| 2023年报 | 0.56 | 1476.94 | 2636.01 |
| 2022年报 | 0.49 | 1241.00 | 2548.35 |
| 2021年报 | 0.45 | 1061.90 | 2342.82 |
| 2020年报 | 0.48 | 949.15 | 1982.19 |

### 周转天数（期末余额简化口径）

> 以下周转天数采用期末余额简化计算（非平均余额），用于趋势观察。存货周转天数 = 存货 / 营业成本 × 365；应收账款周转天数 = 应收账款 / 营业收入 × 365；应付账款周转天数 = 应付账款 / 营业成本 × 365。应收账款为 null 的年份按 ~0 处理。

|--------|------------|---------------|---------------|----------------|

| 2024年报 | 1438 | 0 | 93 | 1345 |
| 2023年报 | 1429 | 0 | 95 | 1334 |

> 数据来源：`maotai_analysis.json`（基于公司年报资产负债表期末余额计算）。2016 年存货周转天数异常高（2208 天）系当年营业成本仅 34.10 亿（基数低），不代表效率恶化。

### 重要口径说明

1. **存货周转天数超长是白酒生产工艺特征**：茅台酒基酒需窖藏 3-5 年方可勾兑灌装出厂，存货中包含大量在产品（基酒）和产成品（老酒），周转天数 1200-1500 天属行业正常水平，**不可将其与普通消费品企业简单对比并视为效率低下**。
2. **公司含财务公司业务**：茅台集团财务有限公司的资产负债表并入合并报表，货币资金中包含同业存放款项，部分不可随时支取。这使得营运资金分析比纯白酒企业更复杂。
3. **现金循环周期为大正数**：传统 CCC = 应收周转天数 + 存货周转天数 − 应付周转天数，计算结果在 1168-2097 天之间，全部为大正数。**不可声称现金循环周期为负**——虽然茅台有大量合同负债（预收款）提供浮存金，但传统 CCC 公式不包含合同负债科目。若将合同负债视为"负营运资金"则另当别论，但此处遵循标准定义。

## 推断（证据等级：中）

1. **总资产周转率改善**：从 2016 年的 0.34 升至 2024 年的 0.60，说明营收增速快于资产扩张，资产利用效率提升。2025 年回落至 0.56，与营收下降（-1.21%）而总资产继续增长有关。
2. **应收账款周转天数接近零**：茅台采用"先款后货"模式（经销商预付款），应收账款极小（2025 年仅 0.03 亿），周转天数约 0 天，体现极强的渠道话语权。
3. **存货周转天数呈下降趋势**：从 2016 年的 2208 天降至 2020 年的 1293 天，随后稳定在 1300-1500 天，反映营收增长快于存货积累，产能利用率提升。
4. **应付账款周转天数稳定**：在 60-111 天之间，2025 年为 98 天，说明对供应商的付款周期相对稳定。
5. **现金循环周期为正且较长**：主要由存货长周期驱动，这是白酒行业的结构性特征而非管理层可调控的效率指标。
