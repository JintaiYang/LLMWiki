# 白酒行业术语表

> [!abstract] 一句话判断
> 白酒行业术语体系庞杂，涵盖香型工艺、渠道定价、消费场景和财务指标四大维度，其中"12987工艺"与"坤沙/碎沙/翻沙/窜香"四级分类决定酱香品质与溢价逻辑，而"大商制/代销制/价格倒挂/五码合一"等则是理解当前渠道变革的钥匙。

## 事实

### 一、核心工艺术语

#### 12987工艺

茅台镇特有的大曲酱香型白酒酿造工艺，为国家级非物质文化遗产。数字"12987"是对全年生产节奏的高度概括：

- **"1" = 1年生产周期**：从端午制曲开始，到次年重阳完成最后一次取酒，整个大周期跨度约一年。
- **"2" = 两次投粮**：重阳下沙（首次投料，占约50%）+ 糙沙（二次投料，占约50%），此后全年不再投粮，仅循环蒸煮发酵。
- **"9" = 九次蒸煮**：头两次蒸煮只为增加发酵时间、不取酒，从第三次蒸煮才开始取酒。
- **"8" = 八次发酵**：每次蒸煮后入石砌窖坑发酵，单次窖期约一个月。
- **"7" = 七次取酒**：从第三次蒸煮开始，共取七个轮次，各轮次风味不同（前期酱香突出、中期醇厚、后期焦糊香）。

关键工艺节点：

- **端午制曲**：以小麦为原料，经踩曲→装仓→翻仓，历时3-5个月，端午时节高温高湿利于微生物富集。
- **重阳下沙**："沙"即红缨子糯高粱，粒小、皮厚、淀粉含量高，能禁得起多次蒸煮而不烂。
- **窖藏**：基酒需窖藏3年以上方可勾调上市。
- **工艺复杂度**：全程共165个操作环节。
- **"四高两长"**：高温制曲、高温堆积、高温馏酒、高温发酵；生产周期长、储存时间长。
- **出酒率**：约5斤粮食出1斤酒，粮耗高是酱香成本高企的根本原因。

### 二、酱香四级分类术语

#### 坤沙酒

- 又名浑沙酒 / 浑籽酒，属传统酱香型白酒中的最高等级。
- 高粱破碎率 ≤ 20%（近乎整粒投料），严格遵循12987工艺全流程。
- 基酒窖藏3年以上。
- 出酒率低（5斤粮出1斤酒），但品质最好。
- 按风味可分为**酱香、窖底香、醇甜**三种典型体，勾调时按比例组合。
- 来源：https://baike.baidu.com/item/%E5%9D%A4%E6%B2%99%E9%85%92/15660478

#### 碎沙酒

- 用磨碎的高粱酿造，生产周期短、出酒率高、价格便宜。
- 品质低于坤沙，香气与层次感不足。

#### 翻沙酒

- 用9次蒸煮后本应丢弃的酒糟，再加入新高粱和新曲药酿造。
- 品质更低，常作为低价酱酒的原料。

#### 窜香酒

- 酱香型中品质**最低**的类别。
- 用坤沙酒最后蒸煮的废弃酒糟 + 食用酒精蒸馏而成，严格意义上不属于纯粮固态酒。

> 四级品质排序：坤沙 > 碎沙 > 翻沙 > 窜香。

### 三、渠道与商业模式术语

#### 大商制

- 以 [[五粮液]] 为代表的渠道模式，依赖少数核心大经销商覆盖区域市场。
- 厂商授权经销商全权负责仓储、资金垫付及终端网络建设。
- 历史背景：1985—2003年五粮液经历三轮扩产，需要快速消化产能，遂借助大商快速铺货。
- "总代 + OEM贴牌"模式催生了金六福、浏阳河等子品牌。
- 弊端：子品牌过多稀释主品牌价值、经销商压货甩货导致价格倒挂、厂家渠道失控。

#### 代销制

- [[茅台]] 于2026年对非标产品推行的新渠道模式。
- 货权归属茅台（而非经销商买断），经销商仅缴纳保证金。
- 茅台按销售额收取5%固定佣金。
- 用以取代传统的买断式经销，强化厂家对货权和终端价格的掌控。

#### 四师一官

- 茅台的经销商认证体系。
- 包含文化宣讲师、品鉴师、品饮师等专业角色 + "官员"。
- 目的在于筛选出服务能力强、专业度高的渠道商。

#### i茅台

- 茅台官方直销 APP，2022年上线。
- 常态化销售飞天茅台，价格1499元/瓶。
- 2026年Q1新增用户约1400万。
- 推动茅台直销占比从13.5%升至46.8%，是渠道变革的标志性平台。

#### 五码合一

- [[汾酒]] 引入的数字化溯源系统。
- 将盒码、箱码、瓶码、追溯码、物流码五码合一。
- 帮助降低窜货率超50%，是数字化治理渠道的样板。

### 四、定价与消费术语

#### 价格倒挂

- 指批发价 / 市场价低于出厂价或指导价，经销商亏损出货。
- 2025年约60%的白酒企业存在此现象。
- 典型案例：飞天茅台批价1485元 < 1499元指导价。
- 是行业景气度下行、渠道库存高企的核心信号。

#### 光瓶酒 / 高线光瓶

- **光瓶酒**：不带纸盒外包装、直接可见瓶身的酒，主打价格亲民、渠道便利、高频消费。
- **高线光瓶**：聚焦50—100元价格带，增速超40%。
- 2024年光瓶酒市场规模超1500亿元，是行业为数不多的高增长赛道。

## 推断

- **工艺决定成本，成本决定溢价**：12987工艺的165个环节、5斤粮出1斤酒、3年窖藏共同构成酱香的高成本护城河，也解释了坤沙酒的高定价合理性。
- **四级分类是消费者避坑的核心知识**：坤沙与窜香在成本和品质上差异巨大，但外包装难以分辨，这是酱酒市场信息不对称的根源。
- **渠道术语正在集体"从大商制转向厂家直控"**：代销制、i茅台、五码合一、四师一官本质上都是厂家收回货权、压缩窜货空间、掌控终端价格的手段，是应对价格倒挂的系统性反应。
- **价格倒挂 + 60%企业占比** 说明当前行业处于去库存周期的底部区间，渠道博弈激烈。
