# 白酒行业关键概念

## 一句话判断

理解白酒行业需要在术语之上掌握一层"战略与市场概念"：格局重构（茅五汾）、量价背离（量减价升）、香型迁移（香型重构）、渠道变革（大商制转直销）、政策约束（禁酒令 + 消费税后移）共同定义了本轮周期的主线。

## 事实 / 概念清单

### 工艺与品质分类（详见术语表）

1. **12987工艺** — 酱香型白酒标志性工艺（1年周期、2次投粮、9次蒸煮、8次发酵、7次取酒），理解它就理解了酱香的成本与溢价逻辑。详解见 [[白酒行业 glossary]]。关联：[[茅台]]
2. **坤沙 / 碎沙 / 翻沙 / 窜香四级分类** — 酱香酒按工艺与原料的品质分级，坤沙最优、窜香最差，是消费者避坑与理解定价的核心知识。详解见 [[白酒行业 glossary]]。

### 格局与量价

3. **"茅五汾"新三强格局** — 替代过去的"茅五洋"（茅台、五粮液、洋河），汾酒凭清香复兴跻身头部三强。关联：[[白酒行业 player map]]、[[汾酒]]
4. **量减价升** — 行业进入产量腰斩但收入逆增的阶段，头部企业以结构升级和提价对冲销量下滑，是本轮周期的核心特征。关联：[[白酒行业 tracker]]
5. **香型重构** — 香型份额剧烈迁移：浓香由约52%降至约33%，酱香出现负增长，清香增速约+20%。反映消费偏好与产区红利的再分配。关联：[[汾酒]]、[[茅台]]

### 渠道变革

6. **大商制 vs 直销变革** — 以五粮液为代表的传统大商制正被厂家直控（直销、电商、代销制）瓦解，核心动因是收回货权、稳定终端价。关联：[[白酒行业 value chain map]]
7. **五码合一** — 汾酒的数字化溯源系统（盒码/箱码/瓶码/追溯码/物流码），降窜货率超50%，是渠道数字化治理样板。关联：[[汾酒]]
8. **i茅台** — 茅台官方直销平台，2022年上线，推动直销占比从13.5%升至46.8%，代表酒企渠道变革方向。关联：[[茅台]]
9. **代销制** — 茅台2026年对非标产品推行的新模式，货权归茅台、按销售额收5%固定佣金，取代买断式经销。关联：[[茅台]]
10. **四师一官** — 茅台经销商认证体系（文化宣讲师、品鉴师、品饮师等 + 官员），筛选服务能力强的渠道商。关联：[[茅台]]

### 定价与赛道

11. **价格倒挂** — 批价/市场价低于出厂价或指导价，2025年约60%企业存在此现象（如飞天茅台批价1485元 < 1499元指导价），是行业景气度下行的核心信号。关联：[[价格不透明]]
12. **光瓶酒 / 高线光瓶** — 无礼盒包装、主打性价比的赛道，2024年规模超1500亿；高线光瓶（50—100元）增速超40%，是行业稀缺的高增长方向。关联：[[白酒行业机会表]]

### 政策约束

13. **消费税后移** — 消费税征收环节由生产端后移至零售端，将重塑价值链的利润分配格局。关联：[[白酒行业 risk map]]
14. **60%孰高规则** — 消费税反避税的核心条款：当白酒销售单位对外售价低于生产企业出厂价70%（口径以"孰高"计税）时，按更高价核定计税价格，用以防止通过关联交易低报出厂价避税。关联：[[白酒行业 risk map]]
15. **禁酒令** — 2025年5月出台，政务消费场景持续缩圈，直接冲击高端商务/政务用酒需求。关联：[[白酒行业 risk map]]

### 消费与资本理念

16. **"三理性"** — 消费者呈现饮酒量理性、价格选择理性、风格偏好理性三重回归，高端炫耀性消费退潮。关联：[[白酒行业机会表]]
17. **去金融化** — 茅台主动削减具投资属性的产品（如生肖酒等），弱化白酒的金融炒作属性，引导价值回归饮用与社交本源。关联：[[茅台]]

## 推断

- **主线是"格局集中 + 量价背离 + 渠道直控"三条线交织**：茅五汾集中度提升（概念3）、量减价升（4）与厂家收回货权（6—10）本质上都是行业出清期头部企业的自保与扩张动作。
- **政策类概念（13、14、15）虽少但影响面最大**：禁酒令冲击需求端，消费税后移与60%孰高规则冲击利润分配端，应作为风险跟踪重点。
- **香型重构（5）与光瓶酒（12）是结构性机会**：清香复兴 + 高线光瓶高增速，指向"性价比 + 低度化 + 大众消费"的新增长极，与"三理性"（16）相互印证。
- **去金融化（17）与价格倒挂（11）互为因果**：削减投资属性产品是对金融泡沫破裂、批价倒挂的主动纠偏。
