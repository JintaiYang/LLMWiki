# 白酒行业 value chain map

## 一句话判断

白酒价值链的核心利润集中在"窖藏"和"品牌"两个环节，酒厂通过控制稀缺陈年基酒和品牌溢价拿走大部分毛利；下游渠道正从传统多级分销向"直销+私域+即时零售"重构，头部酒厂主动向下游延伸抢利润，同时光瓶酒赛道从底部快速扩容。

## 事实

### 上游（原料）

高粱、小麦、大米、玉米等农产品供应商，成本占比约5-10%（口径待核实，不同价格带差异大）。

### 中游（生产）

- 制曲：大曲/小曲/麸曲 → 决定香型（酱香、浓香、清香等）
- 发酵：固态/液态/半固态 → 决定品质等级
- 蒸馏 → 得到基酒
- 储存/窖藏：普通产品1-5年，高端产品10-30年 → 行业公认的核心溢价环节
- 勾兑/调配 → 形成最终成品酒
- 灌装/包装：灌装线 → 包装设计 → 防伪技术，是品牌区隔与反假货的重要环节

### 下游（流通渠道，2024年结构）

- 传统经销商约55%：仍是主导渠道，但增长转向团购精细化（如洋河"天网工程"），依赖多级分销（大商/省代/市代/终端商）
- 电商直营约25%：以 i茅台 APP 为代表，会员体系+私域流量
- 连锁便利店约12%：如711定制光瓶酒等即时消费场景
- 直播电商约8%：抖音"白酒节"单日GMV破10亿
（来源：[雪球-白酒经销模式拆解](https://xueqiu.com/8580018030/325433784)）

### 终端（消费场景）

商务宴请 → 送礼 → 自饮 → 婚宴 → 收藏投资，五类场景对价格敏感度和品牌要求不同。

### 案例一：茅台直销渠道改革

- 直销占比从2020年13.5%升至2025年46.8%；2025年直销收入845.43亿元（+12.96%），首次超过批发渠道
- i茅台常态化投放飞天1499元，2026年Q1新增1400万用户、398万人购酒
- 2026年拟取消分销制，非标产品改为代销制（约5%佣金），经销商单瓶毛利从330元降至270元
- 建立"四师一官"认证体系（文化宣讲师、品鉴师等）
- 目标2026年直销占比超60%
（来源：[搜狐-茅台渠道变革](https://www.sohu.com/a/973363509_121431671)、[新浪-茅台渠道改革重塑供应链](https://news.sina.cn/bignews/insight/2026-03-31/detail-inhsvshk2233758.d.html)）

### 案例二：五粮液大商制

- 1985-2003年三轮扩产，产能从4000吨扩至40万吨
- "总代+OEM贴牌"模式，诞生金六福、浏阳河等子品牌
- 弊端：上千子品牌稀释主品牌；大商压货甩货造成价格倒挂
- 2024年经销商总量突破3700家，净增327家

### 案例三：光瓶酒赛道

- 2024年市场规模超1500亿元，2025年预计达2000亿元
- 2013-2024年复合增长率约13.8%，远超行业均值4.14%
- 占白酒市场17%+（2013年仅6.38%）
- 50-100元"高线光瓶"增速超40%
- 代表产品：玻汾（年销约2亿瓶/80亿+）、绿脖西凤（20亿+）
- 2025年新品：洋河大曲59元、泸州老窖二曲65元、古井贡老瓷贡45元
（来源：[搜狐-光瓶酒行业报告](https://www.sohu.com/a/920930239_730526)、[腾讯-光瓶酒市场规模](https://news.qq.com/rain/a/20250811A01KEF00)）

## 推断

- 酒厂毛利率可达80%以上（参见 [[茅台]] 约91.6%、[[五粮液]] 约77.5%），定价权高度集中在生产端而非渠道端，与多数消费品"渠道为王"格局相反（证据等级：high）
- 茅台直销占比逼近50%、并推进非标代销制与经销商毛利下调，本质是酒厂向下游延伸抢利润，长期压缩传统经销商生存空间；五粮液大商制的价格倒挂问题正是渠道扁平化改革的反面参照（证据等级：high）
- 光瓶酒以13.8%复合增速与50-100元高线段40%+增速扩容，指向大众自饮需求与消费理性化，是头部酒厂对冲高端去库存压力的第二增长曲线（证据等级：medium）
- 直播电商单日破10亿但整体仅约8%占比，说明新渠道爆发力强但尚未改变以经销商为主的存量结构，渠道重构仍处早期（证据等级：medium）
