# 白酒行业 complete research framework

## 一句话判断

白酒行业研究应覆盖需求、结构、价值链、玩家、客户、痛点、术语、商业模式、财务、监管、机会、风险、跟踪 13 个模块，任何单一模块的结论都不足以支撑投资或战略判断。

## 事实

以下 13 个模块的具体问题和要点为综合整理，部分数据点需要在各自专题页面标注独立来源和证据等级。

| 模块 | 白酒行业具体问题 |
|------|------------------|
| 需求/场景 | 谁在喝白酒？商务宴请、送礼、自饮、婚宴、收藏投资分别占多大比例？ |
| 系统架构 | 从粮食到消费者的完整链路：原料→酿造→窖藏→灌装→经销→终端 |
| 价值链 | 利润分配：酒厂毛利80%+、经销商利润来自返利、终端加价空间有限 |
| 玩家 | 茅五汾泸洋+郎剑水舍今，各自定位和竞争策略 |
| 客户 | 35-55岁男性为主、公务/商务场景、节日礼赠、年轻人渗透率仅11% |

| 机会 | 清香崛起、光瓶酒赛道、低度化、即时零售、去库存周期尾声 |
| 风险/证伪 | 代际断层加速、消费税落地冲击、持续去库存 |
| 跟踪器 | 批价周度跟踪、季报业绩、渠道库存、政策动态 |

## 推断

- 白酒行业是一个"高毛利、强渠道控制力、弱营销投入"的特殊消费品行业，其商业模式与一般快消品差异较大，套用通用消费品分析框架容易漏掉渠道库存和批价倒挂这类关键变量
- 年轻人渗透率低（约11%，待验证具体来源）与代际断层风险高度相关，是当前行业最大的长期不确定性，短期财务数据可能掩盖这一趋势
- 消费税后移是政策面最大的潜在变量，一旦落地会直接压缩经销商和终端环节的利润空间，需要持续跟踪
