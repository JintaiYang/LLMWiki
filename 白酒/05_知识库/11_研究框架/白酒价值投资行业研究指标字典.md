# 白酒价值投资行业研究指标字典

## 一句话判断

白酒研究先辨别消费者有没有持续购买，再看成交价格和渠道资金能否支撑补库，最后用厂商量价、财报与长期资本回报验证。酒厂收入和存货不是终端动销和渠道库存的替代品。

方法核对日为2026-10-17；看板财报仍使用已核验的2026-10-10截止快照。两种时点不同，不把调研日当作财报/行情更新日。沿用现有V5公司评分，不用本次行业信号修改公司总分或推荐买卖。

## 原始材料已经确认的事实

1. [伯克希尔2007年股东信](https://www.berkshirehathaway.com/letters/2007ltr.pdf)，PDF第5–7页（正文第6–8页）：长期经济特征、资本需求与竞争优势是生意质量研究的基础。本指标体系为研究归纳，不是股东信的官方公式。
2. [中国酒业协会2026-06-19原文](https://www.cada.cc/Item/1555.aspx)记载中期研究报告发布，关注消费场景、性价比及产品分层。该网页是发布报道，不能从中推导当前库存月数、价格倒挂占比或动销增速。
3. [国家统计局2025-01-17统计范围说明](https://www.stats.gov.cn/sj/zxfb/202501/t20250117_1958332.html)，附注（3）（5）：规上工业和限额以上零售有各自范围，企业范围变化影响同比可比口径；不是全行业消费统计。
4. [贵州茅台2024年报](../../../贵州茅台/02_原始资料/财报/贵州茅台_2024年年度报告.pdf)是本地核对的公司原文：PDF第9页讨论财务公司对现金流的影响，第9–13页列产品/渠道、产销与基酒周期，第93页拆分存货。不能把该公司工艺周期推广成所有香型的统一年数。

2025年中期研究报告的库存天数、价格倒挂比例在多个媒体转载中出现，但本次未取得报告全文及调查分母；不把转载数量当独立交叉验证，不把历史报道写成2026年的现状。原文核验与二手线索应分开。

## 必须区分的三组口径

| 口径 | 能回答什么 | 不能回答什么 |
|---|---|---|
| 规上白酒产量、行业协会样本 | 生产供给、调查样本的行为变化 | 全行业实际饮用量、上市公司的收入 |
| 19家上市公司合并财报 | 厂商收入、利润、现金和资产负债表 | 全国白酒总量、经销商库存、消费者开瓶量 |
| 固定渠道/门店/单品调研 | 净成交价、实际售出、库存月数、补货 | 未抽样地区或品牌的总体结论 |

当前19家样本包含顺鑫农业非酒业务，不含郎酒、剑南春等未上市企业。样本份额必须写“上市样本占比”，不能写“全行业集中度”。

## 12项外部跟踪指标

| 层次 | 指标及频率 | 计算/采集口径 | 研究用途与误读边界 |
|---|---|---|---|
| 需求 | 同店终端动销；月/节日 | 同店同单品实际售出量，同比对齐农历节前节后窗口 | 最接近实际购买；品牌发货、扫码、开瓶和复购要分别记录，不能相互冒充 |
| 需求 | 场景、主销价格带；季度 | 宴席/商务/自饮，销量、客单价、复购及新客 | 验证需求可持续性；问卷购买意愿不等于成交 |
| 价格 | 核心单品批价；周 | 固定规格/度数/年份/箱瓶形态，记录含税成交价和来源 | 连续观察4周；控货提价也可能发生在需求下降时，不能单看一日反弹 |
| 价格 | 经销商实际毛利和倒挂；月 | （净到手售价－同含税进货成本）/进货成本；再看运费资金费 | 区分名义出厂价、已兑现返利和零售指导价；实际亏损可能损害补货意愿 |
| 渠道 | 库存月数；月/节后 | 可售库存/近3个月平均实际售出量 | 同单品、同地区比较；销量为零不算，淡旺季影响显著 |
| 渠道 | 回款、补货、退货；月/季 | 自愿补货量、回款完成、退货率、返利授信变化 | 分辨终端拉动与压货/赊销；合同负债高低均不能单向判断 |
| 供给 | 规上产量及官方同比；月 | 折65度商品量，累计/当月/官方同比独立保存 | 只看供给变化；当前累计不能标全年，不混万吨和万千升 |
| 供给 | 基酒、有效产能；半年/年 | 按香型的合格基酒储备、实际可售量和投产周期 | 设计产能不是有效产能；当年基酒产量与成品销量通常不可直接求产销率 |
| 竞争 | 分价格带/地区份额；半年/年 | 同范围销售额/同范围总额 | 验证品牌与区域优势；收入集中度、利润集中度分开 |
| 竞争 | 量价和产品渠道结构；半年/年 | 同口径酒类收入/成品销量，分产品/地区/直销批发 | 实现均价受结构影响，不能宣称全部是同品提价 |
| 回报 | 正常化资本回报与再投资；年 | 税后经营利润/平均投入资本，维持/扩张投入分开 | 高毛利不等于资本回报；金融业务和非正投入资本另处理 |
| 约束 | 税负、政策、食品安全；事件/季 | 正式文件、生效日、主体，税金及附加/收入辅助 | 不把传闻或征求意见当作政策落地，不把全部税金当消费税 |

优先采集飞天茅台、普五、国窖1573、青花等代表单品，但必须具体到规格，不拼成不可比的“白酒均价”。批价建议每周更新，保留观测日期；“4周确认”是工作窗口，不是经回测的择时规则。

## 当前可计算的8项厂商验证信号

| 指标 | 公式 | 数据边界 |
|---|---|---|
| 厂商存货增速－营收增速 | 同期厂商存货同比－同期营业收入同比；百分点 | 正差额只提示占款/供需复核；基酒陈化及存货成本计价会影响解释 |
| 合同负债/同期营收 | 期末合计合同负债/本报告期累计合计营收 | 不年化，只比去年同报告期，不能理解成全年销售覆盖月数 |
| 经营现金流/营收 | 合计经营现金流/合计营收 | 不是公司比率简单平均；财务公司和税务节奏需单独解释 |
| 简化自由现金流率 | 合计（经营现金流－全部资本开支）/合计营收 | 不是严格股权自由现金流；不区分维持与扩张，扩产可暂时压低 |
| 销售费用/营收 | 合计销售费用/合计营收 | 结合毛利与动销看投入效率，不单向评分 |
| 营收正增长公司数 | 同公司同比为正数量 | 全样本同期基数为正且完整才显示，防止龙头掩盖多数公司下行 |
| 自由现金流为负公司数 | 经营现金流－全部资本开支小于零的数量 | 缺项不计零，也不把部分样本当全部 |
| 上市样本前六营收占比 | 当期营收前六/19家合计营收 | 动态前六，不是行业份额，不是固定品牌组合 |

不使用“厂商存货越少越好”或“库存天数越长越好”的机械规则。厂内长期储存基酒和渠道可售成品库存应按物理归属、工艺和价值分别判断。

## 看板判断与证伪

看板只做可复算的事实摘要：当同口径营收和归母净利同比均下降，显示“上市厂商收入与利润承压”；其他情况显示“需结合终端证据核验”。无论哪个结果，都不自动推出“行业已经见底”。

底部修复的研究证据应同时包含：同店动销改善、同品净成交价稳定、渠道库存去化和补货/回款正常。连续多个窗口才提高确信程度；任意一项反向都需要解释。没有完整量化证据时显示“待采集”，不补50分、不生成行业景气总分。

## 取数验收和本次拒绝项

- 2026-10-17经iFinD搜索确认有“白酒折65度商品量累计产量”数据库条目，元数据截至2026-08-31。
- 具体取数却返回2026-12-31全年标签及年频，与请求月频和元数据截止冲突。**数值拒用**，不调整日期后擅自发布。
- 国家统计局站点已核对统计方法；本次未取得口径完整、可交叉验证的最新白酒行业连续产量序列，因此看板不新增全国总量曲线。
- 未取得净成交批价、渠道库存月数和同店动销的有效观测，暂留空。协会报道只支持研究方向，不支持填入这些数字。
- 结构化源与另一平台可能共享上游；两者相同不能替代原报核查。官方材料也应核对单位、期次、修订和分母。

## 落地与维护

指标定义、来源和推断规则保存在 `白酒/scripts/industry_research.py`；随原生成器写入 `industry.json` 的 `research` 区。现有财务数据不改写、不重新评分。

诊断表随财报选择器切换，外部渠道观察不随财报选择器假装回溯。来源单列方法核对日与财报截至日；后续接入观察值前需扩展字段验收与有效期规则。历史样本存在存续偏差，不能直接作为历史全行业回测。
