# 茅台 2021 年应收账款：已核验零净值

## 一句话判断

2021-12-31 合并资产负债表的应收账款账面净值为 **0 元**，因为账面余额 3,097,678.25 元已经等额计提坏账准备。此前的缺失来自结构化接口空值，现已根据年报附注核验补入，而非把空白一律转零。

## 事实与核验过程

| 项目 | 结果 |
| --- | --- |
| 公司 | 贵州茅台，600519.SH |
| 报告期 | 2021-12-31 |
| 报表口径 | 合并报表，不是母公司报表 |
| 原披露 | 《贵州茅台：贵州茅台2021年年度报告》，2022-03-31 |
| 定位 | 七、合并财务报表项目注释，4、应收账款 |
| 单位 | 人民币元 |
| 期末账面余额 | 3,097,678.25 |
| 期末坏账准备 | 3,097,678.25 |
| 账面净值 | 3,097,678.25 − 3,097,678.25 = 0 |
| 核验与补录日期 | 2026-10-17 |

AKShare/东方财富本地快照的 `ACCOUNTS_RECE` 为空，重新查询 AKShare 年报接口仍为 null；AKShare 新浪资产负债表同项也为 null。iFinD 结构化财务接口没有返回可采纳的固定报告期数值，因此未据空值补零。

随后使用 iFinD 公告检索，定位到中文年报附注：按组合计提的应收账款账面余额及坏账准备均为 3,097,678.25 元，比例 100%；同次检索的英文版年报附注相互印证。补录零值来自这两个已披露金额的相减。

母公司报表中的 1,480,080,983.77 元应收账款属于另一个口径，不能代替合并净值。

- 增加定点补缺记录：`白酒/02_原始资料/05_iFind数据/supplement.csv` 中的 `600519,2021-12-31,receivables,0`。
- 证据：`白酒/02_原始资料/05_iFind数据/receivables_600519_20211231_verified_20261017.json`，保留来源、附注位置、原披露日、检索日、金额及摘录。
- 原 AKShare CSV 未修改；未更改全局缺失处理规则。
- 重新计算茅台年度派生指标及 V5 候选试算。正式 V4 权重、模型版本及已有评分保持原样，财务研究截止日仍为 2026-10-10；这次是历史单项修复，不是全量行情刷新。

## 对评分的含义

V5 的应收账款/营收原先缺少 2021 年数据，导致 7 分项目无法完整计算。补录净值零后可以按原公式计算，不需要放宽缺项规则或修改权重。

**零净值不等于没有信用损失**：这里仍有约 309.77 万元历史应收，只是已经全额计提。资产质量分析还应看账龄、追收和坏账变化；不能只看净额为零就宣称应收无风险。
