# 白酒行业现状指标核验

用户指出2026中报营收与归母净利错误。本次发现并修复的明确问题是：顶部及明细已切换到中报，长期曲线仍固定展示2016–2025完整年度，导致页面内报告口径不一致。逐项金额核对未发现差异，不对有来源支持的值做猜测性修改。

## 2026中报核验结果

19家申万白酒Ⅲ上市公司合并报表的同报告期合计，包含顺鑫农业非酒业务，不代表全国白酒行业。

| 指标 | 合计 / 亿元 | 对2025中报同比 |
| --- | ---: | ---: |
| 营业收入 | 1,963.19 | -6.74% |
| 归母净利润 | 731.00 | -8.35% |
| 经营现金流 | 807.78 | +33.67% |
| 厂商存货 | 1,891.88 | +12.39% |
| 合同负债 | 323.84 | -13.64% |

财务快照研究截至2026-10-10，交叉查询日期2026-10-17。营业收入使用 `OPERATE_INCOME`，归母净利用 `PARENT_NETPROFIT`；不混用营业总收入、合并净利润或单季度金额。利润、收入、现金流为年初至今累计，存货和合同负债为期末余额。

## 检查证据

- 本地原始字段对照1,425项：19家公司、10个年度和5个中期报告、5项金额。使用公告日与修订日截止约束，无差异。
- iFinD交叉对照665项：19家公司、2024年报至2026中报共7个报告期、5项金额。按照返回金额的格式化精度核对，无差异；例如四位小数的亿元仅支持约5,000元精度。
- 新行业历史聚合共46个报告日、230项金额与覆盖数；另对现有公司数据覆盖的近期汇总核对35项，均与底层字段求和一致。
- 快照原表及逐项来源保存在 `dashboard/data.json` 的 `provenance.fields`。查询问题和完整返回表见 [[白酒行业指标交叉核验_20261017.json]]；逐项核验结果见 [[白酒行业指标核验结果_20261017.json]]。

上述结果是结构化数据交叉核对，不等于逐页审计全部官方年报；AKShare与iFinD也可能共享上游来源，不能把两处一致解释为排除一切源头错误。

## 网页调整

中报、三季报、年报分别展示历年同一报告期，选择器同步顶部、全部曲线、分化图及明细，URL保留选择。四组趋势统一叠加变化：金额左轴、YoY右轴；合计归母净利率和CFO/营收的变化用百分点。同比以同期合计计算，不平均公司增速，不年化中报，不与上一季度比较。

样本缺项时不求部分和冒充全样本；历史合同负债未完整披露时留空，不用预收账款直接顶替。零同比基数不计算，负基数按差额除以上年同期绝对值计算并标注。利润率为合计分子除以合计营收。
