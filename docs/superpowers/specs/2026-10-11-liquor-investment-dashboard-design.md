# 白酒行业投资看板研究级改造设计

## 目标

把现有静态白酒看板改造成支持价值投资研究的证据驱动工具。用户需要在同一条决策路径上完成：判断行业所处状态、监控关键经营信号、比较上市公司基本面、区分经营质量与估值、检查数据可信度。

本期沿用现有 HTML、JavaScript、JSON 和 Python 生成脚本，不引入后端服务或实时交易系统。股票池沿用当前申万白酒 III 口径；当前核验成分数为 19 家，页面必须显示口径和基准日期。知识库中“20 家”作为外部宽口径资料，不与 19 家横向排名混用。

## 数据与证据

AKShare 是财务报表、行情和分红的主源。每一条数据保留报告期、公告/更新时间、单位、快照时间、接口和文件路径。数据生成接受 `--as-of`，只使用该日期前已经披露且没有被后续版本覆盖的记录。

当 AKShare 已确认报告期但某个原始字段为空时，才为该字段生成 iFinD 补缺请求。iFinD 结果必须通过代码、报告期、单位、来源日期和请求字段的严格验收；已有人工补缺文件不覆盖。AKShare 与 iFinD 数值不一致时，两边都写入冲突记录，计算值置为空，并在个股页展示冲突状态。

数据质量检查包括：股票池数量与来源一致、报告期完整性、单位为 CNY、公告日期不晚于 as-of、核心字段的异常同比变化、负利润和负现金流、分红方案的实施/除权状态。2025A 和 2026H1/YTD 分开显示，YTD 不年化，也不与完整年混合排序。

## 页面信息架构

`industry.html` 第一屏显示行业口径、最新完整年度和最新 YTD 的状态摘要，至少包括收入、归母净利润、经营现金流、库存/合同负债方向和上市公司样本覆盖。没有可靠全行业序列时，明确显示“上市样本，不代表行业总体”，不伪造行业曲线。

`index.html` 保留横向公司筛选，新增数据质量、质量分、估值分、基准价值/现价安全边际列。质量和估值分开筛选，排序不因缺失数据默认为 0。

`stock.html` 明确区分 2025A、2026H1/YTD 和行情日期，展示财务证据、利润流向、现金流桥、质量分拆解、估值桥、情景和敏感性分析。每个缺失、冲突或异常项给出原因和来源。

`score-formula.html` 显示公式版本、权重、统计窗口、阈值、缺失处理、未计分参考项和 DCF 假设，避免把研究假设误认为事实。

## 评分模型 V2

质量分满分 100，估值不混入质量分。核心数据采用 3～5 年历史，优先使用中位数，并对波动和负值保留风险标记。每个指标先按绝对经营阈值计分，再以白酒样本内 5%--95% 截尾百分位做 70/30 混合修正；不以浏览器端猜测或补 50 分。

| 维度 | 权重 | 组成 |
| --- | ---: | --- |
| 盈利能力与品牌护城河 | 25 | 5 年投入资本回报、毛利率、毛销差和营业利润率稳定性 |
| 现金创造 | 25 | 经营现金流/净利润中位数、股东自由现金流/净利润、销售收现比 |
| 资产负债表 | 20 | 资产负债率、现金/流动负债、经营现金流/流动负债、存货/营收 |
| 增长与稳定性 | 15 | 3 年收入/利润 CAGR、负利润或负 Owner FCF 年份 |
| 资本配置 | 15 | 分红连续性、派现率与 Owner FCF 覆盖、资本开支纪律 |

股息率只作为展示和资本配置证据，不再用最新股价直接改变经营质量分。ROIC 缺少有息负债时留空并降低数据覆盖；不得把空借款当成零。单项分为 70% 绝对阈值分和 30% 样本百分位分，样本不足五家时只用绝对分。亏损或负现金流公司可以保留观察分，但必须显式标记，不进入“可比质量排名”或给出价值陷阱提示。

投资标签单独生成：质量分、DCF 数据质量、基准安全边际和增长/现金流风险共同决定“质优低估、质优不便宜、低估质弱、价值陷阱风险、估值不足”，标签不替代分数和原始证据。

## DCF 与敏感性

主路径为 FCFF：

`FCFF = EBIT × (1 - 税率) + D&A - 资本开支 - ΔNWC`

按2026-10-18更新的要求，直接使用最新完整年报的 FCFF 作为现金流基准，不使用多年平均或中位数。历史现金流桥只供对照。预测期 5 年，增长率从当前 3 年收入趋势逐步收敛到永续增长率；收入趋势假设与现金流基数分开。永续增长率始终小于 WACC。FCFF 折现后只加一次已核验净现金，再除以行情总股本。标签中的低估与不便宜改由已核验可比的基准DCF与现价比较，不再由PE和股息率判断。

当最新年 FCFF 输入不足或非正，但同年 `CFO - capex` 为正时，使用该年简化自由现金流/owner FCF 路径并采用对应的股权折现率；页面必须标明这是替代路径。该年回退现金流仍非正或缺失时，不使用旧年正值替代，不输出正的永续价值。净现金未核验时保留每股价值代理，标签显示“DCF估值待核验”，不能把空债务字段按零计入。

每家公司输出悲观、基准、乐观三种情景，以及至少一张二维敏感性表：WACC × 永续增长率。另对基准现金流做 -10%、基准、+10% 的敏感性，显示每股价值、现价上行空间和安全边际。所有参数、基准年份、路径、股本和净现金来源写入 JSON 与页面。

## 错误处理与测试

生成脚本在源数据为空、冲突、单位错误、报告期未披露、现金流不足时保留 `null` 和状态，不写入 0。严格 JSON 禁止 NaN/Infinity。测试覆盖：缺失字段不排名、AKShare/iFinD 冲突、as-of 截断、分红实施日、FCFF/owner FCF 路径、WACC 大于永续增长、敏感性矩阵完整性和 19 家股票池一致性。

前端验证包括 JavaScript 语法检查、JSON 解析、关键页面 DOM 文案检查和宽窄视口下的静态布局检查。浏览器自动化若受本机安全策略阻止，使用相同数据的离线 DOM/截图检查并在交付中明确说明。

## 范围边界

本期不实现实时下单、自动投资建议、账户连接、后端定时任务和未经核验的行业总量估算。行业总体数据只有取得同口径、可追溯来源后才进入 `industry.json.series`；否则只展示已标注的上市样本序列。
