# 医疗健康研究台 V1

日期：2026-10-18。按用户“参考白酒和银行看板，调研后先搭建一版、后续迭代”的授权实施。

## 目标与结构

沿用白酒研究台的紧凑浅色布局、本地静态 HTML / JavaScript / Chart.js / JSON。新建医疗健康目录，四个入口为行业总览、公司对比、个股深度、评分方法。公司池为25家代表性A股上市公司，覆盖创新药与化药、生物制品、中药、医疗器械、CXO、医疗服务、医药流通、连锁药店；这不是全行业或完整指数成分。研发商业化药企百济神州、泽璟制药另列观察池，不参与成熟经营模型总分排名。

## 调研与方法选择

比较三条路线：直接移植白酒评分简单但忽略业务差异；子行业百分位易用但小样本排名不稳定；采用共同财务维度、子行业固定绝对锚点，并将管线、订单、支付政策和估值独立列示。选择第三条。

取数优先级按用户补充要求：AKShare → 财报PDF → iFinD补缺。三大报表优先用AKShare；研发资本化、授权收入等附注指标优先提取PDF，确实无法取得才用iFinD。保存原始数据、查询时间和字段来源。研究依据包括机构研究和公司披露，不把公告搜索摘录冒充PDF核验。对外许可不能统一当非经常损益，区分签约总额、实际到账和收入确认；研发投入不直接等于创新能力；资本化比例只做会计口径观察；rNPV用于管线研究，V1缺临床成功率和逐项目现金流，不输出伪精确目标价。

## 财务模型

采用2023–2025三个完整年度，另列2026H1同口径同比观察。共五维100分：盈利质量25、现金创造25、资产与偿债20、经营韧性20、利润真实性10。短窗口是V1的数据与模型取舍，后续扩为五年；不能将中报简单乘二计入年报。

盈利：三年中位ROE15分、三年中位扣非归母净利率10分，按子行业使用不同满分锚点。现金：三年累计CFO/合并净利润10分、三年累计(CFO-全部资本开支)/收入10分、FCF为正年数5分。资产：货币资金/流动负债8分、资产负债率6分、应收账款/年收入6分；商誉独立观察，缺失不当零；医疗服务与零售单列租赁负债口径限制。韧性：2022到2025营收CAGR10分、三年扣非盈利年数10分。真实性：三年扣非净利润/三年归母净利润10分。

所有锚点为项目研究假设，不是市场统一评分、不做收益承诺。不以毛利率跨行业直接排名，不把ROE称ROIC，不将CFO-资本开支称严格FCFF。缺项保留null，总分与排名留空，展示已得分范围、覆盖率；不把缺失当零，不归一化补齐。利润累计非正且资料齐全属于经济无效，相关转化率计零分并明确原因。

风险上限：最新年归母或扣非亏损49；连续两年CFO负49；三年累计FCF非正59；归母权益非正39。必要风险字段缺失不出总分。不把未经核验的审计/处罚情况标为安全，监管事件、集采暴露和客户集中度保留待核验状态。

## 页面与验收

行业总览：样本财务合计、分行业对比、收入/利润/现金趋势、政策与产业研究证据。公司对比：搜索、子行业与完整性筛选、主题列、排序、两公司对照及CSV导出。个股页：时间对齐趋势、五维贡献、现金流桥、研发/营运资金、风险和数据来源。方法页：权重、固定锚点、逐项分数、缺失和风险推导、研究资料。

数据由脚本采集并保存原始响应；独立评分模块生成严格JSON，前端只读同一快照。验证单位、年度筛选、季度不混入年度、缺项、亏损、负权益、子行业阈值和风险上限。使用浏览器在1440×1000及390×844检查四页、筛选排序、对照、CSV、图表像素和横向溢出。

## 实施与验收结果

四页已完成，预览服务默认8771端口。100个AKShare原始快照映射12,457个有效字段；四份2025完整年报PDF补充14条带页码附注与经营事实；财务数据没有使用iFinD。机构研究摘要单独存证，明确二手资讯等级。23家公司完整评分，2家单列研发观察池。

11项Python测试通过；225项AKShare关键指标/三大报表交叉核验无差异；Playwright双视口四页、图表像素和交互验证通过。具体口径、证据、测试与限制见医疗健康/研究框架与验收.md。
