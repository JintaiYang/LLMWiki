# 中概互联网研究台 V1

日期：2026-10-18。用户授权先搭建可运行版本，后续迭代。

## 范围与实现

沿用白酒、银行研究台的行业总览、公司对比、个股深度、评分方法结构，新增来源审计视图。独立放在互联网目录，使用原生 HTML/CSS/JS、仓库已有 Chart.js 与 Lucide 本地副本。首页直接展示行业研究工作台；以哈希路由支持可分享视图。图表、数据表、下载均使用同一份规范化数据。

首批覆盖腾讯、阿里、拼多多、京东、美团、网易、携程、百度、快手、哔哩哔哩、腾讯音乐。每家公司保留一条经济实体记录，港美双重上市不重复统计。分组为综合平台、电商零售、本地生活、游戏、在线旅游、内容社区、搜索与AI、音乐订阅。

## 数据契约

必须按 AKShare → 官方财报 PDF → iFinD 顺序逐指标补缺。数据保存数值、单位、期间起止、来源文件、原始字段、取数时间与回退原因。AKShare 与 iFinD 是供应商数据，不能标为官方核验。财年按实际起止识别；阿里 3 月结算年单列 FY，不能混同自然年度。季度、半年累计、全年不得直接相加；同口径才能计算 TTM。

保留至少 2023-2025 年度序列及已获取的 2026 中报。横向评分优先使用最近完整 FY；年度过旧与较新中报恶化单独标记。页面明确实际报告期和行情日期。人民币财务与港元/美元行情分开，未经汇率和股本核对不计算收益率或目标价。

FCF 统一代理口径为经营现金净额减现金购建固定/无形资产支付；不得将现金流中的负资本支出再次相减。公司披露 FCF 单列，含内容/租赁/预付款差异保留桥接。现金等价物不等于含定存和短投的公司净现金，狭义值明确命名。SBC 是经济成本，不能因调整利润加回而消失。

## 研究与评分

市场框架参考：平台经营量价与变现率、分部利润/UE、AI 投入到商业化转化、自由现金流、资本配置、PE/DCF/SOTP。研报聚合与新闻摘要标注二手线索，不宣称已取得券商完整研报。基金发行人官网与公司财报作为一手依据。

V1 自建规则评分，不冒充机构评级。六维满分 100：增长20、盈利质量20、现金创造25、投入纪律15、财务韧性10、股东回报10。每个指标公开权重、阈值、方向和实际贡献。估值独立展示。缺项不填零，不静默视作满分；显示实得/可用分、覆盖率和折算参考分，覆盖率低于80%不发布总分。经营亏损、负现金流作为真实低分，不能被当作缺项排除。无同口径两期不计算同比；负基数利润同比不使用。

共同指标包括收入同比/两年 CAGR、ROIC、经营利润率变化、现金转化、FCF率/持续性、CapEx/CFO、SBC/收入、流动性与负债率、现金回购/分红、摊薄股数变化。平台毛利率只展示，不跨模式按绝对高低打分。风险单列，不以未经核实主观风险打固定扣分。

## 交互与验证

支持公司/代码搜索、子行业筛选、指标分组、可排序横向表格、观察名单、最多四家公司对比、年度切换、个股财务趋势与现金流桥、评分逐项拆解、原始数据链接及 CSV/JSON 导出。观察名单与自定义权重仅本地保存，可重置。无数据和请求失败显示可恢复状态。

验证包括期间和单位约束、负数/缺项评分、FCF与同比计算、来源优先级、浏览器搜索/筛选/对比/路由/权重/导出，以及桌面和移动端截图、图表像素非空与布局溢出检查。使用本地静态服务器启动并提供 URL。
