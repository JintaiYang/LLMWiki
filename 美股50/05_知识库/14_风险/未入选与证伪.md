## 原报告中的未入选与备选

未入选不等于公司差，也不是因为股票贵。以下是本次候选池中最接近入选或值得关注的对象；第 50 名附近的选择可以随证据改变。

| 公司 / 代码 | 本次处理 | 与入选企业相比的主要保留意见 |
|---|---|---|
| Adobe / ADBE | 第一备选 | 五年现金非常强；对 AI 改变创作工具收费与替代关系的判断更保守，SBC 也较高。若客户留存、定价和 AI 商业化证据改善，可替换后段企业 |
| Synopsys / SNPS | 第一备选 | EDA 优势强；本次同类选择 CDNS，主要因大型并购、可比范围和现金投入增加核验难度，不因同业配额排除 |
| Eaton / ETN | 第一备选 | 电气化增长强；需统一经营利润、投入资本与订单周期，在更重成长的框架下可入选 |
| AutoZone / AZO | 第一备选 | 汽配渠道与现金业务优秀；与 ORLY 很接近，海外扩张、资本配置和财年更新可使两者互换 |
| HEICO / HEI | 第一备选 | 航空零部件认证与后市场优势；并购增长、现金使用和航空周期须进一步归一化 |
| Aon / AON、Gallagher / AJG、Brown & Brown / BRO | 第一备选 | 经纪业务重复性强，承保风险低于保险公司；大型并购、股数变化与资金归属需要重算，完成后可能替换银行/保险席位 |
| Danaher / DHR、Thermo Fisher / TMO | 观察 | 业务壁垒较好，但疫情、剥离与生物制药资本开支使增长可比性较弱；DHR 五年报告收入 CAGR 约 -0.2% 不应直接当有机衰退 |
| Amazon / AMZN | 观察 | AWS 很强，但合并五年 FCF 仅 3/5 年为正、中位 FCF 利润率约 1.1%；需要按分部和资本开支拆分，不能用 AWS 质量替代全公司现金质量 |
| Vertex / VRTX | 观察 | 专病产品与现金潜力强；2024 年研发/交易支出造成亏损与负 FCF，需正常化并检验新产品分散能力；单年异常并非永久否决 |
| Novo Nordisk / NVO | 观察 | 年报财务仍很强；GLP-1 竞争、产品/产能投入及 2026 年经营公告需专项更新。本次选择礼来不表示已证明 NVO 基本面恶化 |
| UnitedHealth / UNH | 观察 | 保险与医疗服务结构复杂；医疗成本、监管、资金归属和最新经营利润必须专项重审，历史 CFO 不足以支持入选 |
