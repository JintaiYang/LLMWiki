## 高频更新（日更）— 行情与估值

> 每日开盘后运行，更新股价、市值、PB/PE/股息率、A/H溢价。

| 按钮 | 更新内容 | 数据源 | 脚本 | 影响页面 |
| --- | --- | --- | --- | --- |
| 📈 更新行情快照 | 42家银行最新价/市值/PB/PE/股息率 | AkShare (东方财富) | `scripts/fetch_latest_bank_prices.js` | Dashboard、DDM估值表、A-H估值对照表 |
| 📈 更新行业指数 | 中证银行指数(399986)日线 | AkShare | `scripts/fetch_nim_etf.py` | 行业看板 |

```bash
# 高频更新命令（每日运行）
cd "/Users/yangjintai/Documents/LLM wiki/银行"
node scripts/fetch_latest_bank_prices.js    # 行情快照（约2分钟）
python3 scripts/fetch_nim_etf.py            # 行业指数
```

## 中频更新（季更）— 财报与基本面

> 每季度财报季后运行，更新三大报表、监管指标、深度研究页。

| 按钮 | 更新内容 | 数据源 | 脚本 | 影响页面 |
| --- | --- | --- | --- | --- |
| 📊 拉取深度财务数据 | 18家银行利润表/资产负债表/财务分析/估值 | AkShare (新浪+东方财富) | `scripts/fetch_bank_deep_metrics.py` | 深度研究页、Dashboard data.json |
| 📊 回填iFind监管指标 | NIM/不良率/拨备覆盖率/CET1 | iFind 专项指标 CSV | `scripts/backfill_dashboard_regulatory.py` | Dashboard、全量比较表 |
| 📊 更新深度研究文档 | 把JSON数据写入Markdown页 | 本地 JSON → MD | `scripts/update_deep_research_docs.py` | 18家深度研究.md |
| 📊 回填跟踪器与基础档案 | 把iFind/AkShare数据写入跟踪器和基础档案 | iFind + AkShare JSON | `scripts/update_all_data.py` | 跟踪器×5、核心比较表、基础档案×18 |
| 📊 更新DDM估值表 | 全量42家DDM估值计算 | iFind + 本地脚本 | `scripts/compute_bank_ddm.py` | A股银行DDM估值表 |
| 📊 更新Dashboard数据 | 从MD页提取指标生成data.json | MD → JSON | `scripts/generate_dashboard_data.py` | Dashboard index.html |
| 📊 更新仪表盘深度数据 | 补充深度指标到data.json | AkShare JSON + iFind | `scripts/backfill_dashboard_deep_metrics.py` | Dashboard |

```bash
# 中频更新命令（季度财报季后运行）
cd "/Users/yangjintai/Documents/LLM wiki/银行"
python3 scripts/fetch_bank_deep_metrics.py   # Step 1: 拉取深度数据（约10分钟）
python3 scripts/backfill_dashboard_regulatory.py  # Step 2: 回填iFind监管指标
python3 scripts/update_deep_research_docs.py      # Step 3: 更新深度研究MD
python3 scripts/update_all_data.py                # Step 4: 回填跟踪器+基础档案
python3 scripts/compute_bank_ddm.py               # Step 5: DDM估值
python3 scripts/generate_dashboard_data.py        # Step 6: Dashboard数据
python3 scripts/backfill_dashboard_deep_metrics.py # Step 7: Dashboard深度补充
```
