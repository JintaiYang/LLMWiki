# 银行股Top5排序（基于《手把手教你读财报2》框架）

> **阅读提示**：本页是一次横向排序练习，把知识库中已核验和未核验的数据放在一起比较，**证据等级不对等**是本页最大的局限，务必先读第 5 节"数据证据等级与局限性"再看排名结论。

## 1. 排序目的与方法

- **目的**：从知识库当前 17 家已建立"深度研究"文档的银行中，依据唐朝《手把手教你读财报2》提出的核心指标框架和"好银行画像"标准，筛选并排序出 Top5。
- **方法**：以书中第4章"核心指标汇总表"和第5章"好银行/风险银行画像"六要素为评分依据——①存款护城河 ②资产质量 ③收入结构 ④成本控制 ⑤资本内生 ⑥ROE可持续>12%，结合已提取的 2025A 数据逐项比较。
- **候选池**：知识库 `03_银行库/` 下 17 家已建立"深度研究"文档的银行（中信、中国、交通、兴业、农业、南京、宁波、工商、常熟、平安、建设、招商、杭州、民生、江苏、浦发、邮储、成都）。

## 3. Top5 排序结论

### 第1名：招商银行

| 指标 | 数值（2025A，年报核验） |
| --- | --- |
| 加权ROE | 13.44% |
| ROA | 1.20%（候选池最高） |
| 非息收入占比 | 36.13% |
| 活期存款占比（期末） | 50.79% |
| 存款成本率 | 1.17%（同比 -24bp） |
| 拨备覆盖率 | 391.79% |
| CET1 | 14.16% |
| PB | 0.86 |

**选择理由**：唯一一家在书中六项"好银行画像"上**全部有正式年报数据支撑且全部达标**的银行。活期占比 50.79%、存款成本率 1.17% 显著优于书中"优秀标准"（活期占比>40%、成本率<2.0%）；非息收入占比 36.13% 体现轻资本收入结构优势；ROA 1.20% 为候选池最高，说明资产使用效率最强。主要扣分项是营收几乎零增长（+0.01%），详见 [[05_知识库/03_银行库/招商银行 深度研究]]。

### 第2名：杭州银行

| 指标 | 数值（2025A，年报核验） |
| --- | --- |
| 加权ROE | 14.65% |
| 归母净利润增速 | +12.05% |
| NIM | 1.36%（同比 -5bp） |
| 拨备覆盖率 | 502.24%（候选池最厚） |
| CET1 | 9.59% |
| 个人贷款不良率 | 1.21%，同比 +44bp |
| PB | 0.84 |

**选择理由**：ROE 与利润增速均优于招行，拨备覆盖率是候选池中最厚的安全垫。对公存款占比 70.54%、活期占比 41.25% 符合书中"存款护城河"标准。排名低于招行的原因：CET1（9.59%）明显低于招行（14.16%），资本扩张空间较窄；且已核验出个人贷款不良率同比上升 44bp，科创贷款、小微贷款尚无专项不良数据。详见 [[05_知识库/03_银行库/杭州银行 深度研究]]。

### 第3名：宁波银行

| 指标 | 数值（2025A，AkShare三方数据） |
| --- | --- |
| 加权ROE | 13.11% |
| ROA | 0.87% |
| 营收增速 | +8.01% |
| 净利润增速 | +8.13% |
| PB | 0.91（候选池最高） |

**选择理由**：营收和利润"量价齐升"表现最均衡的一家——书中强调 PPOP 增速应与净利润增速方向一致，宁波银行两者都保持中高个位数正增长，不像招行、杭州银行那样存在"营收停滞"或"利润增速远超营收"的失衡。市场给出的 PB（0.91x）是候选池最高，隐含市场认可度最强。局限：NIM、不良率、拨备覆盖率、CET1、活期占比等指标尚未从年报核验。

### 第4名：常熟银行

| 指标 | 数值（2025A，AkShare三方数据） |
| --- | --- |
| 加权ROE | 14.05% |
| ROA | 1.16%（候选池第二） |
| 净利润增速 | +10.65% |
| 营收增速 | +6.51% |
| PB | 0.69 |

**选择理由**：ROA 和净利润增速均处于候选池前列。作为小微金融特色的农商行，在高 ROA 同时保持两位数利润增长，说明小微定价能力和风控暂未出现明显失衡迹象。局限：全部监管口径指标未核验；且作为农商行，规模和抗系统性风险能力显著弱于全国性股份行/头部城商行。

### 第5名：成都银行

| 指标 | 数值（2025A，AkShare三方数据） |
| --- | --- |
| 加权ROE | 15.39%（候选池最高） |
| ROA | 1.00% |
| 成本收入比（CIR） | 23.73%（候选池最低） |
| PB | 0.83 |

**选择理由**：ROE 和成本收入比均为候选池第一，书中标准 CIR<30% 为优秀，成都银行以 23.73% 大幅超越标准。排名靠后的原因：营收和利润增速仅 +2.70%/+3.31%，明显低于同为高 ROE 的宁波、常熟银行，说明其高 ROE 更多依赖存量效率而非增量扩张；且区域集中度高（主要依赖成都本地对公业务），专项集中度数据尚未核验。

## 5. 数据证据等级与局限性（必读）

- **证据等级不对等**：招商银行、杭州银行是知识库中**仅有的两家**完成正式年报手工核验的深度研究（含 NIM、不良率、拨备覆盖率、CET1、活期存款占比等监管指标）；其余候选银行（含入选的宁波、常熟、成都银行）目前**仅有 AkShare 自动采集的三方数据**。书中最看重的"资产质量前照灯"（逾期90天以上比例、关注类比例、新生成不良率）、"负债护城河核心证据"（活期存款占比、存款成本率）、CET1 等指标对这些银行**全部缺失**，本次评分只能基于盈利能力和估值维度，**不能排除未被发现的资产质量或负债结构风险**。
- **未纳入前五但表现突出的银行**：江苏银行（ROE 13.14%，营收增速 +8.82%，候选池第二快）、南京银行（非息占比 37.16%，候选池最高）在盈利维度同样出色，因综合排序略靠后且同样缺乏年报级指标核验，未进入前五。若调整评分权重（如更看重营收增速），排名可能变化。
- **本页排序不构成投资建议**：仅是基于当前已提取数据的方法论演练，不替代逐项年报核验后的深度研究结论。
