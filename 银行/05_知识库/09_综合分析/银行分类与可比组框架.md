# 银行分类与可比组框架

## 1. 为什么先分组再比较

- 银行业的关键指标高度依赖客群、区域、负债结构和监管要求；不先分组，[[ROE与可持续增长]]、[[不良率关注率与逾期率]] 和估值比较都会失真。
- 当前库内 AkShare 快照覆盖 42 家 A 股上市银行，可作为分组底表入口：[[05_知识库/10_来源/来源_AkShare中国A股上市银行42家快照_2026-07-22]]。

## 2. 建议的一级分组

- 国有大行：规模大、低成本负债强、政策属性更重。
- 股份行：全国经营、零售/财富管理或同业能力差异明显。
- 城商行：区域禀赋强，成长性与区域集中度并存。
- 农商行：县域深耕、普惠与小微特征更明显。

## 3. 二级标签

- 零售优势：见 [[零售银行]] 与 [[财富管理]]。
- 对公与产业链优势：见 [[对公银行]]。
- 金融市场与同业能力：见 [[金融市场与同业]]。
- 县域下沉：见 [[普惠小微与县域]]。

## 4. 研究推断

- 同一类银行内部，最重要的比较维度不是“谁规模更大”，而是“谁的负债更稳、风险暴露更可控、资本补充更从容”。
- 当宏观压力上升时，区域禀赋和治理差异会放大，见 [[治理与区域集中]]。
