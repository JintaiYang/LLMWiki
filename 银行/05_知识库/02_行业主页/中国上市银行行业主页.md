# 中国上市银行行业主页

## 1. 行业定位

- 中国上市银行是典型高杠杆、强监管、重周期行业，核心研究变量是 [[NIM与净利差]]、[[新生成不良与信用成本]]、[[CET1与资本充足率]] 和估值。
- 库内现有 AkShare 快照覆盖 42 家 A 股上市银行，这一覆盖事实可作为研究入口，证据等级为 `medium`：[[05_知识库/10_来源/来源_AkShare中国A股上市银行42家快照_2026-07-22]]。

## 2. 官方事实

- 行业横向比较的监管口径，应优先使用商业银行主要监管指标：[[05_知识库/10_来源/来源_国家金融监督管理总局商业银行主要监管指标]]（https://www.nfra.gov.cn/）。
- 行业扩表、居民与企业资金迁移、社融节奏，应优先使用央行统计：[[05_知识库/10_来源/来源_中国人民银行社融与金融机构统计]]（https://www.pbc.gov.cn/）。

## 3. 研究框架抓手

- 第一层：看 [[货币政策与银行传导]]，判断资产收益率和负债成本方向。
- 第二层：看 [[银行分类与可比组框架]]，确定国有大行、股份行、城商行、农商行之间的可比边界。
- 第三层：看 [[净息差收窄]]、[[资产质量滞后暴露]]、[[资本约束]] 三个行业主矛盾。
- 第四层：回到 [[银行股完整投资研究框架]]，把盈利、风险、资本和估值串起来。

## 4. 研究推断

- 银行股并非单一“高股息”板块，实际上是不同负债能力、区域禀赋、客群结构和监管约束的组合。
- 对长期投资更重要的不是短期利润波动，而是 ROE 的可持续性、资本内生能力和尾部风险暴露速度。
