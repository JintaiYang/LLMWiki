# 货币政策与银行传导

## 1. 传导路径

```text
政策利率 / 准备金 / 公开市场操作
→ 资金利率与债券收益率
→ 贷款定价与存款重定价
→ 银行净息差、规模增速、债券投资收益
→ 利润、资本内生积累与估值
```

## 2. 官方事实

- 央行是政策利率、降准、公开市场操作与 LPR 改革的权威来源：[[05_知识库/10_来源/来源_中国人民银行货币政策工具与利率政策]]（https://www.pbc.gov.cn/）。
- 社融、人民币贷款和存款统计可以观察传导效果是否真正落到信用扩张：[[05_知识库/10_来源/来源_中国人民银行社融与金融机构统计]]。

## 3. 研究推断

- 对银行来说，宽货币不等于宽利润；当资产重定价快于负债重定价改善时，[[NIM与净利差]] 仍可能承压。
- 货币政策更像分配银行利润的速度调节器：它决定谁先受益、谁先被压缩，而不是简单创造行业阿尔法。
