# 房地产与地方化债传导

## 1. 传导链

```text
房地产销售/投资下行 或 地方财政承压
→ 房企、平台、按揭与地方产业链现金流变化
→ 银行贷款质量、重组与展期压力
→ 拨备、资本消耗与估值折价
```

## 2. 官方事实

- 房地产开发投资、商品房销售等宏观事实，优先看统计局：[[05_知识库/10_来源/来源_国家统计局宏观经济与房地产统计]]（https://www.stats.gov.cn/）。
- 地方政府债务、专项债和化债安排，优先看财政部：[[05_知识库/10_来源/来源_财政部财政收支与地方政府债务]]（https://www.mof.gov.cn/）。

## 3. 研究推断

- 房地产与地方化债并不只影响不良确认，更会影响新贷款定价、区域存款流向和资本消耗路径。
- 区域集中度高的银行，往往先在 [[治理与区域集中]] 和 [[资产质量滞后暴露]] 上体现压力，而不是立刻反映到利润表。
