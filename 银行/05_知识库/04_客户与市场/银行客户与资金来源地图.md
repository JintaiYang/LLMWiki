# 银行客户与资金来源地图

## 1. 客户与资金两端

- 资产端核心客户：政府与平台、央国企、大中型民企、小微企业、居民按揭、消费贷、信用卡客户。
- 负债端核心资金：居民存款、企业存款、同业负债、同业存单、金融债、理财回表或表外资金。

## 2. 官方事实

- 居民和企业存款、贷款与广义信用供给，优先看央行统计：[[05_知识库/10_来源/来源_中国人民银行社融与金融机构统计]]。
- 存款保险与金融稳定框架，会影响客户对不同银行的安全感分层：[[05_知识库/10_来源/来源_中国人民银行存款保险与金融稳定]]（https://www.pbc.gov.cn/）。

## 3. 研究推断

- 负债护城河的本质是“客户为什么愿意把低成本、稳定的钱长期留在你这里”，因此 [[存款成本与负债护城河]] 比单纯存款规模更重要。
- 客户结构决定业务场景：对公银行更看产业链与区域财政，零售银行更看财富管理和零售客群黏性，见 [[对公银行]] 与 [[零售银行]]。

## 4. 常见误区

- 把存款增长简单当成竞争力提升，而忽略期限结构和成本变化。
- 把高收益零售贷款当成普遍优势，而忽略后续 [[资产质量滞后暴露]]。
