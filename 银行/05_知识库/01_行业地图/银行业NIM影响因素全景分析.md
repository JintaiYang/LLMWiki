# 银行业NIM影响因素全景分析

> 用途：系统梳理银行行业整体NIM（净息差）的影响因素体系，从宏观政策到资产负债结构逐层拆解，帮助理解NIM变化的方向和幅度。本页是分析单家银行NIM和预判行业趋势的基础框架。

## 1. 核心公式

NIM 的变化本质上是资产端收益率和负债端成本率两端"跷跷板"的结果：

```
NIM = 利息净收入 / 平均生息资产
    ≈ 生息资产平均收益率 - 计息负债平均成本率
```

- **资产端收益率↑ 或 负债端成本率↓ → NIM 扩大**
- **资产端收益率↓ 或 负债端成本率↑ → NIM 收窄**
- **两端同向变化时，看变化幅度谁更大**

---

## 2. 影响因子全景图

```
                    ┌─ LPR/政策利率下降 ───→ 贷款收益率↓ ★
                    ├─ 债券收益率下降 ────→ 投资收益率↓
   资产端收益率 ←──┤
                    ├─ 贷款结构变化（票据/按揭占比↑）→ 收益率↓
                    ├─ LPR存量重定价 ────→ 收益率滞后↓ ★
                    └─ 政策性让利 ───────→ 收益率↓（大行更受影响）

                              NIM

   负债端成本率 ←──┤
                    ├─ 存款定期化 ────────→ 成本率↑ ★
                    ├─ 活期存款占比下降 ──→ 成本率↑ ★
                    ├─ 存款挂牌利率下调 ──→ 成本率↓（利好但有时滞）
                    ├─ NCD/同业利率变化 ──→ 成本率±
                    └─ RRR降准 ─────────→ 释放低收益资产→间接利好NIM

  ★ = 当前行业核心矛盾
```

---

## 3. 宏观政策层（决定行业整体水位）

### 3.1 LPR / 政策利率 — 资产端的"定价锚"

- LPR（贷款市场报价利率）是银行新发放贷款的定价基准。央行降息→LPR下调→新发放贷款利率下降→存量贷款重定价后收益率也随之下降。
- **2023-2025年LPR多次下调**是全行业NIM持续承压的最直接原因——贷款收益率被"行政性"压低。
- 不仅影响贷款：债券收益率也跟随政策利率联动，金融投资的收益率同步下降。
- **影响传导路径**：

```
央行降MLF利率 → LPR下调 → 新发放贷款利率↓
                                ↓
                    存量浮动利率贷款次年重定价↓
                                ↓
                    生息资产平均收益率↓ → NIM收窄
```

### 3.2 存款挂牌利率 — 负债端的"对冲阀"

- 央行引导银行下调存款挂牌利率，可以降低负债成本，部分对冲资产端收益率下降。
- **但有时滞和不对称**：
  - 存款重定价慢于贷款——定期存款到期才重定价，而贷款重定价周期通常为每年1月1日。
  - 活期存款利率已经很低（0.2%），下调空间有限。
  - 所以"降贷款利率"对NIM的冲击往往快于"降存款利率"的缓解——形成"不对称挤压"。

### 3.3 法定存款准备金率（RRR）— "低收益资产"的占比拖累

- 银行每吸收一笔存款，必须按 RRR 把一部分"锁"在央行，央行准备金利率约1.62%——远低于贷款收益率（3.5%-5.0%）。
- RRR越高→低收益资产占比越高→整体NIM被拖累。
- 央行降准→释放这部分资金用于放贷或买债→NIM有小幅改善。
- **国有大行受此影响更大**：大行存款规模大、准备金缴存基数大，低收益资产占比天然更高，这也是大行NIM普遍低于股份行的原因之一。

## 4. 资产端结构层（收益率高低取决于钱投去哪）

### 4.1 贷款占比 vs 非贷资产占比

| 资产类型 | 典型收益率 | 风险 |
| --- | --- | --- |
| 贷款 | 3.5%-5.0% | 信用风险 |
| 债券投资 | 2.0%-2.8% | 利率风险 |
| 同业资产 | 1.5%-2.0% | 低 |
| 央行准备金 | ~1.62% | 无 |

- 贷款是银行收益率最高的生息资产。贷款/总资产占比下降（如银行"资产荒"被迫多买债券）→整体收益率下降→NIM被拖累。
- **关注信号**：当银行出现"资产荒"（优质贷款需求不足），被迫将资金投向低收益债券或同业资产时，NIM会被动收窄。

### 4.2 贷款结构：对公 vs 零售 vs 票据

| 贷款类型 | 收益率 | 资本消耗（风险权重） | 不良风险 |
| --- | --- | --- | --- |
| 零售按揭 | 3.5%-4.0% | 低（50%） | 低 |
| 零售消费贷/信用卡 | 5%-7% | 中（75%） | 中 |
| 对公贷款 | 4%-5% | 高（100%） | 中高 |
| 票据贴现 | 1.5%-2.5% | 低（20%-25%） | 低 |

- **零售贷款占比高的银行**（如招商银行）收益率和资产质量都有优势，NIM通常更高。
- **票据贴现占比上升**→收益率下降（票据是低收益资产），通常是"贷款投放不足"时的填充手段——说明有效信贷需求不足。
- **按揭贷款占比高**的银行收益率偏低但风险低——按揭是低收益低风险资产，NIM贡献不大但对资产质量有利。

### 4.3 LPR存量重定价 — 滞后冲击

- 大量存量房贷和浮动利率贷款每年初按最新LPR重定价。
- LPR下降后，存量贷款收益率逐年"阶梯式"下降——**即使不再新降息，NIM仍会被存量重定价拖累1-2年**。
- **这是NIM"滞后恶化"的核心机制**：降息当期冲击有限，但后续1-2年重定价才逐步体现。

---

## 5. 负债端结构层（成本率高低取决于钱从哪来）

### 5.1 存款结构：活期 vs 定期 — 当前行业核心矛盾

- **活期存款利率0.2%-0.3%**，是银行几乎"免费"的资金。定期存款利率1.5%-2.5%，贵5-10倍。
- **2022-2025年出现"存款定期化"趋势**——居民把钱从活期转向定期，原因：
  - 理财收益下降、破净增多→资金回流存款
  - 风险偏好降低→偏好确定性更高的定期
  - 部分银行主动用高息定期产品揽储
- **定期化对NIM的侵蚀**：即使央行降存款挂牌利率，定期化趋势仍在抵消部分效果——整体存款成本率可能不降反升。
- **活期存款占比是区分银行NIM高低的最关键结构性因素**——招商银行活期占比40%+，负债成本极低，NIM长期领先行业。

### 5.2 存款 vs 主动负债

| 负债类型 | 典型成本率 | 稳定性 |
| --- | --- | --- |
| 活期存款 | 0.2%-0.3% | 高（客户日常使用） |
| 定期存款 | 1.5%-2.5% | 中高（到期可能流失） |
| 同业存单（NCD） | 1.8%-2.5% | 中（到期需续发） |
| 同业拆入/卖出回购 | 2.0%-3.0% | 低（超短期） |
| 已发行债券（金融债等） | 2.0%-3.0% | 高（有固定期限） |

- 存款是最低成本的资金来源。依赖NCD的中小银行在市场利率上升时负债成本跳升更快，NIM波动更大。
- **同业负债占比高的银行**NIM对市场利率更敏感——NCD利率上行时成本率快速上升，但资产端贷款利率不能同步调整，NIM被挤压。

### 5.3 存款挂牌利率下调的效果与局限

- **效果**：定期存款到期后按新利率重定价，负债成本逐步下降。
- **局限**：
  - 时滞——定期存款到期才重定价，3年期定存要等3年才完全重定价。
  - 活期存款已降至0.2%，几乎没有下调空间。
  - 如果存款定期化趋势持续（客户把活期转定期），即使挂牌利率降了，整体成本率可能不降反升。

## 6. 行业特有政策因素

### 6.1 政策性让利

- 经济下行期，监管可能要求银行"让利实体经济"——降低贷款利率、减免手续费、延后还本付息等。
- 这些政策直接压低资产端收益率，对NIM有一次性冲击。
- **国有大行受"让利"政策约束更多**（政治任务），这也是工行ROE/NIM低于招行的原因之一。

### 6.2 存款利率自律机制

- 市场利率定价自律机制对存款利率上限进行约束，防止银行恶性竞争高息揽储。
- 2021年6月改为"基准利率+基点"的定价方式，2022年后多次下调存款利率上限。
- 效果：有助于行业整体负债成本下降，但对活期存款影响有限（本来就低）。

---

## 7. 当前行业NIM核心矛盾总结

**2023-2025年行业NIM持续收窄的核心逻辑链**：

```
央行降息（LPR多次下调）
    ↓
资产端：贷款收益率快速下降 + 存量重定价滞后拖累1-2年
    ↓
负债端：存款挂牌利率同步下调，但 ↓
    ├─ 存款定期化抵消降息效果（活期转定期→成本率结构性上升）
    ├─ 活期存款利率已到底（0.2%），下调空间耗尽
    └─ 定期存款重定价有时滞（3年期定存要等3年）
    ↓
结果：资产端降得快、负债端降得慢 → NIM"不对称收窄"
```

**行业分化逻辑**：

| 银行类型 | NIM表现 | 核心原因 |
| --- | --- | --- |
| 国有大行 | NIM偏低（~1.5%-1.8%）且持续收窄 | 准备金占比高+让利约束+活期占比不如招行 |
| 优秀股份行（招行） | NIM相对高（~2.0%+）且抗收窄 | 活期存款占比40%+，负债成本极低 |
| 城商行 | NIM差异大 | 部分靠区域优势拿高收益资产+本地存款优势；部分依赖NCD成本高 |

## 8. 单银行NIM分析检查清单

分析单家银行NIM时，按以下维度逐项检查：

### 8.1 资产端

- [ ] 生息资产平均收益率（同比变化方向）
- [ ] 贷款/总资产占比（上升=回归本源，利好NIM）
- [ ] 零售贷款占比（上升=收益率提升）
- [ ] 票据贴现占比（上升=有效需求不足，拖累NIM）
- [ ] 新发放贷款平均利率（领先指标）
- [ ] 存量贷款重定价进度（未来1年还有多少待重定价）

### 8.2 负债端

- [ ] 计息负债平均成本率（同比变化方向）
- [ ] 活期存款占比（趋势方向——定期化是负面信号）
- [ ] 存款成本率（同比变化方向）
- [ ] 同业负债占比（NCD依赖度）
- [ ] NCD发行利率趋势

### 8.3 联动判断

- [ ] 资产端收益率变化 vs 负债端成本率变化 → 哪端变化更大？
- [ ] NIM变化是"以量补价"（规模增速>NIM降幅）还是"量价齐跌"？
- [ ] NIM变化是行业共性（LPR/存款利率驱动）还是银行个体因素（结构优化/恶化）？
