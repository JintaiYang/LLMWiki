# 银行业资金循环与价值链地图

> 用途：理解银行如何从负债端获取资金、在资产端配置资金、并在过程中创造价值和承担风险。这是研究银行股的"底层操作系统"。

## 1. 资金循环全景

```text
┌─────────────────────────────────────────────────────────────────────────┐
│                          资金来源（负债端）                              │
│                                                                         │
│  居民存款 ←── 工资/经营收入/投资回报            活期（低成本）          │
│  企业存款 ←── 经营回款/融资到账                  定期（高成本）          │
│  财政存款 ←── 税收/土地出让/转移支付             保证金/协定存款         │
│  同业负债 ←── 银行间拆借/同业存单                短期、利率敏感          │
│  债券融资 ←── 金融债/二级资本债/永续债           中长期、补充资本        │
│  央行投放 ←── MLF/逆回购/再贷款                  政策利率锚定            │
└──────────────────────────┬──────────────────────────────────────────────┘
                           │
                    银行内部资金池
                    （期限转换与信用转换）
                           │
┌──────────────────────────▼──────────────────────────────────────────────┐
│                          资金运用（资产端）                              │
│                                                                         │
│  对公贷款 ←── 基建/制造/房地产/平台         收益中等、风险分散          │
│  零售贷款 ←── 按揭/消费贷/信用卡/经营贷     收益较高、资产质量敏感      │
│  票据贴现 ←── 银承/商承贴现                  收益低、流动性好            │
│  债券投资 ←── 国债/地方债/信用债/金融债      收益中等、利率风险          │
│  同业资产 ←── 拆出/存放/买入返售             收益低、流动性好            │
│  非标投资 ←── 信托/资管计划                   收益高、透明度低            │
└──────────────────────────┬──────────────────────────────────────────────┘
                           │
                     收入与利润生成
                           │
┌──────────────────────────▼──────────────────────────────────────────────┐
│                          价值创造与分配                                  │
│                                                                         │
│  利息收入 = 生息资产 × 资产收益率                                        │
│  利息支出 = 计息负债 × 负债成本率                                        │
│  净利息收入 = 利息收入 - 利息支出  → [[NIM与净利差]]                     │
│  非息收入 = 手续费 + 投资收益 + 其他     → [[非息收入与财富管理]]         │
│  PPOP = 净利息收入 + 非息收入 - 业务及管理费  → [[PPOP与利润质量]]       │
│  信用成本 = 资产减值损失                  → [[新生成不良与信用成本]]      │
│  净利润 = PPOP - 信用成本 - 所得税                                      │
│  分配：分红 → 股东 / 留存 → 补充资本 → 扩张资产                          │
│       → [[资本约束]] / [[CET1与资本充足率]]                               │
└─────────────────────────────────────────────────────────────────────────┘
```

## 2. 负债端：资金从哪来

### 2.1 负债结构决定资金成本

| 负债类型 | 成本 | 稳定性 | 典型占比 | 银行差异 |
| --- | --- | --- | --- | --- |
| 活期存款 | 最低 | 中（可搬家至理财） | 30-50% | 大行 > 股份行 > 城商行 |
| 定期存款 | 中 | 高 | 30-50% | 城商行/农商行占比更高 |
| 同业负债 | 中高 | 低（利率敏感） | 5-15% | 股份行 > 大行 |
| 债券融资 | 中 | 高（锁定期） | 5-10% | 资本补充需求大的银行更高 |
| 央行借款 | 低 | 取决于政策 | 1-5% | 系统重要性银行更多 |

> 关键洞察：负债成本是银行价值链的起点，[[存款成本与负债护城河]] 决定了银行在资产定价上的从容度。大行活期存款占比高，天然具备成本优势。

### 2.2 当前趋势：[[负债定期化]]

- 活期存款向理财和定期迁移，抬升整体负债成本
- 居民储蓄意愿强但更偏好定期，企业活期增速放缓
- 银行间负债竞争从"抢规模"转向"控成本"
- 存款利率自律机制下调挂牌利率是缓解手段，但重定价需要时间

## 3. 资产端：资金往哪去

### 3.1 资产结构决定收益与风险

| 资产类型  | 收益率 | 风险     | 典型占比   | 关键变量         |
| ----- | --- | ------ | ------ | ------------ |
| 对公贷款  | 中   | 信用风险   | 35-55% | 行业投向、集中度     |
| 零售贷款  | 中高  | 周期性违约  | 15-35% | 按揭vs消费贷比例    |
| 债券投资  | 中低  | 利率风险   | 15-30% | 久期、持有至到期vs交易 |
| 同业资产  | 低   | 流动性风险  | 5-10%  | 短期资金调配       |
| 现金及央行 | 最低  | 无      | 5-10%  | 准备金、超额备付     |
| 非标及其他 | 高   | 信用+流动性 | 0-10%  | 监管压缩趋势       |

### 3.2 四条核心业务子链条

**链条一：对公信贷循环**（→ [[对公银行]]）

```text
政府/央企/地方平台/制造业/房地产
  → 项目融资/流动资金贷款/银团贷款
  → 利息收入 + 结算手续费
  → 信用风险：行业周期、政策转向、平台展期
  → 代表银行：建设银行、兴业银行、各城商行
```

- 基建和对公是中国银行业最大的资产配置方向
- 城商行的对公贷款占比往往超过 60%，深度绑定地方经济
- 风险：对公贷款的行业集中度和地方政府依赖度 → [[地方化债降低城商行尾部风险]]

**链条二：零售信贷循环**（→ [[零售银行]]）

```text
居民购房/消费/经营
  → 按揭贷款/信用卡/消费贷/经营贷
  → 利息收入（定价高） + 交叉销售手续费
  → 信用风险：经济下行时违约率上升滞后
  → 代表银行：招商银行、平安银行、常熟银行
```

- 零售贷款定价能力更强，但经济下行期 [[资产质量滞后暴露]]
- 按揭是最安全的零售资产，消费贷和信用卡波动大
- 零售转型是股份行和部分城商行的核心战略

**链条三：金融市场循环**（→ [[金融市场与同业]]）

```text
央行公开市场操作/银行间市场
  → MLF/逆回购/同业存单/债券交易
  → 投资收益 + 交易价差
  → 利率风险 + 流动性风险
  → 代表银行：兴业银行、南京银行
```

- 金融市场业务是银行管理流动性和久期的重要工具
- 利率下行周期中，债券投资浮盈可短期提振利润，但不可持续
- 同业负债依赖度高的银行，资金成本受市场利率波动影响更大

**链条四：财富管理循环**（→ [[财富管理]]）

```text
居民/企业理财与投资需求
  → 代销基金/保险/理财/信托/私人银行
  → 手续费收入（不消耗资本） + AUM规模效应
  → 声誉风险 + 销售合规风险
  → 代表银行：招商银行、宁波银行
```

- 财富管理是轻资本收入，不消耗 [[CET1与资本充足率]]
- AUM 增长可提升中收占比，对冲息差收窄压力
- 但市场波动影响客户意愿，收入稳定性弱于利息收入

## 4. 价值创造：从收入到股东回报

### 4.1 利润生成链条

```text
净利息收入（占比 70-80%）
  + 非息收入（占比 20-30%）
  - 业务及管理费（成本收入比 25-35%）
  = PPOP（税前拨备前利润）→ [[PPOP与利润质量]]
  - 信用减值损失（拨备）→ [[拨备覆盖率与拨贷比]]
  - 所得税
  = 净利润
  × 分红率（通常 25-35%）
  = 股息 → 股东
  × 留存比率
  = 内生资本 → 支撑资产扩张 → [[ROE与可持续增长]]
```

### 4.2 关键杠杆

| 杠杆 | 传导路径 | 投资影响 |
| --- | --- | ---|
| 资产收益率 | 贷款定价能力 → NIM → 净利息收入 | 零售银行定价权强 |
| 负债成本率 | 存款结构 → NIM → 净利息收入 | 大行活期占比高 |
| 信用成本 | 不良生成 → 拨备 → 净利润 | 周期敏感、滞后暴露 |
| 成本收入比 | 科技/人效 → 管理费 → PPOP | 招行/宁波较优 |
| 非息占比 | 手续费/投资收益 → 收入结构 | 降低资本消耗 |
| 分红率 | 留存 vs 分红 → 资本与回报平衡 | 高股息命题核心 |
| 杠杆率 | 资本充足率 → 资产扩张上限 | [[资本约束]] |

### 4.3 不同类型银行的价值链差异

| 维度 | 国有大行 | 股份行 | 城商行 | 农商行 |
| --- | --- | --- | --- | --- |
| 负债优势 | 活期存款、网点 | 中等，同业依赖 | 区域存款黏性 | 县域存款黏性 |
| 资产特征 | 基建+按揭为主 | 零售+对公均衡 | 深耕区域对公 | 小微+零售 |
| 定价能力 | 偏低（基准下浮） | 中高（零售溢价） | 中（区域溢价） | 高（小微溢价） |
| 非息贡献 | 中 | 较高（招行/平安） | 低 | 很低 |
| 核心价值 | 规模+低成本+分红 | 模式+效率+增长 | 区域+成长性 | 小微+本地化 |

## 5. 风险循环：价值链上的断裂点

```text
宏观下行
  → 企业经营恶化 → 对公不良上升
  → 居民收入承压 → 零售违约增加
  → 利率持续走低 → NIM收窄 → [[净息差收窄]]
  → 债券利率反弹 → 投资浮亏

风险暴露
  → 拨备计提增加 → 侵蚀利润
  → 资本消耗加快 → 制约分红和扩张 → [[资本约束]]
  → 信用评级下调 → 融资成本上升

正反馈循环（乐观期）
  → 信用扩张 → 规模增长 → 利润上升 → 资本补充 → 继续扩张

负反馈循环（悲观期）
  → 信用收缩 → 不良暴露 → 拨备侵蚀 → 资本不足 → 被动缩表
```

> 关键洞察：银行是典型的顺周期行业。理解资金循环，本质上是理解"当前处于正反馈还是负反馈的哪个阶段"。

## 7. 研究推断

- 银行的价值链不是"吸存放贷"四个字，而是"负债获取能力 + 资产定价能力 + 风险识别能力 + 资本再生产能力"的组合。
- 当 [[负债定期化]] 上升、而贷款端受 [[净息差收窄]] 压制时，资金循环仍能扩张，但股东价值创造会放缓。
- 不同类型银行在价值链上的主导环节不同：大行靠负债端，股份行靠资产端定价和非息，城商行靠区域深耕，农商行靠小微定价。理解差异后，再看 [[银行分类与可比组框架]] 才能区分优劣。
- 识别一家银行价值链的关键瓶颈：是缺负债、缺定价、缺风控、还是缺资本？不同瓶颈对应不同的投资逻辑。

## 8. 常见误区

- 只看资产端增速，不看负债质量与资本消耗——规模增长可能以利润质量恶化为代价。
- 把债券投资收益短期改善当成可持续核心竞争力——利率下行带来的一次性浮盈不可持续。
- 忽略信用成本的滞后性——当期利润好不代表资产质量好，见 [[资产质量滞后暴露]]。
- 把所有银行的价值链混为一谈——大行和农商行的盈利逻辑完全不同。
