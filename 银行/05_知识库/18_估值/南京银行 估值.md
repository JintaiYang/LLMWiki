## 4. DDM 与股息率

> 本节为 `valuation_assumption`。横向口径与 42 家同一套：见 [[A股银行DDM估值表]]、[[股息贴现模型]]。价格为最新收盘价（2026-09-24），股息率 = 全年DPS ÷ 该价格。

| 参数 | 数值 | 信息类别 | 来源 |
| --- | --- | --- | --- |
| 报告期 | 2025A | official_fact | 年报 |
| 每股净资产 BV0 | 14.66 元 | official_fact / third_party_data | stock_data 2025-12-31 |
| 加权 ROE | 12.05% | official_fact / third_party_data | 同年报 |
| 全年每股分红 D0 | 0.529 元 | official_fact | 中期+末期合计 |
| 分红率 | 30.0% | official_fact / third_party_data | 打分 F3 或 DPS/EPS |
| 最新价 / 现价PB | 11.95 元 / 0.82x | third_party_data | AkShare stock_zh_a_hist_tx 未复权日线 2026-09-24 |
| 股息率 | 4.43% | third_party_data | 全年DPS / 最新价 |
| COE | 10.5%（城商行分档） | valuation_assumption | [[股权成本COE]] |
| 终值 g | 3% | valuation_assumption | 全市场统一审慎上限 |
| D1 = D0×(1+g) | 0.545 元 | valuation_assumption | 现行分红外推 |
| DDM 现行分红 | 7.27 元（相对现价 -39.2%） | valuation_assumption | D1/(COE−g) |
| 稳态分红率 p* | 75.1% | valuation_assumption | 1−g/ROE |
| DDM 稳态 / 合理 PB | 17.69 元 / 1.21x（相对现价 48.0%） | valuation_assumption | 与 PB-ROE 等价 |
| 内生增速 | 8.4% | research_inference | ROE×(1−分红率) |
| 模型角色 | 主交叉 | research_inference | 分红率≥30% 作主交叉，否则辅助 |

白话：2025A 全年每股大约分 0.529 元。若这笔分红以后每年增长 3%、股东要求 10.5%（城商行分档），现行分红 DDM 约为 7.27 元。若终值把分红率提高到 75.1% 以刚好支撑 3% 增长，稳态价值 17.69 元，合理 PB 1.21 倍——与 PB-ROE 公式相同。对照最新价 11.95 元（2026-09-24），股息率 4.43%，现行 -39.2%、稳态 48.0%。这不是目标价。

派现拆解：2025每10股派现合计 5.291 元（06月3.062+12月2.229）
