# 股息贴现模型

> 用途：本库银行估值的 DDM 方法页。所有模型参数属于 `valuation_assumption`，不得写成公司已披露事实。分红方案、每股派息和资本充足率回到正式披露；股价、市值和表观股息率按第三方数据记录。
>
> 小白先读：[[估值公式小白释义]]（每个符号的人话）· [[股权成本COE]]（COE 不是贷款利率）。

## 0. 本页符号白话

| 符号 | 人话 |
| --- | --- |
| `P0` | 模型认为今天一股值多少钱，不是行情现价 |
| `D1` | 预计明年全年每股现金分红（中期+末期） |
| `COE` | 你买这只股票要求的年化回报，见 [[股权成本COE]] |
| `g` | 很远的未来，分红大概每年能增长百分之几 |
| `BV0` / `B0` | 现在一股对应多少账面本金 |
| `ROE` | 股东本金一年实际赚了百分之几 |
| `p` | 利润里拿出来分红的比例 |

折现：把以后才到手的分红，按你要求的回报换成今天的钱。COE 越高，同样的分红今天越不值钱。

## 1. 主题定义

- 一句话定义：股票价值等于未来全部现金股息按股权成本折现后的现值。
- 适用范围：估值；优先用于分红稳定、资本安全垫较厚、增长接近稳态的成熟银行。
- 为什么重要：银行的“债务”本身是产品，自由现金流难以定义；股东真正拿到的现金流是分红。DDM 把价值直接写成这笔现金流，并与 [[ROE与可持续增长]]、[[CET1与资本充足率]] 联动。

```text
P0 = Σ  D_t / (1 + COE)^t
```

其中 `D_t` 为第 t 年预期每股现金分红，`COE` 为股权成本。若存在明确退出时点，可把该时点的终值一并折现；终值仍须由此后股息或等价的稳态公式给出。

## 2. 官方事实 / 标准定义

- 现金分红方案、每股派息、股权登记日和发放日，以交易所公告与年报利润分配预案为准：[[05_知识库/10_来源/来源_交易所上市银行信息披露与分红规则]]。
- 分红能否持续，取决于利润、留存和监管资本缓冲，横向可比口径优先看监管总局：[[05_知识库/10_来源/来源_国家金融监督管理总局商业银行主要监管指标]]。
- 本库口径：`DDM` 适用于分红稳定、资本安全垫较高银行；全部估值参数属于 `valuation_assumption`：[[06A_银行业数据口径规范]]。
- A/H 价格、股息率和税务必须分开记录，不能把 A 股税前股息率直接当成 H 股或港股通投资者的到手回报：[[A-H银行股估值差异]]。

## 3. 第三方结构化数据

> 本页是方法页，不锁定某一交易日的个股价格。取数时按下表隔离。

| 数据项 | 用途 | 类别 | 证据等级 | 来源 |
| --- | --- | --- | --- | --- |
| 每股派息、分红率 | 构造历史 D 与分红政策 | official_fact | high | 年报 / 分红公告 |
| CET1、RWA | 判断分红是否侵蚀资本垫 | official_fact | high | 年报 / 监管口径 |
| 股价、市值、表观股息率 | 对照市场定价 | third_party_data | medium | AkShare / 行情快照 |
| 分析师预期 DPS | 只能进预期层 | external_expectation | medium | 卖方一致预期 |

口径提醒：横向 DDM 表的股息率 = 全年 DPS（中期+末期合计）÷ 最新未复权收盘价，见 [[A股银行DDM估值表]]。`dashboard` 浅层字段 `dividend_yield` 与部分 AkShare 快照仍可能是最近一次派息事件，未合计全年，招行、成都、江苏等中期分红银行按此会低估。见 [[ROE与可持续增长]]。

## 4. 外部预期

- 市场对国有大行常用“股息率对国债利差”来定价，这是 `external_expectation`，不是 DDM 本身。
- 卖方 DPS / 分红率预测可作 `D1` 的对照，但不得直接写入估值假设；估值页必须自设 `D1`、`COE`、`g` 并说明依据。

## 5. 银行为什么用 DDM，而不是企业 DCF

银行不能按一般企业的 FCFF 折现，原因不是“银行没有现金流”，而是经营现金流的经济含义不同：

| 一般企业 DCF | 银行 |
| --- | --- |
| 有息负债是资本结构 | 存款和同业负债是产品，利息支出是主营成本 |
| FCFF = EBIT(1-t)+D&A−CapEx−ΔNWC | 对应指标会把“吸收存款”当成融资流入，扭曲价值 |
| WACC 同时折现经营资产和税盾 | 监管看的是股权与总损失吸收能力，核心折现率是 `COE` |
| 终值常按 GDP 增长外推收入 | 终值必须同时满足 ROE、分红率和 CET1 / RWA 约束 |

因此本库的主内在价值是 RIM，DDM 是其现金流表述。在干净盈余（clean surplus）下，DDM 与 RIM 给出同一价值；两者分叉，通常是账面净资产未充分确认损失、分红口径不一致，或终值假设互相矛盾。

## 6. 模型族（valuation_assumption）

### 6.1 零增长 / 永续年金

适用于增长停滞、盈利和分红几乎不变的极限情形。

```text
P0 = D / COE
合理 PB = ROE / COE
```

这是 [[银行核心指标词典]] §6.1 中 `PB = ROE / r` 的来源：假设利润全部可分配且 `g = 0`。

### 6.2 Gordon 稳定增长（本库默认稳态式）

若下一年每股股息为 `D1`，此后按固定增速 `g` 永续增长，且必须 `COE > g`：

```text
P0 = D1 / (COE - g)
隐含股息率 = D1 / P0 = COE - g
```

银行经营指标改写：

```text
D1 = B0 × ROE × p
g  = ROE × (1 - p)          （无外部融资、ROE 稳定时的内生增速）
P0 = B0 × ROE × p / (COE - g)
合理 PB = ROE × p / (COE - g) = (ROE - g) / (COE - g)
```

因此 **Gordon DDM 与稳态 PB-ROE 是同一公式的两种写法**。本库个股估值页里，DDM 区块和 PB-ROE 区块必须共用同一套 `ROE / COE / g / p`，不允许一边假设高分红、另一边假设高增长。

### 6.3 两阶段 DDM（显式期 + 稳态终值）

当近 3–5 年分红率、ROE 或 RWA 增速仍在过渡，不能直接用永续 `g`：

```text
P0 = Σ_{t=1}^{n} D_t / (1+COE)^t  +  P_n / (1+COE)^n
P_n = D_{n+1} / (COE - g_n)
```

显式期每年写清：正常化 ROE、分红率、RWA / 净资产增速、是否再融资。终值期的 `g_n` 不得高于长期名义增长的审慎上限，且须与终值分红率同时成立。

### 6.4 H 模型（分红增速线性回落）

若当前股息增速 `g_s` 将在 2H 年内线性回落到稳态 `g_l`：

```text
P0 = D0 × (1+g_l) / (COE - g_l)  +  D0 × H × (g_s - g_l) / (COE - g_l)
```

适用于“高增长城商行逐步成熟、分红率逐步抬升”的过渡叙事，仍是 `valuation_assumption`，不能替代逐年分红路径。

## 7. 银行专用参数规则

### 7.1 三个输入必须同时成立

| 参数 | 经济含义 | 本库约束 |
| --- | --- | --- |
| `D1` | 下一完整会计年度每股现金分红 | 用全年合计（中期+末期）；优先由 `B0 × 正常化ROE × p` 生成，再用最近预案交叉检查 |
| `COE` | 股东要求回报 | 与 PB-ROE / RIM 共用；A 股与 H 股可因流动性、税务不同 |
| `g` | 股息长期增速 | 不得超过 `COE`，也不得超过审慎名义增长上限；不能无约束地取 `ROE×(1-p)` |

关键不等式：

```text
内生增速 g_internal = ROE × (1 - p)
若 g_internal > RWA 增速：资本垫增厚，分红更可持续
若 g_internal < RWA 增速：要么降分红，要么外部融资摊薄，DDM 的 D 路径必须改写
```

完整 CET1 判断式见词典 §6.5：还需扣 OCI、用 CET1 口径回报，而不是报表 ROE。

### 7.2 为什么不能把 `g = ROE×(1-p)` 直接塞进 Gordon

中国上市银行的报表 ROE 常在 8%–15%，分红率 25%–35%，机械内生增速可达 6%–10%。若 `COE` 取 9%–11%，`COE − g` 会过小甚至为负，模型爆炸。经济含义是：银行不可能按这个速度永续扩表而不压低 ROE、不消耗资本或不变监管环境。

处理顺序：

1. 先定终值期可持续 ROE（正常化，不是单年高点）；
2. 再定终值期 RWA / 净资产增速上限（通常低于长期名义 GDP 的审慎值，本库个股页常用 2%–4% 作 `g`）；
3. 反推终值分红率 `p = 1 − g / ROE`；
4. 若反推的 `p` 与现行分红政策差太远，说明“高分红 + 高增长 + 厚资本垫”不能同时成立，必须改 ROE 或改增长，而不是强行 Gordon。

这正是 [[银行高股息可持续性]] 的定量内核。

### 7.3 适用边界（研究推断）

| 银行画像 | DDM 角色 | 理由 |
| --- | --- | --- |
| 国有大行：分红率稳定、CET1 缓冲厚、扩表接近名义增长 | 主方法之一，与 PB-ROE / RIM 交叉 | 股东回报以现金股息为主 |
| 高股息股份行：利润波动大于大行，但政策分红意愿明确 | 主交叉检查 | 需先正常化 ROE，避免把拨备调节当年化 |
| 高 ROE、低分红、仍在扩表的城商行（如杭州银行 2025A 分红率 26.43%） | 仅辅助 | 价值更多在留存再投资，主模型用 PB-ROE / RIM，见 [[杭州银行 估值]] |
| 资本垫薄、再融资频繁、分红时有时无 | 不作为主模型 | `D` 路径不可信，先调整 BV 再谈 RIM |

## 8. 演算示例（valuation_assumption，非目标价）

> 以下数字只演示公式，不是任何银行的正式目标价，也不是市场共识。

### 8.1 稳态大行

假设：`B0 = 10.00` 元，正常化 `ROE = 10.0%`，终值 `g = 3.0%`，`COE = 9.5%`。

```text
终值分红率 p = 1 − g / ROE = 1 − 3.0%/10.0% = 70%
D1 = 10.00 × 10.0% × 70% = 0.70 元
P0 = 0.70 / (9.5% − 3.0%) = 10.77 元
合理 PB = (10.0% − 3.0%) / (9.5% − 3.0%) = 1.08x
```

若该行当前实际分红率只有 30%，却把 `g` 仍设为 3%，含义是剩余 40% 利润在增厚 CET1，而不是支撑 3% 以外的更快增长。此时正确写法是：显式期按 30% 分红逐年建模，待资本垫达到目标后再把 `p` 抬到 70%。把现行 30% 分红和 3% 永续增长同时塞进 Gordon，会系统性低估稳态派息能力。

### 8.2 高 ROE 成长行：DDM 为什么偏低

假设：`B0 = 10.00`，`ROE = 13.0%`，现行 `p = 26%`，`COE = 10.5%`。机械内生增速 `g = 13% × 74% = 9.6%`，与 `COE` 只差 0.9 个百分点，Gordon 极不稳定。

本库处理：显式 5 年按高留存、较高增长建模；终值把 `g` 压到 3%、`p` 提到 `1 − 3%/11%`（假设终值 ROE 回落到 11%）。近五年股东回报主要来自净资产增长，而不是股息，故 DDM 只作辅助，RIM / PB-ROE 作主模型。

### 8.3 `COE` 与 `g` 敏感度（D1 = 0.70 元）

| g \ COE | 8.5% | 9.5% | 10.5% |
| --- | ---: | ---: | ---: |
| 2.0% | 10.77 | 9.33 | 8.24 |
| 3.0% | 12.73 | 10.77 | 9.33 |
| 4.0% | 15.56 | 12.73 | 10.77 |

分母 `COE − g` 每收窄 1 个百分点，价值大约上升 15%–25%。这是高股息银行“利率下行重估”的模型来源，也是参数必须隔离为假设、不能写成事实的原因。

### 8.4 与市场股息率的对照，不是同一个东西

```text
表观股息率 = 最近已派 DPS / 当前股价     （third_party_data）
Gordon 隐含股息率 = COE − g             （valuation_assumption）
可持续股息率 ≈ 正常化 ROE × p / PB      （research_inference）
```

表观股息率高，可能是分红多，也可能只是股价跌了，或只统计了末期、漏了中期。DDM 问的是：按你愿意接受的 `COE`，这笔可持续股息值多少钱。

## 9. 与其他方法的关系

```text
DDM：折现股东现金
RIM：当前净资产 + 未来超额收益（ROE − COE）的折现
PB-ROE：稳态时把上面两式压成一个倍数
PE：单期利润的价格，银行仅作交叉检查
```

使用顺序建议：

1. 先判断账面净资产是否需要扣潜在损失 → 决定 RIM 的 `BV0`；
2. 再判断终值期 ROE、分红、增长能否同时成立 → 得到稳态 PB 或 Gordon `P0`；
3. 若分红稳定且资本垫厚，把 DDM 作为主交叉；若分红低、增长高，以 RIM / PB-ROE 为主，DDM 只检查显式期现金回报；
4. PE 只用于核对盈利预测有没有明显离谱。

3–5 年股东回报拆解与 DDM 一致：

```text
总回报 ≈ 股息回报 + 净资产增长 + 估值变化（PB 变动）− 资本补充摊薄
```

DDM 把后三项都折进价格；回报拆解把它们按持有期分开看。两套数字应能对上，对不上就说明 `g`、分红率或再融资假设不一致。

## 10. 研究解释：常见误区

- 把去年 DPS 直接当 `D1`。`D1` 是预期下一完整年度分红，需考虑中期分红、分红率政策变化和利润正常化。
- 把高表观股息率当成低估。低 PB 会放大 `ROE × p / PB`；若可持续 ROE 正在下台阶，高股息可能是价值陷阱。
- `g` 与 `p` 独立拍脑袋。二者由 `g = ROE × (1-p)` 锁死，再叠加 CET1 / RWA 约束。
- A/H 混用股息率。港股通红利税、汇率和流动性会改变到手 `COE` 与净股息，必须分市场建模。
- 忽略再融资。配股、可转债转股会摊薄每股股息，DDM 必须把新股数写进 `D_t`。
- 用报告期 ROE 替代正常化 ROE。少提拨备、投资收益大年和单季年化，都会抬高 `D1`。
- 认为 DDM 与 PB-ROE 可以给出两套互斥目标价。稳态下它们必须一致；不一致就回头查参数。

## 11. 本库个股估值页的填写规则

各银行估值页「DDM 与股息率」一节，最低填写：

| 字段 | 信息类别 | 要求 |
| --- | --- | --- |
| 预期每股分红 `D1` | valuation_assumption | 写清由哪一年 BV、正常化 ROE、分红率推出；注明是否含中期 |
| `COE` | valuation_assumption | 与 PB-ROE / RIM 同一数值 |
| 股息增长率 `g` | valuation_assumption | 终值期数值；若显式期不同，改用两阶段并附表 |
| DDM 内在价值 | valuation_assumption | 由公式推导，标注情景 |
| 当前股息率 | third_party_data 或 official_fact | 价格日期、税前/税后、A 或 H |

未完成资本垫、正常化 ROE 或分红全年口径核验前，内在价值保持 `待计算`，不输出目标价或上涨空间。杭州银行案例见 [[杭州银行 估值]]：分红不是主锚时，应明确写“DDM 仅作辅助”。
