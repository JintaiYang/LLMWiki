# 银行估值方法体系

> 用途：建立统一的银行估值方法框架，明确各方法的适用范围、关键参数和信息类别隔离规则。所有估值参数都属于 `valuation_assumption`。

## 1. PB-ROE 框架

> 信息类别：`valuation_assumption`

稳定期近似：

```text
P/B = (ROE - g) / (COE - g)
```

### 适用场景

- 同业比较与估值分位
- 解释估值溢价的来源
- 反推隐含长期 ROE

### 关键参数

| 参数 | 含义 | 数据来源 | 信息类别 |
| --- | --- | --- | --- |
| ROE | 正常化净资产收益率 | 正式年报 / AkShare | official_fact / third_party_data |
| COE | 股权成本率 | CAPM 或主观设定 | valuation_assumption；白话见 [[股权成本COE]] |
| g | 终值增长率 | 研究推断 | valuation_assumption |
| BV | 每股净资产 | 正式年报 | official_fact |

### 注意事项

- 采用正常化 ROE，不直接外推单期 ROE
- PB 必须同步标注所对应的账面净资产期末时点
- A/H 银行需分别计算 PB

## 2. RIM（剩余收益模型）

> 信息类别：`valuation_assumption`。完整定义、BV0 调整规则和与 DDM 的等价证明见 [[剩余收益模型]]。

```text
RI_t = (ROE_t − COE) × BV_(t-1)
V0   = BV0 + Σ[RI_t / (1+COE)^t] + 终值
稳态 PB = (ROE − g) / (COE − g)
```

RIM 估的是：今天的净资产，加上未来超额收益（利润减去资本租金）的折现。`ROE = COE` 时只值账面；`ROE > COE` 才配溢价。

### 适用场景

- 本库主内在价值模型
- 将银行价值拆为当前净资产和未来超额收益
- 分红低、留存再投资为主时，比 DDM 更稳

### 前提条件

- 建模前必须评估账面资产是否充分确认潜在损失
- 若账面净资产高估（如潜在不良未充分拨备），需先调整 BV0
- `COE`、终值 `g` 和分红率须与 DDM / PB-ROE 同一套参数

### 关键参数

| 参数 | 含义 | 信息类别 |
| --- | --- | --- |
| BV0 | 当前每股净资产；必要时下调 | official_fact / valuation_assumption |
| ROE_t | 预测期各年正常化 ROE | valuation_assumption |
| COE | 股权成本率 | valuation_assumption |
| 终值增长率 | 长期稳定增长率，或 ROE 向 COE 消退 | valuation_assumption |

## 3. DDM 与股息率

> 信息类别：`valuation_assumption`。完整推导、银行参数约束和个股页填写规则见 [[股息贴现模型]]。

```text
P0 = D1 / (COE - g)
D1 = B0 × ROE × p
合理 PB = (ROE - g) / (COE - g)
```

稳态下 DDM 与 PB-ROE 是同一公式。`g` 不得无约束地取 `ROE×(1-p)`，必须同时满足 `COE > g`、CET1/RWA 约束和终值分红率。42 家现行/稳态结果见 [[A股银行DDM估值表]]。

### 适用场景

- 分红稳定、资本安全垫较高的成熟银行：可作为主交叉
- 高 ROE、低分红、仍在扩表的银行：仅辅助，主模型用 PB-ROE / RIM
- 与国债、信用债、A/H 股息率和自身历史分位比较

### 关键参数

| 参数 | 含义 | 信息类别 |
| --- | --- | --- |
| D1 | 预期下一完整年度每股分红（含中期） | valuation_assumption |
| COE | 股权成本率，须与 PB-ROE / RIM 共用 | valuation_assumption |
| g | 股息长期增长率（终值期） | valuation_assumption |
| p | 分红率，与 g、ROE 同时成立 | valuation_assumption |

## 4. PE 辅助

> 仅用于阶段性盈利预期和历史区间交叉检查。拨备、信用成本及投资收益可能显著扭曲单期 PE。

## 5. 三情景与回报拆解

### 三情景设定

每家重点银行设置悲观、基准和乐观情景，包含：

- 资产增速
- NIM
- 非息增速
- 信用成本
- 正常化 ROE
- 分红率
- COE
- 终值增长率

### 3-5 年回报拆解

```text
3-5 年总回报
  约等于 盈利与净资产增长
  加上   股息回报
  加上   估值变化
  减去   资本补充摊薄
```

## 6. 估值隔离规则

- 估值参数属于 `valuation_assumption`，不得写成公司已披露事实
- 市场一致预期属于 `external_expectation`，不得写入估值假设
- 正式披露的 PB/PE/股息率属于 `third_party_data` 或 `official_fact`
- 情景分析结果由假设推导，必须标注假设来源
