# 剩余收益模型

> 用途：本库银行估值的 RIM 方法页。RIM 是主内在价值框架。所有模型参数属于 `valuation_assumption`；每股净资产、拨备和不良回到正式披露，不得把模型输出写成公司已披露事实。
>
> 小白先读：[[估值公式小白释义]]（每个符号的人话）· [[股权成本COE]]（COE 是及格线，不是贷款利率）。

## 0. 本页符号白话

| 符号 | 人话 |
| --- | --- |
| `RIM` | Residual Income Model，剩余收益模型。价值 = 今天的账面本金 + 未来多赚出来的利润折到今天 |
| `BV0` | 现在一股对应多少账面本金；坏账没提够时要先下调 |
| `ROE` | 股东本金一年实际赚了百分之几 |
| `COE` | 你要求这笔本金至少赚百分之几，见 [[股权成本COE]] |
| `RI` | 剩余收益 = 实际利润 − 你要求的“资本租金” |
| `g` | 很远的未来，本金或超额收益大概每年能增长百分之几 |
| `V0` | 模型认为今天一股值多少钱，不是行情现价 |

`ROE > COE` 才配溢价（PB>1）；`ROE < COE` 应折价（PB<1）。低 PB 不一定等于便宜。

## 1. 主题定义

- 一句话定义：`RIM`（Residual Income Model）是剩余收益模型。银行股价值 = **今天的净资产** + **未来超额收益的折现**。
- 适用范围：估值；本库将其作为主内在价值模型，尤其适合资本约束强、分红不稳定或留存再投资为主的银行。
- 为什么重要：银行真正稀缺的是股权资本。RIM 直接问：这块账面净资产能不能持续赚出超过股东要求的回报。

剩余收益（residual income）不是会计科目，而是估值构造：

```text
RI_t = 净利润_t − COE × BV_(t-1)
     = (ROE_t − COE) × BV_(t-1)
```

`COE × BV_(t-1)` 是股东对上期净资产要求的“资本租金”。利润刚好覆盖这笔租金时，剩余收益为零，股票只值账面净资产；多赚的部分才构成溢价，少赚则应折价。

## 2. 官方事实 / 标准定义

- 每股净资产、归母净利润、分红和股本变化以年报和交易所公告为准：[[05_知识库/10_来源/来源_交易所上市银行信息披露与分红规则]]。
- 资本是否够用、账面资产是否可能高估，要对照监管资本与资产质量口径：[[05_知识库/10_来源/来源_国家金融监督管理总局商业银行主要监管指标]]。
- 本库口径：RIM 作为主内在价值框架时，必须明确 `ROE`、`COE`、终值增长率和净资产基数；全部估值参数属于 `valuation_assumption`：[[06A_银行业数据口径规范]]。

RIM 本身不是监管指标，也不是报表附注名称。个股估值页里的“RIM 内在价值”一律是假设推导，不是官方披露。

## 3. 模型公式（valuation_assumption）

### 3.1 一般式

```text
V0 = BV0
   + Σ_{t=1}^{n}  (ROE_t − COE) × BV_(t-1) / (1 + COE)^t
   + 终值 / (1 + COE)^n
```

| 符号 | 含义 | 信息类别 |
| --- | --- | --- |
| `BV0` | 当前每股净资产；若潜在损失未充分拨备，应先下调 | official_fact，调整后进入 valuation_assumption |
| `ROE_t` | 预测期各年正常化 ROE | valuation_assumption |
| `BV_(t-1)` | 上期末每股净资产，由留存和再融资滚动 | 由假设推导 |
| `COE` | 股权成本，须与 DDM / PB-ROE 共用 | valuation_assumption |
| 终值 | 显式期之后剩余收益的现值 | valuation_assumption |

三个直接推论：

| 关系 | 含义 |
| --- | --- |
| `ROE = COE` | 剩余收益为零，`V0 = BV0`，合理 PB = 1 |
| `ROE > COE` | 创造经济利润，合理 PB > 1 |
| `ROE < COE` | 消耗股东价值，合理 PB < 1 |

这就是银行看 PB 不看 PE 的模型基础：价格首先是对净资产的溢价或折价，溢价厚度由 `ROE − COE` 能维持多久决定。

### 3.2 稳态式（与 PB-ROE、DDM 等价）

若正常化 ROE 与净资产增速 `g` 长期不变，且 `COE > g`：

```text
V0 = BV0 + (ROE − COE) × BV0 / (COE − g)
   = BV0 × (ROE − g) / (COE − g)
合理 PB = (ROE − g) / (COE − g)
```

与 [[股息贴现模型]] 的 Gordon 式相同。干净盈余（本期净资产变动 = 净利润 − 分红，忽略 OCI 等）下，RIM 与 DDM 给出同一价值，只是拆法不同：

```text
DDM：价值来自股东拿到的现金
RIM：价值来自已经进账的净资产 + 还没进账的超额利润
```

### 3.3 两阶段 RIM

近 3–5 年 ROE、分红率或 RWA 仍在过渡时，不要直接用永续式。显式期逐年滚动：

```text
BV_t = BV_(t-1) × [1 + ROE_t × (1 − p_t)] − 每股再融资摊薄
RI_t = (ROE_t − COE) × BV_(t-1)
```

终值常用两种收口，必须写明选了哪一种：

| 终值假设 | 公式含义 | 适用 |
| --- | --- | --- |
| 剩余收益永续增长 | `TV = RI_(n+1) / (COE − g)` | ROE 能长期高于 COE |
| ROE 向 COE 消退 | 终值溢价趋于 0，`V_n → BV_n` | 竞争优势难以永续 |

银行终值 `g` 的约束与 DDM 相同：不得超过 `COE`，也不得超过审慎名义增长；并与终值分红率、CET1 / RWA 同时成立。见 [[ROE与可持续增长]]。

## 4. 银行为什么把 RIM 当主模型

| 一般企业 DCF / 单纯 DDM | 银行 RIM |
| --- | --- |
| 要定义自由现金流或稳定分红 | 直接用净利润和净资产，银行这两个数更可观察 |
| 分红低、留存高时 DDM 对近端现金不敏感 | 留存会抬高 `BV`，超额收益仍被计入 |
| 不自动检查账面是否虚高 | 建模前必须审视 `BV0` 是否扣过潜在不良 |
| 价值与资本约束脱节 | 股权账面是监管和经营的硬约束 |

因此：

- 分红稳定、资本垫厚的成熟大行：RIM、DDM、PB-ROE 三套应能对上；
- 高 ROE、低分红、仍在扩表的城商行：以 RIM / PB-ROE 为主，DDM 只检查显式期现金回报；
- 资本垫薄、拨备不足、再融资频繁：先调整 `BV0`，再跑 RIM；未调整的账面不能当内在价值锚。

## 5. `BV0` 调整规则（本库硬约束）

建模前必须评估账面资产是否充分确认潜在损失。常见下调项属于 `research_inference` / `valuation_assumption`，要单独列示，不能改写年报数字本身：

| 检查 | 若成立 | 对 RIM 的处理 |
| --- | --- | --- |
| 不良认定偏松、逾期与不良剪刀差大 | 未来信用成本会补提 | 下调有效 `BV0`，或压低显式期 ROE |
| 拨备覆盖率 / 拨贷比过薄 | 利润和净资产被前置 | 同上 |
| 关注类、重组贷款占比高 | 迁徙后侵蚀资本 | 情景中单列损失路径 |
| 永续债、优先股计入净资产 | 普通股 ROE 被稀释 | 用归母普通股权益，不要用全部净资产 |
| OCI / 公允价值未实现亏损 | 利率上行年份资本被吃掉 | 滚动 `BV` 时写入，而不是只看净利润 |

未做上述检查就把报表 `BV0` 代入公式，RIM 会把“虚高的账面”当成已经属于股东的价值。

## 6. 演算示例（valuation_assumption，非目标价）

> 以下数字只演示公式，不是任何银行的正式目标价。

假设：`BV0 = 10.00` 元，正常化 `ROE = 12.0%`，`COE = 10.0%`，终值 `g = 3.0%`。

```text
每年超额收益率 = 12.0% − 10.0% = 2.0%
稳态剩余收益（相对期初账面）= 2.0% × 10.00 = 0.20 元
V0 = 10.00 + 0.20 / (10.0% − 3.0%) = 10.00 + 2.86 = 12.86 元
合理 PB = (12.0% − 3.0%) / (10.0% − 3.0%) = 1.29x
```

同参数下 DDM：终值分红率 `p = 1 − g/ROE = 75%`，`D1 = 10 × 12% × 75% = 0.90`，`P0 = 0.90 / (10% − 3%) = 12.86`。两边必须相等。

若把 ROE 改成 8.0%、其余不变：

```text
合理 PB = (8.0% − 3.0%) / (10.0% − 3.0%) = 0.71x
V0 = 7.14 元
```

ROE 低于 COE 时，RIM 给出的就是折价，不是“便宜”。低 PB 可能只是在给低盈利能力定价。

## 7. 与 DDM、PB-ROE 怎么选

```text
先问账面是否实在  →  调整 BV0，这是 RIM 的起点
再问超额收益能维持多久  →  显式期 ROE 路径 + 终值是永续溢价还是消退
然后用 DDM 核对  →  同一套 ROE / p / g / COE 必须得到同一 V0
最后用 PB-ROE 做横比  →  把 V0 / BV0 放到同业和历史分位上
```

3–5 年回报拆解与 RIM 一致：净资产增长对应 `BV` 滚动，股息对应干净盈余里拿走的部分，估值变化对应市场 PB 向模型 PB 收敛，再融资摊薄对应 `BV_t` 被新股稀释。

## 8. 常见误区

- 把 RIM 理解成“剩余流动性”或某个监管指标。它只是估值模型。
- 用单年报告 ROE 当永续 ROE。少提拨备、投资收益大年会让剩余收益虚高。
- 不调 `BV0` 就给资产质量差的银行算溢价。
- 显式期假设高增长，终值仍让 ROE 永续高于 COE，造成重复计算。
- 与 DDM 使用两套互相矛盾的分红率和 `g`。
- 把优先股 / 永续债权益算进普通股 `BV0`，高估归母价值。
- 把模型 `V0` 写成“目标价”或“上涨空间”，尤其在价格与 PB 尚未用可复核快照更新时。

## 9. 本库个股估值页的填写规则

各银行估值页「RIM 内在价值」一节，最低填写：

| 字段 | 信息类别 | 要求 |
| --- | --- | --- |
| `BV0`（每股净资产） | official_fact | 写明报告期；若调整，单列调整额与理由 |
| 预测期 ROE 路径 | valuation_assumption | 至少基准情景；注明是否正常化 |
| `COE` | valuation_assumption | 与 PB-ROE / DDM 同一数值 |
| 终值增长率 / 终值规则 | valuation_assumption | 永续增长或 ROE 消退，二选一写清 |
| 内在价值 | valuation_assumption | 由公式推导，标注情景 |

未完成 `BV0` 质量检查、正常化 ROE 或与 DDM 参数对齐前，内在价值保持 `待计算`。
