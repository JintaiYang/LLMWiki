# 银行核心指标词典

> 本词典基于 [[05_知识库/10_来源/来源_手把手教你读财报2]]（唐朝著，《手把手教你读财报2》，2018年）逐章梳理，结合巴塞尔协议III和金融监管总局现行口径，将银行投研需要关注的核心指标分为六大类，逐个给出公式、通俗解释、关注要点和对照案例。

## 一、盈利能力指标

银行利润表可以简化为一行公式：

> **净利润 = (利息净收入 + 非息收入) - 管理费 - 拨备 - 税**

盈利能力指标就是用来拆解这条公式每一项的效率。

---

### 1.1 NIM（净息差）— 银行最重要的盈利指标

| 属性 | 内容 |
| --- | --- |
| **公式** | NIM = 利息净收入 / 平均生息资产 |
| **优秀标准** | >2.0%（国有大行）/ >2.5%（股份行）/ >3.0%（优秀零售银行） |
| **数据来源** | 年报"利润表"附注 + "生息资产/计息负债平均余额表" |
| **报告频率** | 半年报、年报披露；季报可从利息净收入/总资产粗算 |

**通俗解释**：

NIM 回答一个问题——“银行每拿出去100块钱生息，扣掉资金成本后净赚了多少利息？”它衡量的是“资金运用效率”。

**为什么NIM比净利差更重要

银行的生息资产由两部分资金支撑：**计息负债（要付利息）+ 自有资本金（不付利息）**。自有资本金也拿去放贷生息了，但银行不需要为它付利息——这块"免费的钱"就是NIM高于净利差的原因。

一个数值例子看懂：假设一家迷你银行——放贷110亿（收益率4%），其中100亿来自存款（成本率2%），10亿是自有资本金（0%）。

- 利息收入 = 110 × 4% = 4.4亿；利息支出 = 100 × 2% = 2.0亿
- 净利差 = 4% - 2% = **2.00%**
- NIM = (4.4 - 2.0) / 110 = **2.18%** > 净利差

原因拆解：自有资本金那10亿也在按4%生息（每年贡献0.4亿），却一分利息都不用付。净利差的公式（收益率-成本率）隐含假设"所有资产都是借来的"，察觉不到这块免费的钱；而NIM的分母是生息资产110亿（含资本金），分子却没多付利息——NIM自然被垫高。

一句话总结：**净利差假设所有资产都是借来的；NIM承认有一部分资产是股东白给的——这部分只赚不付，把NIM垫高了**。所以NIM更准确反映"整体资金的净回报率"。

**NIM影响因素全景分析**： [[银行业NIM影响因素全景分析]]

**关注要点**：

- **趋势比绝对值重要**：NIM 持续下降（如从2.5%降到1.8%）意味着利差收窄，盈利能力在恶化。2023-2025年LPR多次下调，全行业NIM普遍承压。
- **横向对比要分类型**：国有大行NIM低（负债中准备金占比高、收益率低），股份行和城商行NIM高（零售贷款占比高、收益率高）。不同类型银行直接比NIM不公平，应与同类行比。
- **NIM下降但利润增长**：可能是"以量补价"——虽然单位利差收窄，但资产规模扩张更快，总利息净收入仍在增长。但要警惕"以量补价"走到尽头——规模增速不可能永远快于NIM下降。

**对照案例**：

| 银行 | 类型 | ROE | 推断NIM水平 | 含义 |
| --- | --- | --- | --- | --- |
| 工商银行 | 国有大行 | 9.45% | 偏低（~1.5%-1.8%） | 大行准备金占比高拖累NIM |
| 招商银行 | 股份行 | 13.44% | 偏高（~2.0%-2.2%） | 零售贷款+活期存款双优势 |

---

### 1.2 净利差（Spread）

| 属性 | 内容 |
| --- | --- |
| **公式** | 净利差 = 生息资产平均收益率 - 计息负债平均成本率 |
| **优秀标准** | >2.0% |
| **数据来源** | 年报"平均余额及利率表" |

**通俗解释**：

净利差回答的问题是——“银行买入资金的成本和卖出资金的收益之间的差价是多少？”它不考虑资金规模差异，纯粹看“买入价和卖出价的差额”。

**与NIM的区别**：

- 净利差 = 收益率 - 成本率（两个比率相减）
- NIM = 净利息收入 / 平均生息资产（一个比率）
- NIM考虑了"银行有自有资本金不需要付利息"这一事实，所以NIM通常略高于净利差

**关注要点**：

- 拆开看收益率和成本率各自的变化方向：收益率下降+成本率下降→可能是降息周期中存贷同步下降；收益率下降+成本率上升→最危险，息差被两头挤压
- 成本率的驱动力：存款结构（活期多→成本低）、同业负债占比（NCD多→成本高）、市场利率环境

---

### 1.3 ROE（净资产收益率）

| 属性 | 内容 |
| --- | --- |
| **公式** | ROE = 归母净利润 / 平均归母净资产 |
| **优秀标准** | >12%（优秀）/ >10%（及格）/ <8%（偏弱） |
| **数据来源** | 年报"主要财务指标" |

**通俗解释**：

ROE 回答的问题是——“股东每投入100块钱，银行一年能赚回多少利润？”

**银行的ROE为什么比一般企业低？**

银行是高杠杆行业（杠杆12-20倍），即使ROA只有1%左右，乘以杠杆后ROE也能到12%+。但高杠杆也意味着风险放大——资产端只要亏损0.5%，净资产就缩水6%-10%。所以银行ROE的"质量"需要结合资产质量和拨备来综合判断。

**关注要点**：

- **拨备前ROE vs 报告ROE**：拨备前ROE = (净利润+信用减值损失) / 平均净资产。如果拨备前ROE=18%但报告ROE=12%，6个百分点被拨备"吃掉了"——可能是真实风险，也可能是藏利润
- **ROE的可持续性**：靠高NIM和高中收驱动的ROE更可持续；靠低拨备和高杠杆驱动的ROE是"虚高"
- **ROE vs 内生增长率**：内生增长率 ≈  净利润 × (1 - 分红率) / 期初资本 = ROE × (1 - 分红率) 。ROE=13%、分红率30%→内生增长率≈9%，如果RWA增速≤9%就不需要外部融资


**对照案例**：

| 银行 | ROE | 分红率（假设） | 内生增长率 | 判断 |
| --- | --- | --- | --- | --- |
| 工商银行 | 9.45% | 30% | ~6.6% | 大行RWA增速低，可内生 |
| 招商银行 | 13.44% | 30% | ~9.4% | 资本效率高，内生能力更强 |

---

### 1.4 ROA（总资产收益率）

| 属性 | 内容 |
| --- | --- |
| **公式** | ROA = 净利润 / 平均总资产 |
| **优秀标准** | >0.8%（优秀）/ >0.6%（及格） |
| **数据来源** | 年报"主要财务指标" |

**通俗解释**：

ROA 回答的问题是——"银行每100块钱的总资产，一年能赚多少净利润？"

ROE = ROA × 杠杆倍数。ROA 剥离了杠杆效应，直接看"资产本身的赚钱效率"。两家银行ROE都是13%，但A行ROA=1.0%杠杆13倍、B行ROA=0.8%杠杆16倍——A行用更少的杠杆达到了同样的回报，质量更高。

**关注要点**：

- ROA与ROE的差距反映杠杆水平：ROE/ROA = 杠杆倍数。杠杆越高，同样的资产亏损对净资产的冲击越大
- 国有大行ROA偏低（0.7%-0.8%），因为准备金等低收益资产占比高；优秀股份行ROA可达1.0%-1.2%

---

### 1.5 成本收入比（CIR）

| 属性 | 内容 |
| --- | --- |
| **公式** | CIR = 业务及管理费 / 营业收入 |
| **优秀标准** | <30%（优秀）/ <35%（及格）/ >40%（偏高） |
| **数据来源** | 年报"主要财务指标" |

**通俗解释**：

CIR 回答的问题是——“银行每赚100块钱收入，花了多少运营成本？”

**关注要点**：

- CIR逐年上升→收入增长跟不上成本膨胀，可能是组织臃肿或数字化转型效果不佳
- CIR突然大幅下降→可能是裁员或缩减投入，需警惕是否影响长期竞争力
- 不同类型银行CIR差异大：大行网点多人员多CIR偏高（30%-35%），互联网化程度高的银行CIR可低至25%

---

### 1.6 非息收入占比与中收

| 属性 | 内容 |
| --- | --- |
| **公式** | 非息收入占比 = 非息收入 / 营业收入 |
| **优秀标准** | >30%（优秀）/ >20%（及格） |
| **数据来源** | 年报利润表"手续费及佣金净收入"+"投资收益"+"公允价值变动收益"等 |

**先搞懂"中收"这个词**：

**中收 = 中间业务收入**，是"手续费及佣金净收入"的俗称。在银行利润表里：

```
营业收入 = 利息净收入 + 非利息收入
                              ├── 手续费及佣金净收入（= 中收）★
                              ├── 投资收益
                              ├── 公允价值变动损益
                              ├── 汇兑损益
                              └── 其他业务收入
```

严格说"中收"指**手续费及佣金净收入**这一项；口语中有时也把整个非息收入笼统称为"中收"，但准确口径应以利润表科目为准。

**为什么叫"中间"业务？**

银行的业务分三类，中收卡在"中间"位置：

| 业务类型 | 银行扮演的角色 | 赚什么钱 | 举例 |
| --- | --- | --- | --- |
| 资产业务 | 资金的**出借方** | 利差 | 放贷款 |
| 负债业务 | 资金的**借入方** | 服务于吸储 | 吸收存款 |
| 中间业务 | 资金的**中间人/过手方** | 手续费、佣金 | 代销基金、结算、托管 |

关键特征：**银行不动用（或不直接动用）自己的资金、不承担信用风险，只“过一手”提供服务，收一笔服务费**。钱不是银行的钱，银行只在资金的流动中当“中介”——所以叫“中间业务”，收入叫“中收”。

**通俗解释**：

非息收入回答的问题是——“银行有多少收入不是靠‘利差’赚的？”中收是更“轻”的商业模式。

**为什么银行都拼命做中收？**

| 维度 | 利息收入 | 中收 |
| --- | --- | --- |
| 是否消耗资本 | 消耗（放贷占用CET1） | **基本不消耗**（轻资本） |
| 是否承担信用风险 | 承担（贷款可能变坏账） | **不承担**（钱不是银行的） |
| 受NIM收窄影响 | 直接冲击 | **免疫**（不靠利差） |
| 周期波动 | 受经济周期影响大 | 相对稳定 |

当前行业NIM持续收窄背景下，中收是银行的"第二增长曲线"——不用多烧资本就能多赚钱。这正是招商银行非息占比约37%（行业领先）被市场给高估值溢价的核心原因。

**关注要点**：

- **真中收 vs 假中收**：
  - 真中收：银行卡手续费、代理销售手续费、托管费、结算清算费、投行费——不依赖信用投放、不承担违约风险
  - 假中收：贷款承诺费、信贷额度承诺费——本质是信用业务的附加收费，经济下行时仍会萎缩
- **投资收益波动性**：部分银行非息收入中"投资收益"和"公允价值变动收益"占比高，这部分受市场波动影响大，不是稳定收入
- 招商银行非息占比约37%（行业领先），主要来自财富管理手续费和银行卡手续费

**相关指标**：

| 指标 | 公式 | 参考标准 |
| --- | --- | --- |
| 中收占比 | 手续费及佣金净收入 ÷ 营业收入 | >30%为优秀 |
| 非息收入占比 | (营业收入 - 利息净收入) ÷ 营业收入 | 招行~37%行业领先 |
| 中收增速 | 手续费及佣金净收入同比 | 与财富管理景气度挂钩 |

**一句话总结**：**中收 = 银行不动用自己的钱、不担信用风险，靠"当资金的中介/过手方"收的服务费**。它轻资本、抗息差收窄——中收占比越高，商业模式的"含金量"越高。

### 1.7 PPOP增速（拨备前利润增速）

| 属性 | 内容 |
| --- | --- |
| **公式** | PPOP = 营业收入 - 业务及管理费；PPOP增速 = PPOP同比增速 |
| **优秀标准** | 与净利润增速方向一致 |
| **数据来源** | 年报利润表 |

**通俗解释**：

PPOP 回答的问题是——“去掉拨备这个‘水龙头’后，银行的真实经营利润增长了多少？”如果只看净利润增速，会被拨备计提的增减误导——利润增速慢可能是经营变差，也可能是主动多提拨备。

**关注要点**：

- PPOP增速 > 净利润增速→拨备在"吃利润"（多提拨备，可能是藏利润或前瞻性应对风险）
- PPOP增速 < 净利润增速→拨备在"释放利润"（少提拨备维持利润，盈利质量在恶化）
- PPOP增速和净利润增速同向同步→盈利质量相对真实

## 二、资产质量指标

银行最大的风险不是流动性，不是资本不够，而是**贷款质量恶化**——一笔贷款变成坏账，银行可能损失全部本金。资产质量指标就是用来判断"贷款会不会烂、烂了多少、藏了多少"。

---

### 2.1 不良率

| 属性 | 内容 |
| --- | --- |
| **公式** | 不良率 = (次级+可疑+损失类贷款) / 贷款总额 |
| **优秀标准** | <1.0%（优秀）/ <1.5%（及格）/ >2.0%（偏弱） |
| **数据来源** | 年报"贷款五级分类分布表" |

**通俗解释**：

不良率回答的问题是——“银行放了100块钱贷款，有多少已经‘确认烂了’？”注意这只是“确认烂了的”——可能还有些有潜在风险的（关注类）尚未计入，未来也可能变烂。

**五级分类对照**：

| 分类 | 预计损失率 | 专项拨备比例 |
| --- | --- | --- |
| 正常 | 0% | 1%-2% |
| 关注 | 0%-5% | 2%-5% |
| 次级 | 30%-50% | 30%-50% |
| 可疑 | 50%-90% | 50%-90% |
| 损失 | 90%-100% | 100% |

**关注要点**：

- 不良率是"后视镜"——反映的是已经确认的不良，银行有一定自由裁量权
- 不良率下降可能是真实改善，也可能是加大核销把不良"洗掉"了——必须结合新生成不良率看
- 不良率的"结构"比总量更重要：对公不良 vs 零售不良、房地产行业不良 vs 其他行业不良

---

### 2.2 关注类比例

| 属性 | 内容 |
| --- | --- |
| **公式** | 关注类比例 = 关注类贷款 / 贷款总额 |
| **优秀标准** | <2.0%（优秀）/ <3.0%（及格） |
| **数据来源** | 年报"贷款五级分类分布表" |

**通俗解释**：

关注类比例回答的问题是——"有多少贷款'快烂了'但还没被确认为不良？"

关注类是不良的"蓄水池"——关注类大幅上升，未来不良率大概率也会上升。

**关注要点**：

- 关注类→不良的"迁移率"：看上期关注类有多少在本期变成了不良
- 关注类比例上升+不良率持平→"不良蓄水池在蓄水"，未来不良率大概率上升
- 关注类比例下降+不良率下降→资产质量真实改善

---

### 2.3 逾期90天以上比例

| 属性 | 内容 |
| --- | --- |
| **公式** | 逾期90天以上比例 = 逾期90天以上贷款 / 贷款总额 |
| **优秀标准** | <1.0%（优秀） |
| **数据来源** | 年报"逾期贷款期限分布表" |

**通俗解释**：

逾期90天以上比例回答的问题是——"有多少贷款已经客观违约超过3个月了？"

这是"前照灯"——逾期是客观事实（合同约定还款日过了没还），不依赖银行的主观认定。而不良率依赖银行的五级分类认定标准，有调节空间。

**关注要点**：

- 逾期90天以上比例 > 不良率→银行在"藏不良"（有逾期但没认定为不良）
- 逾期90天以上比例 < 不良率→银行认定标准严格（甚至把未逾期90天的也认定为不良）

---

### 2.4 不良/逾期90天剪刀差

| 属性 | 内容 |
| --- | --- |
| **公式** | 剪刀差 = 不良贷款余额 / 逾期90天以上贷款余额 |
| **优秀标准** | >100%（认定严格）/ <80%（认定宽松） |
| **数据来源** | 年报五级分类表 + 逾期分布表 |

**通俗解释**：

剪刀差回答的问题是——“银行对逾期贷款的认定标准严格还是宽松？”逾期是客观事实（还款日过了没还），不良是银行的主观认定，两者一比就暴露认定尺度。

**关注要点**：

- 比值 >100%：银行把所有逾期90天以上的都认定为不良，甚至更严格——拨备扎实，可信度高
- 比值 <100%：有部分逾期90天以上的贷款没被认定为不良——不良率被低估了
- 2018年监管要求"逾期90天以上必须入不良"后，大部分银行已达标，但仍需关注

---

### 2.5 拨备覆盖率

| 属性 | 内容 |
| --- | --- |
| **公式** | 拨备覆盖率 = 贷款减值准备余额 / 不良贷款余额 |
| **监管要求** | 120%-150% |
| **优秀标准** | >200%（充足）/ >300%（厚实）/ <150%（偏薄） |
| **数据来源** | 年报"贷款减值准备明细表" |

**通俗解释**：

拨备覆盖率回答的问题是——“如果所有不良贷款全部变成坏账，银行有几倍的准备金来覆盖？”倍数越高，吸收损失的能力越强，“藏利润”的空间也越大。

**关注要点**：

- 拨备覆盖率下降 + 净利润增长→银行在"释放拨备"维持利润，盈利质量在恶化
- 拨备覆盖率上升 + 净利润增速放缓→银行在"增厚拨备"藏利润，或前瞻性应对风险
- 招商银行拨备覆盖率400%+，有巨大的利润释放空间；国有大行约200%+，缓冲适中
- 拨备覆盖率和不良率有数学关系：拨备覆盖率 = 拨贷比 / 不良率

---

### 2.6 拨贷比（贷款拨备率）

| 属性 | 内容 |
| --- | --- |
| **公式** | 拨贷比 = 贷款减值准备余额 / 贷款总额 |
| **监管要求** | 1.5%-2.5% |
| **优秀标准** | >3.0%（充足） |
| **数据来源** | 年报"贷款减值准备明细表" |

**通俗解释**：

拨贷比回答的问题是——“银行在所有贷款中提了多少比例的准备金？”

**与拨备覆盖率的区别**：

- 拨备覆盖率的分母是"不良贷款"——看对已确认不良的覆盖倍数
- 拨贷比的分母是"全部贷款"——看整体贷款的拨备厚度
- 两者关系：拨备覆盖率 = 拨贷比 / 不良率（知道两个就能算第三个）

**关注要点**：

- 不良率低的银行拨备覆盖率可以很高但拨贷比不一定高——因为分母不同
- 拨贷比更稳定（不易被不良认定标准影响），适合跨银行比较拨备厚度

---

### 2.7 信用成本率

| 属性 | 内容 |
| --- | --- |
| **公式** | 信用成本率 = 当期信用减值损失 / 平均贷款余额 |
| **优秀标准** | <0.8%（优秀）/ <1.0%（及格） |
| **数据来源** | 年报利润表"信用减值损失" + 资产负债表"贷款总额" |

**通俗解释**：

信用成本率回答的问题是——“银行当期每放100元贷款，计提了多少元减值？”

**关注要点**：

- 信用成本率上升可能是：①真实风险恶化（不良新生成加速）；②主动增厚拨备（藏利润）
- 信用成本率下降可能是：①资产质量真实改善；②少提拨备虚增利润
- 判断方法：信用成本率 + 新生成不良率联动看——如果新生成不良没升但信用成本率上升，说明在藏利润

---

### 2.8 新生成不良率

| 属性 | 内容 |
| --- | --- |
| **公式** | 新生成不良率 = (期末不良 - 期初不良 + 当期核销转出) / 平均贷款余额 |
| **优秀标准** | <0.5%（优秀）/ <0.8%（及格） |
| **数据来源** | 年报附注手工计算（不直接披露） |

**通俗解释**：

新生成不良率回答的问题是——“银行在当期‘真实新增’了多少不良？”

例子：期初有10亿不良，期末还是10亿——看起来不良没变。但中间核销转出了5亿，又新生成了5亿——实际新生成5亿。这就是“新生成不良”。

**为什么这个指标最硬核？**

因为不良率可以被"核销"粉饰——银行把不良贷款核销掉后，不良率就下降了，但这不代表资产质量在改善。新生成不良率排除了核销影响，反映的是"贷款在当期实际恶化的速度"。

**关注要点**：

- 需要从年报"贷款质量分析"附注中手工计算：找到期初不良、期末不良、当期核销/转出金额
- 新生成不良率持续上升→资产质量在真实恶化，即使不良率表面平稳
- 新生成不良率下降→资产质量真实改善

---

## 三、资本充足率指标

**银行增长的天花板不是规模，而是资本充足率**。每放一笔贷款都要消耗资本，如果资本不够就不能继续扩张。

---

### 3.1 CET1（核心一级资本充足率）

| 属性 | 内容 |
| --- | --- |
| **公式** | CET1 = 核心一级资本 / 风险加权资产（RWA） |
| **监管要求** | ≥7.5% + D-SIBs附加（0.25%-1.5%）+ G-SIBs附加（工农中建1%-2.5%） |
| **优秀标准** | >9.5%（充足）/ >11%（厚实） |
| **数据来源** | 年报"资本充足率明细表" |

**通俗解释**：

CET1 回答的问题是——“银行最核心、最硬的自有资本（普通股+留存收益），相对于风险加权资产是否达标？”

**三层资本结构**：

| 资本层级 | 构成 | 监管要求 | 吸收损失能力 |
| --- | --- | --- | --- |
| **核心一级资本（CET1）** | 普通股 + 资本公积 + 留存收益 | ≥7.5%+附加 | 最强（永久吸收） |
| 其他一级资本 | 优先股 + 永续债 | ≥8.5%+附加（含CET1） | 较强（可减记/转股） |
| 二级资本 | 二级资本债 + 超额拨备 | ≥10.5%+附加（含一级） | 一般（有期限、可减记） |

**关注要点**：

- CET1是最硬的约束——银行每放一笔贷款都要消耗CET1，CET1不够就不能扩张
- 系统重要性银行（G-SIBs/D-SIBs）要多留0.25%-1.5%的附加资本
- CET1的补充来源：①利润留存（最优，内生）；②定增配股（摊薄股东）；③可转债转股（间接）
- 优秀银行应能靠利润留存实现CET1内生增长，不需频繁再融资

---

### 3.2 一级资本充足率

| 属性 | 内容 |
| --- | --- |
| **公式** | 一级资本充足率 = (CET1 + 其他一级资本) / RWA |
| **监管要求** | ≥8.5% + D-SIBs附加 |
| **优秀标准** | >11% |

**通俗解释**：

一级资本 = 核心一级资本 + 其他一级资本（优先股、永续债）。其他一级资本有固定利息成本，且在银行"无法生存"时可以被减记（不用还了）。

---

### 3.3 资本充足率（CAR）

| 属性 | 内容 |
| --- | --- |
| **公式** | CAR = (一级资本 + 二级资本) / RWA |
| **监管要求** | ≥10.5% + D-SIBs附加 |
| **优秀标准** | >13% |

**通俗解释**：

CAR 包含了全部三层资本。二级资本（二级资本债）有到期日（5+5或10年），到期后需要续发。如果二级资本债到期未能续发，CAR会突然下降。

---

### 3.4 杠杆率

| 属性 | 内容 |
| --- | --- |
| **公式** | 杠杆率 = 一级资本 / 表内外总资产（不做风险加权） |
| **监管要求** | ≥4% |
| **优秀标准** | >5% |

**通俗解释**：

杠杆率回答的问题是——“不管你给资产标什么风险等级，你的总资产相对于一级资本有没有过度膨胀？”

**与资本充足率的区别**：资本充足率用“风险加权资产”做分母——风险低的资产权重低、消耗资本少，但风险权重可被人为调整。杠杆率直接用“表内外总资产”做分母、不加权——不管资产标成什么风险等级，总资产膨胀杠杆率就下降，是资本充足率的“兜底”指标。

**关注要点**：

- 杠杆率低→表内外总资产相对于一级资本膨胀过度，即使CAR达标也可能有隐性风险
- 杠杆率与CAR同时看：如果CAR高但杠杆率低→银行可能在通过调整风险权重"节省"资本

---

### 3.5 RWA增速 / 总资产增速

| 属性 | 内容 |
| --- | --- |
| **公式** | RWA增速 / 总资产增速（比值） |
| **优秀标准** | <1（资本效率在提升） |
| **数据来源** | 年报"资本充足率明细表" + 资产负债表 |

**通俗解释**：

这个比值回答的问题是——"银行资产扩张时，风险加权资产的增长是否比总资产更快？"

如果 RWA增速 > 总资产增速（比值>1），说明银行在向高风险权重的资产倾斜（如对公贷款增速快于零售），资本消耗加速。反之比值<1，说明银行在优化资产结构，向低风险权重资产倾斜。

**关注要点**：

- 比值持续>1→银行资本消耗加速，即使规模不增长CET1也可能下降
- 比值持续<1→银行在"轻资本"转型，资本效率提升

---

## 四、流动性指标

流动性风险是银行"猝死"的常见原因——不是因为不赚钱，而是因为"借短贷长"导致到期还不上钱。

---

### 4.1 LCR（流动性覆盖率）

| 属性 | 内容 |
| --- | --- |
| **公式** | LCR = 优质流动性资产 / 未来30天净现金流出 |
| **监管要求** | ≥100% |
| **优秀标准** | >120% |
| **数据来源** | 年报"流动性风险管理和监管指标" |

**通俗解释**：

LCR 回答的问题是——“如果未来30天出现流动性压力，银行手头的‘随时能变现的资产’够不够覆盖净现金流出？”LCR=150%意味着有1.5倍的钱来覆盖30天的支出。

**关注要点**：

- LCR持续下降→流动性缓冲在收窄
- LCR = 100%是"活命线"，低于100%说明30天内有流动性危机风险
- 大行通常LCR>120%；中小银行可能贴近100%

---

### 4.2 NSFR（净稳定资金比例）

| 属性 | 内容 |
| --- | --- |
| **公式** | NSFR = 可用稳定资金 / 所需稳定资金 |
| **监管要求** | ≥100% |
| **优秀标准** | >110% |
| **数据来源** | 年报"流动性风险管理" |

**通俗解释**：

NSFR 回答的问题是——"从1年角度看，银行的长期稳定资金够不够覆盖长期资产所需？"

LCR管30天的短期流动性，NSFR管1年的中长期流动性。你的"稳定资金"（如长期存款、永续债、股东权益）必须够覆盖"长期资产"（如长期贷款）所需的稳定资金。

**关注要点**：

- NSFR低→如果遇到长期流动性紧张（如长期存款搬家），银行可能被迫收缩资产
- NSFR与LCR联动看：LCR高但NSFR低→短期没问题但长期有隐忧

---

### 4.3 流动性比例

| 属性 | 内容 |
| --- | --- |
| **公式** | 流动性比例 = 流动性资产 / 流动性负债 |
| **监管要求** | ≥25% |
| **优秀标准** | >40% |

**通俗解释**：

流动性比例是最传统的流动性指标——短期资产覆盖短期负债的比例。比LCR更简单但不够精细。

---

### 4.4 存贷比

| 属性 | 内容 |
| --- | --- |
| **公式** | 存贷比 = 贷款余额 / 存款余额 |
| **监管要求** | 监测指标（2015年前≤75%硬约束，现已取消） |
| **优秀标准** | 70%-85% |

**通俗解释**：

存贷比回答的问题是——“银行放的贷款相对于吸收的存款有多少？”如果存贷比>100%，说明贷款比存款还多，银行必须靠同业借款（NCD等）来弥补缺口。

**关注要点**：

- 存贷比太高（>90%）→依赖高息主动负债，流动性紧张
- 存贷比太低（<70%）→存款多但贷款少，资金运用效率低，可能"资产荒"
- 2015年后存贷比从硬约束降为监测指标，但仍是重要的结构性参考

---

### 4.5 核心负债依存度

| 属性 | 内容 |
| --- | --- |
| **公式** | 核心负债依存度 = 核心负债 / 总负债 |
| **监管要求** | ≥60% |
| **优秀标准** | >70% |

**通俗解释**：

核心负债 = 活期存款 + 定期存款 + 其他稳定负债（不含同业借款和已发行债券）。核心负债依存度高说明银行不依赖短期同业资金，负债结构稳定。

---

## 五、资产负债结构指标

这些指标不是直接的"盈利"或"风险"指标，但它们决定了银行的经营画像和商业模式，是理解NIM、资产质量、资本消耗的根本驱动力。

---

### 5.1 活期存款占比

| 属性 | 内容 |
| --- | --- |
| **公式** | 活期存款占比 = 活期存款 / 客户存款总额 |
| **优秀标准** | >40%（优秀）/ >30%（及格） |

**通俗解释**：

活期存款是银行最便宜的资金来源（利率0.2%-0.3%），几乎是"免费的杠杆"。活期存款占比高的银行，负债成本天然就低。

**关注要点**：

- 活期存款占比高→负债成本低→NIM有优势→息差收窄周期中防御力强
- 活期存款占比下降→客户在把钱从活期转向理财或定期→负债成本上升
- 国有大行和招商银行活期占比行业领先（40%+），主要靠庞大的零售客户基础和支付账户绑定

---

### 5.2 零售存款占比

| 属性 | 内容 |
| --- | --- |
| **公式** | 零售存款占比 = 个人存款 / 客户存款总额 |
| **优秀标准** | >50% |

**通俗解释**：

零售存款（个人存款）比企业存款更稳定——个人客户不会像企业那样大额搬家。零售存款占比高的银行在流动性紧张时更有韧性。

---

### 5.3 存款成本率

| 属性 | 内容 |
| --- | --- |
| **公式** | 存款成本率 = 利息支出(存款部分) / 平均存款余额 |
| **优秀标准** | <2.0% |

**通俗解释**：

存款成本率直接反映银行获取存款的资金成本。越低越好——说明银行不靠高息揽储。

**关注要点**：

- 存款成本率上升→可能是在用高息产品（如结构性存款、大额存单）抢存款
- 存款成本率下降→可能是活期占比提升或市场利率下行

---

### 5.4 同业负债占比

| 属性 | 内容 |
| --- | --- |
| **公式** | 同业负债占比 = (同业存放+拆入资金+卖出回购+同业存单) / 总负债 |
| **监管要求** | ≤25%（同业负债占总负债比例，不含同业存单的旧口径）/ ≤33%（含同业存单的新口径） |
| **优秀标准** | <20% |

**通俗解释**：

同业负债是银行向同行借钱（而非向客户吸收存款），成本高、期限短、不稳定。同业负债占比高说明银行存款不足，需要靠"借钱"来维持资产扩张。

**关注要点**：

- 同业负债占比高→负债成本高+流动性风险大（到期续发风险）
- 同业存单（NCD）是中小银行主动负债的核心工具——3-12个月期限，到期需要续发
- 过度依赖NCD的银行在市场利率上升或流动性紧张时可能"续不上"——旧债到期但新债发不出去

---

### 5.5 贷款/总资产

| 属性 | 内容 |
| --- | --- |
| **公式** | 贷款/总资产 = 发放贷款及垫款 / 总资产 |
| **优秀标准** | 50%-65% |

**通俗解释**：

贷款是银行最核心的生息资产。贷款占比高说明银行"回归本源"——靠放贷赚利差。贷款占比低可能是金融投资或同业资产占比高——这部分收益偏低且受市场波动影响。

---

### 5.6 零售贷款占比

| 属性 | 内容 |
| --- | --- |
| **公式** | 零售贷款占比 = 个人贷款 / 贷款总额 |
| **优秀标准** | >40%（优秀） |

**通俗解释**：

零售贷款（个人住房按揭、信用卡、消费贷）通常比对公贷款收益率更高、不良率更低、风险权重更低（按揭50% vs 对公100%）。零售贷款占比高的银行在盈利能力和资本效率上都有优势。

---

### 5.7 金融投资三分类占比

| 属性 | 内容 |
| --- | --- |
| **公式** | AC占比 + FVTPL占比 + FVOCI占比 = 金融投资总额 |
| **数据来源** | 年报"金融投资明细表" |

**三分类对照**：

| 分类 | 通俗理解 | 对损益的影响 | 浮盈浮亏是否可见 |
| --- | --- | --- | --- |
| AC（摊余成本） | "持有到期收本息" | 仅利息计入利润 | **隐性**（浮亏不体现） |
| FVTPL（公允价值变动计入损益） | "随时可能卖" | 公允价值变动直接进利润 | 显性 |
| FVOCI（公允价值变动计入其他综合收益） | "可能持有也可能卖" | 利息进利润；浮盈浮亏进权益 | 在权益中体现，不进利润 |

**关注要点**：

- AC占比过高→利率风险"隐性化"——如果利率大幅上升，债券市值下跌但资产负债表上仍按摊余成本记账，浮亏"隐身"了
- FVTPL占比高→利润波动大（每期公允价值变动直接进利润表）
- 需结合"其他综合收益"中的金融资产公允价值变动判断隐性损益

## 六、估值与回报指标

---

### 6.1 PB（市净率）

| 属性       | 内容                               |
| -------- | -------------------------------- |
| **公式**   | PB = 总市值 / 归母净资产（或：每股股价 / 每股净资产） |
| **优秀标准** | 与ROE匹配：合理PB ≈ ROE / 要求回报率        |
| **数据来源** | AkShare行情快照（medium）/ 交易所行情       |

**通俗解释**：

PB 回答的问题是——“你花多少钱买银行1块钱的净资产？”

**为什么银行看PB比PE更重要？**

银行净利润可被拨备大幅调节（多提少提拨备差几个亿），但净资产相对稳定。所以PB更可靠。

**合理PB的估算**：

- 如果ROE=13%，要求回报率=10%，合理PB≈1.3倍
- 如果ROE=9%，要求回报率=10%，合理PB≈0.9倍
- 低于合理PB→可能被低估；高于合理PB→可能被高估

**`合理PB ≈ ROE / 要求回报率`怎么来的？**

它来自**股利折现模型**：股票价值等于未来所有可分配给股东的现金流，折现到今天后的总和。先假设银行不增长、每年盈利和分红都稳定；设期初每股净资产为 `B`，可持续ROE为 `ROE`，股东要求回报率为 `r`：

```text
每年可分配利润 = B × ROE
股票价值 P = 每年可分配利润 ÷ r = B × ROE ÷ r
PB = P ÷ B = ROE ÷ r
```

例如每股净资产10元、ROE=12%、要求回报率=10%：每年每股可赚1.2元。若这1.2元可稳定分配，市场为取得10%回报愿意支付 `1.2 ÷ 10% = 12` 元；因此 `PB = 12 ÷ 10 = 1.2倍`。所以：

- `ROE > 要求回报率` → `PB > 1`：银行创造的回报高于股东要求，通常值得溢价；
- `ROE = 要求回报率` → `PB = 1`：银行只获得与资本成本相当的回报；
- `ROE < 要求回报率` → `PB < 1`：资本使用效率低于股东要求，通常应折价。

这里的**要求回报率**不是银行贷款利率，而是股东承担银行经营风险后要求的年化回报。它会随无风险利率、资产质量、资本缓冲、盈利稳定性和市场风险偏好变化。

**稳定增长模型如何推导**：

现实中银行并非不增长。设下一年度每股股息为 `D₁`，此后股息每年按稳定增速 `g` 增长，股东要求回报率为 `r`，且必须满足 `r > g`。股价是未来股息的折现和：

```text
P₀ = D₁/(1+r) + D₁×(1+g)/(1+r)² + D₁×(1+g)²/(1+r)³ + ···
   = D₁/(r-g)                                      （等比数列求和）
```

将股息改写为银行经营指标。设分红率为 `p`，当前每股净资产为 `B₀`，则：

```text
下一年度每股利润 EPS₁ = B₀ × ROE
下一年度每股股息 D₁ = EPS₁ × p = B₀ × ROE × p
P₀ = B₀ × ROE × p ÷ (r-g)
PB = P₀ ÷ B₀ = ROE × p ÷ (r-g)
```

银行将 `1-p` 的利润留存为资本；在ROE稳定、无需额外融资且资产结构稳定的假设下，留存利润支持的可持续增长率为：

```text
g = ROE × (1-p)
ROE × p = ROE × [1-(1-p)] = ROE - g
```

代入可得银行常用的稳定增长 PB 公式：

```text
合理PB = (ROE - g) ÷ (要求回报率 - g)
```

因此，前面的简化式只是 `g=0`（不增长）时的特殊情形：`PB = ROE / 要求回报率`。增长会提高合理PB，但增长不是免费的：银行需留存利润补充CET1、支撑RWA增长，因而更高的 `g` 通常意味着更低的当期分红率。

**使用边界**：公式中的ROE必须是可持续ROE。少提拨备、一次性投资收益、过度杠杆或资本缓冲偏薄造成的高ROE，不能直接代入；同时必须保证 `要求回报率 > 长期增长率`，否则模型会得出不合理的极高估值。

**对照案例**：

| 银行 | ROE | 最新PB | 合理PB估算 | 判断 |
| --- | --- | --- | --- | --- |
| 工商银行 | 9.45% | 0.68x | ~0.95x | 偏低估 |
| 招商银行 | 13.44% | 0.85x | ~1.34x | 偏低估 |

（注：PB为AkShare快照数据，证据等级medium，仅供参考。实际估值需考虑ROE可持续性、增长预期等。）

---

### 6.2 PE（市盈率）

| 属性 | 内容 |
| --- | --- |
| **公式** | PE = 总市值 / 归母净利润（或：每股股价 / 每股收益） |
| **使用建议** | 仅作辅助，受拨备影响大 |

**为什么PE对银行不太好用？**

因为银行利润可被拨备大幅调节——同一家银行，拨备多提5亿利润就少5亿，PE就变高。所以PE反映的"贵不贵"可能只是拨备政策的产物，不反映真实盈利能力。

---

### 6.3 股息率

| 属性 | 内容 |
| --- | --- |
| **公式** | 股息率 = 每股分红 / 股价 |
| **优秀标准** | >5%（高分红）/ >3%（中等） |
| **数据来源** | AkShare行情快照 / 年报分红方案 |

**通俗解释**：

股息率回答的问题是——“按当前股价买入，每年靠分红能拿回百分之几？”长期持有总回报 ≈ 股息率 + 净资产增长率。

**关注要点**：

- A股银行股息率通常按税前算；H股需考虑红利税（港股通扣20%）
- 股息率高可能是因为分红多，也可能是因为股价跌了——需区分
- 高股息率 + 低PB + 稳定ROE → 典型的价值型银行股投资逻辑

---

### 6.4 分红率

| 属性 | 内容 |
| --- | --- |
| **公式** | 分红率 = 年度现金分红 / 归母净利润 |
| **优秀标准** | 25%-35%（平衡区间） |
| **数据来源** | 年报"利润分配方案" |

**通俗解释**：

分红率回答的问题是——"银行把赚的利润分了多少给股东，留了多少补充资本？"

**分红率与内生增长的平衡**：

- 分红率高→股东到手现金多，但留存利润少，CET1补充慢→可能需要外部融资（摊薄）
- 分红率低→CET1补充快，内生增长强，但股东到手现金少
- 25%-35%是大多数银行的选择——兼顾股东回报和资本补充

---

### 6.5 内生增长率

| 属性 | 内容 |
| --- | --- |
| **公式** | 内生增长率 ≈ ROE × (1 - 分红率) |
| **判断标准** | 内生增长率 ≥ RWA增速 → 可不靠外部融资 |

**通俗解释**：

内生增长率回答的问题是——"银行靠自己的利润留存，CET1每年能增长百分之几？"

如果内生增长率 ≥ RWA增速，银行可以不靠外部融资（定增、配股）实现增长——这是"内生性增长"。如果内生增长率 < RWA增速，银行就必须再融资，稀释股东价值。

**公式怎么来的（三步推导）**：

```
① 资本增速 = 当年新增资本 / 期初资本 = 留存利润 / 期初资本        （不融资时，资本唯一增量=留存利润）

② 留存利润 = 净利润 - 分红 = 净利润 × (1 - 分红率)                （分红率的恒等变形）

③ 资本增速 = 净利润 × (1-分红率) / 期初资本 = (净利润/期初资本) × (1-分红率) = ROE × (1-分红率)
```

数字验证：期初资本100亿，ROE=13%→净利润13亿；分红率30%→分红3.9亿、留存9.1亿；资本增速=9.1/100=9.1%，与公式 13%×(1-30%)=9.1% 完全一致。本质只是"留存率×赚钱效率"的代数重排。

**严格版的四个修正**：

1. **ROE口径**：严格应用"CET1口径回报率"（净利润/平均核心一级资本），而非报表ROE——净资产中含优先股、永续债等，这部分补不了CET1
2. **OCI影响**：CET1变动还受其他综合收益影响（FVOCI债券公允价值变动等）——利率大幅上行年份，OCI损失可能吃掉大半利润留存
3. **RWA密度变化**：公式隐含假设资产结构不变；若银行多配低风险权重资产（按揭50% vs 对公100%），RWA增速可低于总资产增速，相当于变相省出资本
4. **完整判断式**：`CET1充足率自然变动 ≈ [ROE(CET1口径)×(1-分红率) + OCI变动率] - RWA增速`，结果>0资本越攒越厚，<0逐年变薄

**对照案例**：

| 银行 | ROE | 分红率（假设） | 内生增长率 | RWA增速（假设） | 能否内生？ |
| --- | --- | --- | --- | --- | --- |
| 工商银行 | 9.45% | 30% | 6.6% | ~6% | 可以 |
| 招商银行 | 13.44% | 30% | 9.4% | ~8% | 可以 |

## 七、指标联动分析框架

单个指标看银行容易"盲人摸象"。真正有效的分析是多个指标联动看。

### 7.1 盈利质量四联动

```
PPOP增速 vs 净利润增速 → 判断拨备在"吃利润"还是"释放利润"
  ↓
信用成本率 vs 新生成不良率 → 判断拨备计提是否与真实风险匹配
  ↓
拨备覆盖率趋势 → 判断"蓄水池"在增厚还是在消耗
  ↓
拨备前ROE vs 报告ROE → 判断"去水"后的真实盈利能力
```

### 7.2 资本约束三联动

```
ROE × (1 - 分红率) → 内生增长率
  ↓
内生增长率 vs RWA增速 → 能否不融资扩张？
  ↓
CET1 vs 监管要求+附加 → 资本缓冲厚度
```

### 7.3 资产质量五联动

```
关注类比例趋势 → 不良"蓄水池"方向
  ↓
不良率 + 逾期90天+ → 剪刀差判断认定严格度
  ↓
新生成不良率 → 真实恶化速度
  ↓
拨备覆盖率 + 拨贷比 → 拨备厚度
  ↓
信用成本率 → 当期风险定价
```

### 7.4 估值闭环

```
ROE（盈利能力）+ 资产质量（风险调整）+ 资本内生性（可持续性）
  ↓
合理PB ≈ ROE / 要求回报率
  ↓
实际PB vs 合理PB → 低估 or 高估
  ↓
股息率 + 分红率 → 股东回报
```
