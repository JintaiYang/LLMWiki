# 银行股完整投资研究框架

## 1. 研究主线

```text
宏观与监管
→ 资产负债结构
→ 净息差与非息收入
→ 资产质量与信用成本
→ 拨备与利润质量
→ 资本约束与分红能力
→ 正常化 ROE
→ 估值与 3-5 年股东回报
```

## 2. 官方事实

- 宏观、利率、社融和存款环境，优先来自央行：[[05_知识库/10_来源/来源_中国人民银行货币政策工具与利率政策]] 与 [[05_知识库/10_来源/来源_中国人民银行社融与金融机构统计]]。
- 资本、流动性、资产质量和拨备的横向可比口径，优先来自监管总局：[[05_知识库/10_来源/来源_国家金融监督管理总局商业银行主要监管指标]]。
- 覆盖范围上，当前库内 AkShare 快照识别 42 家 A 股上市银行，作为行业全景的 `medium` 级底表：[[05_知识库/10_来源/来源_AkShare中国A股上市银行42家快照_2026-07-22]]。

## 3. 研究拆解

- 第一步：先确认银行属于哪个可比组，见 [[银行分类与可比组框架]]。
- 第二步：理解赚钱逻辑，重点看 [[NIM与净利差]]、[[非息收入与财富管理]] 与 [[存款成本与负债护城河]]。
- 第三步：检查风险质量，重点看 [[不良率关注率与逾期率]]、[[新生成不良与信用成本]]、[[拨备覆盖率与拨贷比]]。
- 第四步：看扩表和分红能否持续，重点看 [[CET1与资本充足率]]、[[RWA与风险密度]]、[[ROE与可持续增长]]。
- 第五步：回到估值与市场结构，结合 [[A-H银行股估值差异]] 和行业主矛盾页判断预期差。

## 4. 研究推断

- 银行研究最容易失真的地方，是把短期利润表改善和长期价值创造混为一谈；因此必须用 PPOP、信用成本、资本消耗和分红约束联动观察。
- 一个银行是否值得长期持有，关键不是“利润能不能涨”，而是“盈利质量能否穿越周期，并转化为可持续股东回报”。
