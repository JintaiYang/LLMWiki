# 估值公式小白释义

> 读 [[股息贴现模型]]、[[剩余收益模型]] 之前先看本页。下面每个符号都配一句人话和一个银行数字直觉。公式里的具体取值是研究假设，不是年报原文。

## 1. 先建立三个角色

买银行股，脑子里只放三个人：

| 角色 | 问的问题 | 对应符号 |
| --- | --- | --- |
| 银行这家店 | 股东的本金现在账上有多少？今年能赚多少？分多少现金？ | `BV`、`ROE`、`p`、`D` |
| 你这个买家 | 承担风险后，一年至少要赚百分之几才肯买？ | `COE` |
| 市场这块牌子 | 现在股价相当于净资产的几倍？相当于利润的几倍？ | `PB`、`PE`、股息率 |

估值不是预测明天涨跌，而是问：按你要求的回报，这家店今天值多少钱。

## 2. 符号词典（公式里出现的都在这里）

### 2.1 折现

把“以后才到手的钱”换算成“今天值多少”。明年稳拿 110 元、你要求 10% 回报，今天只值 `110 / 1.10 = 100` 元。分母里用的年利率，对股票就是 [[股权成本COE]]。

### 2.2 BV / B / 每股净资产

Book Value，账面净资产。银行股东在账本上的本金。

- 总净资产：资产 − 负债后属于股东的部分
- 每股净资产 `BV0`：总净资产 ÷ 总股本，也就是“一股对应多少本金”
- 口语：净值、账面价值

例：每股净资产 10 元，意思是账面上这一股背后有 10 元股东本金。买价 7 元就是花 7 元买 10 元账面本金，`PB = 0.7` 倍。

注意：账面不一定等于真本金。坏账没提够，账面会被高估。所以 RIM 要求先检查资产质量，必要时下调 `BV0`。

### 2.3 ROE

Return on Equity，净资产收益率。股东每 100 元本金，这一年银行赚了多少利润。

```text
ROE = 归母净利润 / 平均净资产
```

例：本金 10 元，ROE 12%，今年每股大约赚 1.2 元。详见 [[ROE与可持续增长]]。

`正常化 ROE`：去掉“今年少提了拨备、炒债券大赚一笔”之后，你认为长期能维持的 ROE。估值必须用这个，不能直接用某一季年化。

### 2.4 COE

Cost of Equity，股权成本 / 股东要求回报率。你买这只股票，一年至少想赚多少。

它**不是**贷款利率，也**不是**年报科目。专门解释见 [[股权成本COE]]。

直觉：国债大约 2%–3%，股票更波动，银行股 COE 研究里常见大约 8%–12% 这一档，风险越大应越高。

### 2.5 分红、D、D1、分红率 p

| 符号 | 白话 |
| --- | --- |
| 分红 / 股息 / DPS | 公司用现金发给股东的钱。不是股价涨跌，是真金白银打到账上 |
| `D1` | 预计**下一年全年**每股能分到多少现金（中期 + 末期要加总） |
| 分红率 `p` | 利润里拿出多大比例来分红。`p = 30%` 表示赚 1 元分 0.3 元，留下 0.7 元当本金继续经营 |

银行版生成式：

```text
明年每股利润 ≈ 今年每股净资产 × ROE
明年每股分红 D1 ≈ 每股净资产 × ROE × 分红率
```

例：净资产 10 元，ROE 10%，分红率 30%，则 `D1 ≈ 10 × 10% × 30% = 0.30` 元。

### 2.6 g（长期增长率）

以后每年，分红或净资产大概能增长百分之几。是对很远的未来的假设，不是今年贷款增速。

本库常用 2%–4% 作终值期的审慎上限，大约对应长期名义经济增长，而不是把近几年 8% 的扩表速度当成永远。

必须满足 `COE > g`。否则等于说“增长永远比你要求的回报还快”，公式会算出离谱天价。

### 2.7 内生增长率

不向市场再融资时，光靠留下的利润，本金能长多快：

```text
内生增长率 ≈ ROE × (1 − 分红率)
```

例：ROE 10%、分红率 30%，留下 70%，本金大约年增 7%。分红分得越多，能支撑的增长越慢。高分红、高增长、厚资本垫，三件事不能同时长期成立。

### 2.8 PB / PE / 股息率

| 符号 | 公式直觉 | 白话 |
| --- | --- | --- |
| `PB` 市净率 | 股价 ÷ 每股净资产 | 花多少钱买 1 元账面本金 |
| `PE` 市盈率 | 股价 ÷ 每股利润 | 花多少年利润才能回本。银行利润可被拨备调节，本库只当辅助 |
| 股息率 | 每股分红 ÷ 股价 | 按现价买，一年分红能拿回百分之几。高可能是分红多，也可能只是股价跌了 |

### 2.9 剩余收益 RI

利润减去“股东要求的资本租金”：

```text
RI = (ROE − COE) × 上期净资产
```

例：净资产 10 元，ROE 12%，COE 10%。股东要求每年 1 元，银行赚了 1.2 元，剩余收益 0.2 元。这 0.2 元才是配得上溢价的部分。见 [[剩余收益模型]]。

### 2.10 V0 / P0 / 内在价值

模型算出来的“今天值多少钱”。`P0` 常用于 DDM，`V0` 常用于 RIM，意思接近。它是假设的结果，**不是**行情软件上的现价，也**不要**直接写成“目标价”或“一定能涨到”。

### 2.11 和银行强相关、公式里会碰到的词

| 词 | 白话 |
| --- | --- |
| `CET1` 核心一级资本充足率 | 最硬的安全垫：真损失吸收能力 / 风险加权资产。垫子薄了就要少分红或再融资 |
| `RWA` 风险加权资产 | 把贷款按风险打了折的“风险规模”。增长太快会消耗资本 |
| 拨备 | 预先留下的坏账准备金。少提拨备，今年利润和 ROE 会虚高 |
| 干净盈余 | 简化记账：净资产变动 ≈ 净利润 − 分红。在这个前提下，DDM 和 RIM 算出同一个价值 |
| 再融资 / 摊薄 | 向市场再要股东的钱（配股、转股）。老股东每股净资产和每股分红会被稀释 |

## 3. 三条主公式，逐项翻译

下面用同一套教学数字，方便对照。全部是假设，不是某家银行的结论。

```text
每股净资产 BV0 = 10 元
正常化 ROE     = 10%
分红率 p       = 30%     （先用现行分红；稳态时可能更高，见下文）
股东要求 COE   = 9.5%
长期增长 g     = 3%
```

### 3.1 股息贴现 DDM：值多少钱 = 未来分红折到今天

明年每股分红：

```text
D1 = 10 元 × 10% × 30% = 0.30 元
```

若从明年起分红永远按 3% 增长：

```text
P0 = D1 / (COE − g) = 0.30 / (9.5% − 3%) = 0.30 / 6.5% ≈ 4.62 元
```

人话：明年给你 0.30 元，以后每年多 3%；你要求 9.5%。扣掉增长后，相当于按 6.5% 的“净要求”把这笔永久现金流买下来，值 4.62 元。

这里有个关键：现行分红率只有 30% 时，机械内生增速是 `10% × 70% = 7%`，已经接近 COE，不能把 7% 当成永远的 `g`。本库终值 `g` 常用 3%，意味着终值期要么提高分红率，要么承认多余利润在囤资本、而不是永远 7% 扩表。详见 [[股息贴现模型]]。

若终值把分红率提高到 `p = 1 − 3%/10% = 70%`：

```text
D1 = 10 × 10% × 70% = 0.70 元
P0 = 0.70 / (9.5% − 3%) ≈ 10.77 元
合理 PB = 10.77 / 10 = 1.08 倍
```

### 3.2 剩余收益 RIM：值多少钱 = 本金 + 多赚出来的部分

每年相对及格线多赚：

```text
ROE − COE = 10% − 9.5% = 0.5%
每年剩余收益 ≈ 0.5% × 10 元 = 0.05 元
```

稳态：

```text
V0 = 10 + 0.05 / (9.5% − 3%) = 10 + 0.77 = 10.77 元
```

人话：账上已经有 10 元本金；以后每年还能比你的要求多赚 0.05 元，这块超额按同样口径折回来值 0.77 元。总共 10.77 元。与上面提高分红率后的 DDM **必须相等**。

若 ROE 只有 8%，低于 9.5% 的要求：

```text
合理 PB = (8% − 3%) / (9.5% − 3%) ≈ 0.77 倍
```

低 PB 此时不是“便宜”，而是模型认为它赚不够你要求的回报。详见 [[剩余收益模型]]。

### 3.3 合理市净率 PB-ROE：把上面两式压成一个倍数

```text
合理 PB = (ROE − g) / (COE − g) = (10% − 3%) / (9.5% − 3%) = 1.08 倍
合理价格 = 合理 PB × 每股净资产 = 1.08 × 10 = 10.80 元   （四舍五入与上面一致）
```

人话：不逐笔折现分红，直接问“1 元净资产该卖几元”。本库横比银行贵贱，主要看这个，而不是 PE。

零增长时更简单：`合理 PB ≈ ROE / COE`。ROE 12%、COE 10%，大约值 1.2 倍净资产。

## 4. 一张图记住三者关系

```text
DDM     问：以后能拿到多少现金分红？
RIM     问：现在账上有多少本金，以后还能多赚多少？
PB-ROE  问：1 元本金该卖几元？

稳态 + 同一套 ROE、COE、g、分红率
        ↓
      三个答案必须一样
不一样  =  假设互相打架，回头改参数，而不是改公式
```

选用顺序（本库）：

1. 账面坏账提够了没有 → 决定 RIM 的本金 `BV0`
2. 长期能维持多高 ROE、分多少、长多快 → 得到合理 PB 或 RIM/DDM 价值
3. 分红很稳、资本垫厚 → DDM 当主交叉
4. 分红低、还在快速扩表 → RIM / PB-ROE 为主，DDM 当辅助

## 5. 读个股估值页时怎么认信息类别

| 你看到的东西 | 它是什么 | 能不能当成“公司已经说了” |
| --- | --- | --- |
| 年报每股净资产、分红预案 | 官方事实 | 可以，要写报告期 |
| 行情软件里的 PB、现价、股息率 | 第三方数据 | 可以引用，但要写日期；本库默认证据中等 |
| 分析师预测明年分红 | 外部预期 | 只能放预期栏，不能直接当模型输入 |
| COE、g、正常化 ROE、内在价值 | 估值假设 | 不可以写成事实 |
