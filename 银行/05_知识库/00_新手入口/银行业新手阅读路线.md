# 银行业新手阅读路线

## 1. 先回答三个问题

- 银行赚的是什么钱：先看 [[银行业资金循环与价值链地图]]，再看 [[NIM与净利差]] 与 [[非息收入与财富管理]]。
- 银行怕的是什么风险：先看 [[不良率关注率与逾期率]]、[[新生成不良与信用成本]] 与 [[资产质量滞后暴露]]。
- 银行为什么会便宜或贵：先看 [[ROE与可持续增长]]、[[CET1与资本充足率]] 与 [[A-H银行股估值差异]]。

## 2. 推荐阅读顺序

1. 行业全景：[[中国上市银行行业主页]]、[[银行分类与可比组框架]]。
2. 赚钱逻辑：[[银行业资金循环与价值链地图]]、[[银行客户与资金来源地图]]。
3. 关键指标：[[NIM与净利差]]、[[PPOP与利润质量]]、[[拨备覆盖率与拨贷比]]。
4. 风险与监管：[[中国银行体系与监管架构]]、[[货币政策与银行传导]]、[[金融资产风险分类]]。
5. 场景化理解：[[对公银行]]、[[零售银行]]、[[财富管理]]、[[金融市场与同业]]、[[普惠小微与县域]]。
6. 投资落地：[[银行股完整投资研究框架]]、[[净息差收窄]]、[[资本约束]]。

## 3. 官方事实

- 当前库内 AkShare 快照识别 42 家 A 股上市银行，可用于理解覆盖范围，但证据等级为 `medium`：[[05_知识库/10_来源/来源_AkShare中国A股上市银行42家快照_2026-07-22]]。
- 资本、流动性、不良和拨备等横向可比口径应优先回到监管来源：[[05_知识库/10_来源/来源_国家金融监督管理总局商业银行主要监管指标]]（https://www.nfra.gov.cn/）。

## 4. 研究推断

- 新手最常见错误不是不会算指标，而是把不同银行放进错误可比组；因此应先读 [[银行分类与可比组框架]]，再做优劣排序。
- 对银行股的长期判断，本质上是“盈利能力、资产质量、资本约束、估值”四者的联动，而不是单看股息率。
