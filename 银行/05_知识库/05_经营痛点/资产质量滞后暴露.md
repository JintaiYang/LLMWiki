# 资产质量滞后暴露

## 1. 问题定义

- 银行风险往往先隐藏在关注、逾期、展期、重组和核销节奏里，真正反映到不良率与利润表常常具有滞后性。

## 2. 官方事实

- 风险分类和不良认定的制度边界，优先看监管总局：[[05_知识库/10_来源/来源_国家金融监督管理总局资本与风险分类制度]]。
- 房地产和地方财政压力是重要外部触发因素，可参考统计局：[[05_知识库/10_来源/来源_国家统计局宏观经济与房地产统计]]。

## 3. 研究推断

- 资产质量问题最怕“看起来没事”，因为利润表可以被拨备平滑，但风险迁徙通常不会消失，只会后移。
- 区域集中高、地产和平台暴露高的银行，更容易在 [[治理与区域集中]] 与 [[房地产与地方化债传导]] 的共振中出现滞后暴露。
