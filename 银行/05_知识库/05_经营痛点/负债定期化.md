# 负债定期化

## 1. 问题定义

- 负债定期化指活期存款占比下降、定期化或高成本负债占比上升，通常会抬升银行整体资金成本并削弱负债灵活性。

## 2. 官方事实

- 存款总量与结构变化的宏观背景，可优先参考央行统计：[[05_知识库/10_来源/来源_中国人民银行社融与金融机构统计]]。
- 利率政策与存款挂牌利率环境，会影响客户期限选择：[[05_知识库/10_来源/来源_中国人民银行货币政策工具与利率政策]]。

## 3. 研究推断

- 负债定期化本质上是竞争格局和客户行为变化，不只是利率问题；当客户更在意安全和收益时，中小银行往往需要付出更高成本。
- 若负债定期化与 [[净息差收窄]] 同时发生，而银行又缺少 [[财富管理]] 或结算场景支撑，盈利弹性会明显下降。
