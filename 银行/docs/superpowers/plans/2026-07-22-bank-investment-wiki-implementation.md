# 中国 A 股银行投资研究知识库实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 在当前空 Vault 中搭建一个覆盖全部 A 股上市银行、深度研究 18 家重点银行、可持续摄入官方披露与 AkShare 数据的中长期投资研究知识库。

**Architecture:** 采用“行业 Wiki + 投资驾驶舱”混合架构。原始资料只读存档，结构化知识用双链连接，行业与个股投资命题通过跟踪器持续验证，估值与市场预期严格和事实层隔离。

**Tech Stack:** Obsidian、Markdown/YAML、CSV、Python 3、AkShare、Git。

## Global Constraints

- 研究范围：中国 A 股上市银行，A/H 同一主体共享基本面、分离交易口径。
- 投资周期：3–5 年中长期基本面投资。
- 数据截点：2026-07-22 前正式披露资料；2025 年年报为完整基准，2026 年最新正式季报用于边际更新。
- 18 家重点银行：工商、建设、农业、中国、邮储、交通、招商、兴业、平安、中信、浦发、民生、宁波、江苏、成都、杭州、南京、常熟。
- 证据优先级：监管/政府官方数据 > 银行正式披露 > AkShare > 市场预期 > 研究推断。
- AkShare 原始数据默认 `medium`，官方复核后才能升级为 `high`。
- 事实、第三方数据、市场预期、研究推断、估值假设和待验证事项必须隔离。
- 不自动提交 Git。
