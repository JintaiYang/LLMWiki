# 创新药 LLM Wiki 设计规范

> 基于 Karpathy LLM Wiki 范式与 industry-llm-wiki skill 构建。
> 设计确认日期：2026-07-19

## 1. 项目定位

- **用途**：投资研究（公司、管线、估值、催化剂与风险）
- **市场范围**：中国创新药为主（A 股/港股），兼顾海外授权与全球竞品
- **研究框架**：管线质量 + 临床概率 + 商业化 + BD + 财务估值（综合框架）
- **信息截止**：尽量更新至 2026-07-19，仅采纳可核验公开信息
- **首期深度**：60–80 页深度版

## 2. 架构：公司—管线—靶点三层知识网络

### 2.1 三类核心实体

**公司层** — 回答"这家公司是否值得投资"：
- 公司定位与核心投资逻辑
- 管理层与研发能力
- 产品组合和核心管线
- 商业化能力
- License-in / License-out 与合作网络
- 营收、利润、研发费用、现金储备及现金跑道
- 估值框架与关键假设
- 未来 12–18 个月催化剂
- 核心风险和证伪条件

**管线层** — 回答"这个资产是否有临床与商业价值"：
- 药物名称、机制、分子形式和权益归属
- 适应症与临床阶段
- 关键试验设计
- 疗效、安全性和患者基线
- 与标准疗法及同靶点资产的横向比较
- 临床成功概率
- 市场空间、竞争位置和商业化假设
- 未来数据读出、申报和审批节点
- 失败条件与待验证问题

**靶点/赛道层** — 回答"这个方向是否值得投入以及谁可能胜出"：
- 靶点生物学和作用机制
- 已验证程度
- 适用疾病与患者分层
- 全球及中国竞争格局
- 已上市药物和标准疗法
- 同机制管线比较
- 差异化维度
- 赛道拥挤度
- 技术、临床、监管与商业化风险

### 2.2 核心链接关系

```
公司 → 拥有/合作 → 管线
管线 → 作用于 → 靶点
管线 → 开发用于 → 适应症
管线 → 对比 → 同机制竞品
公司 → 发生 → BD 交易
公司/管线 → 对应 → 催化剂
公司/管线/赛道 → 面临 → 风险
投资判断 → 依赖 → 证据与估值假设
```

### 2.3 设计原则

- 公司页不重复堆放临床细节，临床数据放到管线页
- 管线页不重复解释靶点基础知识，统一链接靶点页
- 每项投资判断必须能追溯到来源或明确标记为推断
- 所有未来事件必须注明"预期时间"和"信息来源"，不能写成确定事实
- 估值结果必须同时保留关键假设、敏感性和证伪条件
- 页面采用短节点和密集双链，而非长篇研报

## 4. 重点公司筛选与首期覆盖

### 4.1 筛选模型（六维评分）

| 维度 | 权重 | 评估内容 |
|---|---:|---|
| 管线质量 | 25% | 靶点验证程度、临床数据、差异化、适应症价值 |
| 商业化能力 | 20% | 已上市产品、销售能力、医保准入、海外商业化 |
| 研发平台 | 15% | 持续产出能力、技术平台复用性、研发效率 |
| BD 能力 | 15% | License-out 质量、合作方、首付款与里程碑 |
| 财务安全 | 15% | 现金储备、研发投入、现金跑道、融资压力 |
| 投资可跟踪性 | 10% | 信息披露、未来催化剂、估值锚与预期差 |

公司类型标记：核心型、成长型、平台型、事件型、高风险型。

### 4.2 首期 15 家重点公司

**核心综合型**：百济神州、信达生物、恒瑞医药、中国生物制药、石药集团

**创新成长型**：康方生物、科伦博泰、荣昌生物、再鼎医药、和黄医药

**平台及前沿技术型**：传奇生物、亚盛医药、君实生物、诺诚健华、三生制药

> 若资料核验显示某家公司截至截止日的投资跟踪价值明显下降，可替换为翰森制药、复宏汉霖、迈威生物、映恩生物、宜明昂科、云顶新耀等候选公司，并在操作日志记录替换理由。

## 5. 管线页面设计

### 5.1 核心管线选择规则

满足以下任意条件才进入核心管线库：
1. 已上市，且对公司收入或估值具有显著影响
2. 已进入注册性或关键临床阶段
3. 已产生较强的人体有效性信号
4. 已达成重要海外授权或联合开发交易
5. 属于公司估值中的核心资产
6. 未来 12–18 个月存在关键数据读出、申报或审批节点
7. 虽处早期，但机制、分子设计或临床结果具有明显差异化

每家公司原则上选择 1–3 条核心管线，预计建立 20–25 个独立管线页。

### 5.2 管线页统一结构

```
一句话资产判断
├── 基本信息（通用名、研发代号、分子类型、机制、权益归属）
├── 适应症与开发阶段
├── 关键临床试验（试验编号、设计、入组、终点、数据截止日）
├── 疗效证据
├── 安全性证据
├── 跨试验比较限制
├── 标准疗法与未满足需求
├── 同靶点/同机制竞品
├── 差异化判断
├── 临床成功概率
├── 商业价值与市场假设
├── 未来催化剂
├── 核心风险与证伪条件
├── 待验证问题
└── 来源
```

### 5.3 临床数据规范

临床数据必须同时保存：数据截止日期、样本量、入组标准、治疗线数、生物标志物状态、随访时间、剂量与给药方案、ORR/DCR/DoR/PFS/OS、≥3 级 TRAE/SAE/停药率、单臂或随机对照、是否独立评审、数据来源（会议摘要/论文/说明书）。

跨试验比较统一标记为**非头对头比较**，不得直接得出确定性优劣结论。

### 5.4 临床成功概率

采用分层判断：低、中低、中、中高、高。如需用于 rNPV，给出概率区间及上下行情景，不把主观概率包装成客观事实。

评估维度：生物学验证、前期证据、试验质量、疗效优势、安全性、开发路径、竞争变化、执行能力。

## 6. 靶点与技术平台

首期预计建立 10–14 个核心概念或赛道页：

**肿瘤与血液瘤**：PD-1/PD-L1、BTK、CD19 CAR-T、BCMA CAR-T、Claudin 18.2、HER2 ADC、TROP2 ADC、双特异性抗体、ADC 技术平台、细胞凋亡通路

**自免与代谢**：IL-17 与自身免疫疾病、TSLP 与炎症通路、GLP-1 及多受体激动剂、B 细胞靶向治疗

最终页面由重点公司实际核心资产反向决定，避免缺少投资关联的孤立页面。

## 7. 适应症与诊疗路径

`15_消费场景` 适配为疾病和诊疗场景，首期选择 5–7 个对重点公司估值影响最大的适应症：

- 非小细胞肺癌
- 乳腺癌
- 胃癌及胃食管结合部癌
- 淋巴瘤
- 多发性骨髓瘤
- 银屑病及炎症性疾病
- 肥胖与代谢疾病

每页覆盖：流行病学、患者分层、当前标准疗法、治疗线次、诊疗路径、未满足需求、支付与医保、相关药物和公司、市场空间假设。

## 8. 估值体系

### 8.1 已商业化公司

根据业务成熟度组合使用：PE/PEG、EV/Sales、SOTP 分部估值、已上市产品现金流折现、核心在研管线 rNPV、净现金或净负债调整。

### 8.2 Biotech 与研发型公司

```
公司价值 = 已上市产品价值 + Σ管线rNPV + 平台价值 + 净现金 - 管理与融资折价

管线rNPV = Σt [风险调整后现金流t / (1+r)^t] - 剩余研发投入现值
```

每个估值必须列出：目标患者数量、渗透率、治疗周期、药品价格与医保折扣、销售峰值、毛利率和销售费用、上市时间、专利或市场独占期限、临床及监管成功概率、折现率、权益比例与分成条款、股本、净现金、币种及汇率日期。

### 8.3 输出方式

不提供缺少依据的单点目标价，而是提供：悲观/基准/乐观三种情景、核心假设敏感性、当前市值隐含预期、市场预期与知识库判断的差异、可能导致估值失效的证伪条件。

## 9. AkShare 数据接入

AkShare 主要承担行情和标准化财务数据补全。

优先获取：A 股及港股历史行情、总市值/流通市值、市盈率/市销率/市净率、资产负债表/利润表/现金流量表、研发费用及财务比率、股本变化、汇率和无风险利率。

每次取数记录：provider、interface、symbol、adjustment、currency、retrieved、period_end、cross_checked。

质量规则：
1. AkShare 是数据获取渠道，不自动等于 high 证据
2. 关键财务数字需与年报或交易所公告交叉验证
3. 估值使用的股价与市值必须注明交易日期
4. 港股需记录股本口径和币种，避免港元市值直接与人民币现金相加
5. 接口缺失或异常时保留空值并进入验证日志
6. 若当前环境无 AkShare skill，使用 AkShare 官方 Python 包标准接口

## 10. 催化剂跟踪器

统一的 `创新药催化剂日历`，覆盖未来 12–18 个月。

字段：公司、管线、事件类型、适应症/试验、预期窗口、时间来源、市场预期、成功标准、失败标准、影响等级、状态、最后核验日。

"公司预计"与"知识库推断"严格分开。没有公司指引时只写时间区间，不伪造精确日期。

## 11. 证据与时间管理

### 11.1 声明级证据

重要结论的关键数据行附带：来源、发布日期、数据截止日、证据等级、事实/推断/假设、最近核验日。

### 11.2 时间敏感标签

- **静态知识**：作用机制、制度框架
- **低频数据**：年报财务、患者规模
- **中频数据**：管线阶段、医保状态
- **高频数据**：股价、市值、催化剂和临床事件

高频数据超过设定期限会标记为可能过期。

### 11.3 未来信息限制

只有能够从公开来源核验的信息才写成事实。无法检索或尚未正式披露的内容必须留空、标记"待验证"、或保留最近可核验的数据并注明截止日。

## 12. 数据来源优先级

**临床与监管**：NMPA/CDE/FDA/EMA > ClinicalTrials.gov/中国药物临床试验登记 > 同行评议论文 > 会议原始摘要 > 公司公告和演示材料 > 新闻及二手转述

**财务与市场**：交易所公告/年报/中报 > 公司投资者关系材料 > AkShare > 权威金融数据平台 > 媒体报道

**市场规模**：优先使用患者数量、渗透率、价格和份额进行自下而上估算；第三方报告仅作交叉验证。

### 12.1 数据冲突处理

- 同时保留两个数值及各自口径
- 优先选择更高证据等级及更晚数据截止日的来源
- 区分试验更新、分析集变化、汇率和会计口径造成的差异
- 在验证日志中建立冲突项
- 冲突解决前降低证据等级

## 13. 更新工作流

**每周**：更新股价/市值/估值倍数、检查催化剂状态、检查监管和临床试验状态变化、记录重大 BD 与数据读出

**每月**：更新重点公司比较表、更新核心管线竞争格局、复核投资机会评分、清理已发生/延期/失效催化剂

**每季度**：更新财务数据和现金跑道、更新 SOTP/rNPV、复核公司覆盖优先级、重写多头/空头/证伪条件、形成季度投资复盘

**重大事件触发**：原始资料存入 02_原始资料/ → 更新管线页 → 更新公司页 → 更新竞品和靶点页 → 更新催化剂状态 → 更新估值假设 → 验证日志与操作日志留痕

## 14. 首期交付规模

目标约 70 页，允许根据可核验资料在 60–80 页内调整：

| 模块 | 预计页数 |
|---|---:|
| 全局文件、导航与模板 | 7 |
| 新手路线、行业主页、价值链与研究框架 | 5 |
| 公司筛选、15 家公司及横向比较 | 18 |
| 核心管线 | 20–24 |
| 靶点、机制与技术平台 | 10–12 |
| 适应症和诊疗路径 | 5–7 |
| 机会、风险、估值、催化剂与验证 | 7–9 |
| 来源索引与跟踪器 | 3–4 |

## 15. 验收标准

**结构**：规定目录、4 个全局文件和 9 个最小页面全部存在；总页面 60–80 页；15 家重点公司均有独立页面；核心公司至少链接 1 条独立管线。

**内容**：所有页面具备完整 YAML frontmatter；所有公司页包含财务、管线、BD、催化剂、估值和风险；所有管线页包含临床证据、竞品比较和跨试验比较限制；所有机会有验证问题；所有重大风险有证伪或监控标准。

**证据**：关键数据有来源和截止日；无来源的确定性声明数量为零；未来事件不写成已发生事实；AkShare 关键财务数据有交叉验证状态；数据冲突进入验证日志。

**链接**：每个知识页面至少有 2 个有效双链；不存在断链；不存在孤立页面；公司、管线、靶点、适应症能够双向导航。

**可维护性**：导航首页显示关键数据快照和系统状态；索引覆盖全部页面；操作日志记录初始化、资料填充和健康检查；跟踪器提供更新频率、来源和最近核验日期。
