# 中国生物制药

## 一句话投资判断

中国生物制药以肝病与肿瘤成熟产品组合提供稳定现金流底座，安罗替尼 联合疗法拓展与 BD 出海是估值上行的核心驱动力，但仿制药/集采压力与创新管线尚未形成第二增长曲线是主要风险。

## 公司定位与类型标记

- **定位**：覆盖肿瘤、肝病、呼吸与心脑血管的综合制药企业，正由仿制药/成熟产品驱动转向创新管线驱动。
- **类型**：**核心型**；成熟现金流 + 创新转型。
- **上市地/币种**：港交所 1177.HK；财务为人民币，市值为港币。

## 核心投资逻辑

1. 安罗替尼（福可维®）是中国自研小分子抗血管生成药物的标杆，联合 PD-1 等免疫疗法拓展大适应症。[来源：公司年报/NMPA]
2. 肝病领域（恩必普 等）和呼吸领域提供稳定现金流，降低 Biotech 式烧钱风险。[来源：公司年报]
3. 多恩达（TQB209）等创新管线逐步进入后期，提供增量期权。
4. BD 能力逐步验证，潜在 License-out 提供估值重估可能。
5. 正大天晴与北京泰德两大平台覆盖肿瘤与慢病，协同但结构复杂。

## 商业化能力

- 正大天晴和北京泰德在中国肝病与肿瘤领域拥有深厚医院覆盖与品牌认知。[来源：公司年报]
- 安罗替尼上市后放量路径验证商业化执行力。
- **推断（high）**：成熟产品现金流是区别于纯 Biotech 的核心优势；但仿制药/集采对利润率持续施压。

## 研发平台与组织能力

- 研发投入逐年提升，正大天晴为集团核心创新引擎。
- 覆盖小分子、抗体与生物药；ADC 与新模态布局早期。
- **推断（medium）**：管线广度尚可，但差异化与全球竞争力需更多后期数据验证。

## BD 与合作网络

- 安罗替尼联合疗法与多家 PD-(L)1 企业合作。
- 潜在 License-out 交易为估值重估催化剂。
- **推断（low）**：BD 能力尚处早期，需用实际交易首付款与里程碑验证。

## 估值框架

- **方法**：SOTP。成熟产品 DCF + 安罗替尼联合疗法 rNPV + 后期管线 rNPV + 净现金。
- **三情景**：悲观看仿制药加速下滑且联合疗法失败；基准看成熟业务稳健 + 安罗替尼新适应症获批；乐观看 BD 出海 + 多条管线成功。
- **敏感性**：仿制药衰退速度、安罗替尼联合疗法成功概率、BD 首付款与里程碑。
- **当前市值隐含预期（推断，medium）**：市场给予转型溢价但尚不充分；隐含安罗替尼增长预期温和。

## 核心风险

- 仿制药/集采持续压制利润，创新药放量不够快。
- 安罗替尼联合疗法 III 期失败或竞争性联合方案率先获批。
- 管线差异化不足，"me-too/me-better"风险。
- BD 出海不及预期或条款不佳。
- 子公司结构复杂，管理效率与激励一致性存疑。

## 多头论点与空头论点

| 多头 | 空头 |
|---|---|
| 成熟产品现金流提供安全垫 | 仿制药集采持续侵蚀利润 |
| 安罗替尼联合疗法若成功可打开大适应症 | 联合疗法竞争激烈 |
| BD 出海提供估值重估空间 | BD 能力尚未充分验证 |
| 正大天晴研发平台有产出潜力 | 管线差异化不突出 |

## 证伪条件

- 安罗替尼核心联合 III 期失败且无替代增长驱动力。
- 创新药收入占比连续两个报告期停滞或下降。
- 仿制药收入加速下滑且利润率显著恶化。
- 现金流由正转负且持续。

## 事实

- 安罗替尼已在中国获批多个适应症，是中国自研小分子抗肿瘤药标杆。[来源：NMPA]
- 公司通过正大天晴和北京泰德覆盖肝病与肿瘤市场。[来源：公司年报]

## 推断

- **high**：成熟产品现金流是核心下行保护。
- **medium**：估值弹性来自安罗替尼联合疗法与 BD 出海。
