# 诺诚健华

## 一句话投资判断

诺诚健华已用 [[奥布替尼]] 建立血液瘤商业底座，并把高选择性 BTK 能力延伸到一线治疗和自身免疫；估值上行依赖奥布替尼持续放量、TYK2/BTK 自免形成第二曲线，主要风险是收入集中、全球合作波折和多项目现金消耗。

## 公司定位与类型标记

- **定位**：聚焦血液肿瘤、自身免疫和实体瘤的小分子/抗体创新药公司，具备发现、临床、生产和商业化闭环。
- **类型**：**成长型 + 平台型**；奥布替尼商业化降低纯临床风险，后续自免资产仍具有事件属性。
- **上市地/币种**：上交所科创板 688428.SH、港交所 9969.HK；需统一 A/H 总股本、人民币财务与不同市场价格。

## 核心投资逻辑

1. [[奥布替尼]]已在中国获批 r/r CLL/SLL、r/r MCL、r/r MZL 及一线 CLL/SLL 等适应症，并进入国家医保目录，是收入与研发平台的核心验证。[来源：NMPA、国家医保局、公司官网]
2. 公司官网截至 2026-07 披露一线 CLL/SLL III 期结果发表于 STTT，说明奥布替尼正从复发难治市场向前线扩展；具体效应量应在管线页引用论文原文。[来源：公司官网/论文]
3. [[ICP-332]]、ICP-488等 TYK2/JAK1 自免资产与奥布替尼 SLE 等研究，有望把口服激酶平台从血液瘤延伸至更大慢病市场。
4. 早期 ADC/实体瘤扩张提供期权，但在出现人体 PoC 前不宜与成熟奥布替尼等权估值。

|---|---|---|---|

## 商业化能力

- 奥布替尼已纳入医保并覆盖多个血液瘤适应症，商业团队可在血液科中心共享渠道。
- 一线适应症扩大患者池和治疗持续时间，但与泽布替尼、伊布替尼等竞争时，真实份额取决于指南、医生经验、价格和长期安全性。
- Tafasitamab 可补充 DLBCL 产品组合，但区域准入、联合用药成本和患者规模决定贡献。
- **推断（medium）**：血液瘤渠道具规模效应；若自免产品上市，则需建立皮肤科/风湿科新渠道，销售费用不会完全复用。

## 研发平台与组织能力

- 创始团队具结构生物学与药物研发背景，公司建立从创新、临床、商业化到生产的完整平台。[来源：公司官网]
- 高选择性激酶设计是核心能力；奥布替尼的多适应症和长期暴露数据构成最强验证。
- 2026-07 公司披露 CDH17 ADC ICP-B208 首例给药，显示平台向 ADC 扩展，但该平台尚处早期。[来源：公司新闻]
- **推断（medium）**：平台溢价应主要给予激酶发现和临床转化；ADC 在首个人体数据前仅计研发期权。

## BD 与合作网络

- 曾与 Biogen 就奥布替尼多发性硬化全球权益合作，后续合作终止/权利回归对全球开发路径和会计产生影响；应以双方终止公告及年报为准。
- 从 Incyte 获得 tafasitamab 大中华区权益，补充血液瘤商业组合。[来源：公司公告]
- **推断（medium）**：权利回归提升潜在全价值，也恢复全部开发成本与执行风险；不能简单视作利好或利空。

## 估值框架

- **方法**：奥布替尼中国分适应症 DCF + 海外/自免 rNPV + TYK2 资产 rNPV + tafasitamab 区域价值 + 早期平台期权 + 净现金。
- **关键假设**：一线 CLL/SLL/MCL/MCD-DLBCL 成功率、医保净价、治疗时长、BTK 份额、自免患者与渗透率、全球权益、销售费用和稀释股本。
- **三情景**：悲观为血液瘤竞争压价且自免失败；基准为奥布替尼在中国持续增长、一个自免资产成功；乐观为一线血液瘤建立领先份额且 TYK2/BTK 自免全球化。
- **敏感性**：奥布替尼峰值销售与衰减、一个自免适应症成功概率、销售费用率和净现金最关键。
- **当前市值隐含预期（推断，medium）**：市场对奥布替尼商业价值已有基础定价，自免成功是主要期权；2026-07-19 A/H 总市值与净现金需同日重算。

## 核心风险

- 收入高度集中于奥布替尼，BTK 竞品、医保降价或专利变化影响大。
- 中国 CLL/SLL 患病结构与欧美不同，全球市场数据不能直接外推中国峰值。
- 自免慢病需要更长安全性观察，感染、实验室异常和长期依从性可能限制渗透。
- Biogen 合作终止后，全球开发资金与执行更多回到公司。
- 管线扩张至 ADC 和实体瘤可能分散资源，持续亏损带来融资风险。

## 多头论点与空头论点

| 多头 | 空头 |
|---|---|
| 奥布替尼多适应症获批并进入医保，商业底座清晰 | 单产品收入集中且 BTK 赛道拥挤 |
| 一线治疗提高患者规模和疗程价值 | 竞品已有全球规模与指南优势 |
| TYK2/BTK 自免可打开更大市场 | 慢病安全性和销售渠道要求更高 |
| 激酶平台成熟、ADC 提供新期权 | ADC 平台尚无人体验证，项目过多消耗现金 |

## 证伪条件

- 奥布替尼销售连续多个报告期低于行业和适应症扩张所支持的水平。
- 一线 CLL/SLL/MCL 或 MCD-DLBCL 关键注册项目失败或明显延迟。
- ICP-332、ICP-488 或 BTK 自免连续出现疗效不足/长期安全性问题。
- 经营现金消耗显著加速且无高质量 BD，导致折价融资和股本摊薄。

## 事实

- 奥布替尼已在中国和新加坡获批，并进入中国国家医保目录。[来源：公司官网、监管/医保文件]
- 公司官网列示 13 个临床阶段创新药，覆盖血液瘤、自免和实体瘤。[来源：公司投资者关系页面]
- 2026-07-13 公司披露一线 CLL/SLL III 期结果发表；2026-07-06 披露 ICP-B208 中国首例给药。[来源：公司官网]

## 推断

- **high**：奥布替尼仍是未来两年收入、现金流和研发信用的核心。
- **medium**：自免资产若有一个注册成功，公司估值框架将从血液瘤单品转向多专科平台。
- **low**：ADC 等新模态在人体 PoC 前不应获得显著平台溢价。
