# 亚盛医药

## 一句话投资判断

亚盛医药以 [[奥雷巴替尼]] 建立中国商业化底座、以 lisaftoclax（[[APG-2575]]）争取全球 BCL-2 价值；投资弹性来自细胞凋亡平台和 Takeda 等合作验证，但收入规模、核心后期试验与持续研发投入使其仍是高波动事件型 biotech。

## 公司定位与类型标记

- **定位**：聚焦蛋白—蛋白相互作用和细胞凋亡通路的小分子创新药公司，重点覆盖 BCL-2、IAP、MDM2-p53 与耐药 CML。
- **类型**：**平台型 + 事件型 + 高风险型**；已有产品使其不再是纯临床阶段公司，但尚未形成多产品稳定盈利。
- **上市地/币种**：港交所 6855.HK；财务以人民币/港币披露，估值须记录港币市值、人民币净现金和完全摊薄股本。

## 核心投资逻辑

1. [[奥雷巴替尼]]是中国获批的第三代 BCR-ABL TKI，为 T315I 突变等耐药 CML 患者提供治疗选择，并已进入国家医保目录。[来源：NMPA、国家医保局、公司年报]
2. [[APG-2575]]（lisaftoclax）是下一价值核心；其竞争力需由随机/注册性数据、肿瘤溶解综合征管理和全球注册路径验证，而不能仅凭早期 ORR 比较。
3. Takeda 于 2024 年对奥雷巴替尼达成选择权/许可安排并进行股权投资，构成外部验证和潜在全球化路径。[来源：亚盛医药、Takeda 公告]
4. 细胞凋亡平台覆盖多个机制，但平台估值应以第二个获批产品或独立后期成功资产为条件。

## 产品与管线组合

| 资产 | 靶点/形式 | 阶段（截至 2026-07-19） | 投资意义 |
|---|---|---|---|
| [[奥雷巴替尼]]（olverembatinib，耐立克） | 第三代 BCR-ABL TKI | 中国已上市、医保覆盖；全球开发/合作推进 | 商业底座、全球 BD 锚 |
| [[APG-2575]]（lisaftoclax） | BCL-2 抑制剂 | 多项血液瘤后期/注册性开发 | 最大在研资产 |
| APG-1252（pelcitoclax） | BCL-2/BCL-xL 抑制剂 | 临床开发 | 实体瘤/血液瘤组合期权 |
| APG-115（alrizomadlin） | MDM2-p53 抑制剂 | 临床开发 | p53 通路差异化，证据待加强 |
| APG-1387（dorapimod） | IAP 抑制剂 | 临床开发 | 细胞凋亡平台延展 |
| APG-2449 | FAK/ALK/ROS1 抑制剂 | 临床开发 | 精准肿瘤补充资产 |

> 临床疗效、安全性、样本量与竞品横向比较应迁移至独立管线页。不同疾病亚型、既往治疗和联合方案之间均为**非头对头比较**。

## 商业化能力

- 奥雷巴替尼在中国获批后由信达生物参与商业推广；亚盛保留研发和约定经济权益。[来源：双方公告]
- 纳入医保有利于患者可及和销量，但净价下降、罕见突变患者识别与中心覆盖决定收入上限。
- **推断（medium）**：商业模式更接近“专业血液瘤产品 + 合作销售”，可降低固定销售费用，但亚盛对终端执行和收入确认的控制弱于完全自营模式。

## 研发平台与组织能力

- 公司长期研究蛋白—蛋白相互作用，围绕凋亡逃逸与耐药机制构建小分子管线。
- 奥雷巴替尼从发现到获批证明了 CMC、临床与监管执行；APG-2575 将决定平台能否复制到更大患者群。
- **推断（medium）**：BCL-2 已是临床验证靶点，风险主要从“机制是否有效”转为差异化、安全管理、组合策略和商业竞争。

## BD 与合作网络

- 与信达生物就奥雷巴替尼在中国达成商业合作。
- 2024 年与 Takeda 达成奥雷巴替尼相关选择权安排；Takeda 同时进行少数股权投资。具体选择权行使条件、区域、里程碑和后续分成以正式公告为准。[来源：双方公告]
- 与 UNITY Biotechnology 等历史合作及学术网络为平台提供外部验证，但不应把合同总额等同确定收入。
- **推断（medium）**：Takeda 是否行权、何时行权及承担何种全球开发责任，是估值中比“headline 总金额”更重要的变量。

## 最新可核验财务

| 指标 | 最近可靠口径 | 说明 |
|---|---:|---|
| 商业收入 | 以 2024 年报为最近稳定可核验完整口径 | 主要来自奥雷巴替尼及合作；具体拆分见年报 |
| 归母净利润/亏损 | 仍处亏损期 | 研发、注册性试验和商业投入较高 |
| 研发费用 | 以 2024 年报审计口径为准 | 需区分核心后期项目与其他平台投入 |
| 现金及银行结余 | 受 2024 年 Takeda 股权投资/合作现金增强 | 可用现金需扣除受限资金并结合后续融资 |
| 2025 年完整财务 | **待验证** | 未取得可稳定复核的完整一手年报数字，不填二手估算 |
| 现金跑道 | 约 18–30 个月（推断，low） | 对 APG-2575 试验规模、BD 现金和融资节奏高度敏感 |

## 估值框架

- **方法**：奥雷巴替尼中国利润/分成 DCF + 海外权益/里程碑 rNPV + APG-2575 分适应症 rNPV + 其他早期资产期权 + 净现金。
- **关键假设**：CML 可治疗患者、T315I/耐药人群占比、医保后净价、信达分成、Takeda 权益、APG-2575 成功概率、全球峰值份额、上市时间、折现率与股本稀释。
- **三情景**：悲观为奥雷巴增速放缓且 APG-2575 注册失败；基准为奥雷巴稳定增长、APG-2575 至少一个血液瘤适应症成功；乐观为 Takeda 全球化落地且 BCL-2 多适应症获批。
- **敏感性**：APG-2575 成功概率和经济权益、Takeda 行权、持续融资稀释最关键。
- **当前市值隐含预期（推断，medium）**：市场通常同时交易 APG-2575 读出与 BD 选择权；2026-07-19 市值、股本和净现金待同日口径重算。

## 核心风险

- APG-2575 与 venetoclax 及其他 BCL-2/BCL-xL 资产竞争，差异化可能不足。
- 小样本、单臂或联合治疗数据存在选择偏差；跨试验比较不能证明优效。
- 奥雷巴替尼目标患者相对集中，医保降价和竞争影响峰值收入。
- Takeda 选择权不等同已完成全球授权，行权与经济条款存在不确定性。
- 持续亏损和多项目并行可能带来融资及股本稀释风险。

## 多头论点与空头论点

| 多头 | 空头 |
|---|---|
| 已有获批药物与医保准入，非纯早期 biotech | 商业规模尚不足覆盖研发投入 |
| BCL-2 是已验证大靶点，APG-2575 有全球潜力 | 竞争强且差异化需随机数据验证 |
| Takeda/信达合作降低商业和全球执行门槛 | 合作条款、选择权和分成降低可得价值 |
| 细胞凋亡平台提供多资产期权 | 多数后续资产尚未形成确定 PoC |

## 证伪条件

- APG-2575 核心注册性试验未达主要终点，或安全性不支持目标用法。
- Takeda 不行权且公司无法找到等质量全球伙伴，海外路径显著延后。
- 奥雷巴替尼连续多个报告期销量/收入停滞且无法由新增适应症补偿。
- 现金消耗显著快于计划并以大幅折价融资，导致每股管线价值下降。

## 事实

- 奥雷巴替尼已在中国获批并进入国家医保目录。[来源：NMPA、国家医保局]
- 公司拥有 BCL-2、IAP、MDM2-p53 等凋亡相关临床管线。[来源：公司管线]
- 亚盛与信达、Takeda 建立了围绕核心资产的商业或全球合作安排。[来源：公司公告]

## 推断

- **high**：APG-2575 是决定公司从单产品 biotech 向平台型公司跃迁的核心变量。
- **medium**：奥雷巴替尼可提供估值底座，但单独难覆盖全部平台与长期研发成本。
- **low**：Takeda 交易在正式行权前不应按完整全球许可价值计入基准情景。
