# 创新药 player map

> **资料截止日：2026-07-19。** 分类是研究标签，不是永久事实；精确财务、阶段和交易条款以交易所、SEC 与公司年报为准。

## 一句话判断

中国创新药玩家已从“传统药企 vs. Biotech”分化为**综合全球化、商业化平台、技术平台、专科成长与现金流/事件驱动**多种模式，比较时必须同时看管线质量、商业兑现、BD、现金安全和估值可跟踪性。

## 事实

### 1. 六维筛选模型

| 维度 | 权重 | 高分标准 |
|---|---:|---|
| 管线质量 | 25% | 人体/随机证据强、差异化、适应症价值高、权益清晰 |
| 商业化能力 | 20% | 经常性产品收入、医保/进院执行、专科销售效率、全球覆盖 |
| 研发平台 | 15% | 第二/第三资产重复产出，CMC 与临床执行可复用 |
| BD 能力 | 15% | 高质量伙伴、条款可验证、持续推进而非仅高 headline value |
| 财务安全 | 15% | 现金覆盖关键读出、经营现金改善、融资稀释可控 |
| 投资可跟踪性 | 10% | 披露充分、催化剂明确、估值锚和证伪条件可量化 |

### 3. 竞争位置分组

#### A. 综合全球化与平台底座

[[百济神州]]、[[恒瑞医药]]：优势是组合、临床与商业化一体化；估值应看持续产品现金流、全球费用率与在研 rNPV，不能用单资产 PoS 代表全部公司。

#### B. 本土商业化与创新转型

[[信达生物]]、[[中国生物制药]]、[[石药集团]]、[[三生制药]]：优势是医院与现金流；关键是创新产品是否提高收入质量，以及传统业务是否拖累增长。BD 可加速转型，但应拆交易条款。

#### C. 技术平台与全球伙伴验证

[[康方生物]]、[[科伦博泰]]、[[传奇生物]]：分别以双抗、ADC、CAR-T 获得外部验证；平台溢价只有在第二/第三个独立资产成功时才稳固，且合作方控制与分成影响经济价值。

#### D. 专科成长与全球/区域商业化

[[再鼎医药]]、[[和黄医药]]、[[诺诚健华]]、[[亚盛医药]]：专科能力和资产聚焦有助执行，但规模、权益分散和后续管线接续决定估值上限。

#### E. 商业兑现与融资敏感

[[荣昌生物]]、[[君实生物]]：已有研发与获批基础，核心矛盾是销售现金流能否覆盖持续研发；应先测 runway 和稀释，再谈远期管线总价值。

### 4. 技术赛道映射

| 赛道 | 重点公司 | 研究重点 |
|---|---|---|
| 双特异性抗体 | [[康方生物]]、[[恒瑞医药]]、[[百济神州]] | 靶点组合、头对头设计、安全性、给药与全球权益 |
| ADC | [[科伦博泰]]、[[荣昌生物]]、[[恒瑞医药]]、[[石药集团]] | 抗体/linker/payload、治疗窗、旁观者效应、CMC |
| 细胞治疗 | [[传奇生物]] | 产能、周转时间、中心覆盖、长期安全、下一代竞争 |
| 小分子靶向 | [[和黄医药]]、[[诺诚健华]]、[[亚盛医药]] | 选择性、耐药、组合策略、全球对照与专利 |
| 肿瘤免疫 | [[信达生物]]、[[君实生物]]、[[康方生物]] | PD-(L)1 后差异化、组合价值、价格竞争 |
| 自免/代谢 | [[信达生物]]、[[荣昌生物]]、[[诺诚健华]]、[[恒瑞医药]] | 大患者池、长期安全、支付、产能和依从性 |

### 5. 公司类型与估值适配

| 公司类型 | 首选方法 | 不宜做法 |
|---|---|---|
| 多产品盈利/接近盈利 | SOTP + 产品 DCF + 管线 rNPV + 净现金 | 只用单一 PS 忽略收入质量 |
| 平台 + 核心合作资产 | 权益拆分 rNPV + 已收现金 + 审慎平台期权 | 全额计入交易潜在总额 |
| 单/少资产临床期 | 情景 rNPV + 融资稀释 + 失败残值 | 用同行市值直接类比 |
| 成熟药企转型 | 传统业务现金流 + 创新资产 SOTP | 把全部研发项目等权相加 |
| License-in 商业化 | 产品地区 DCF + 合同义务 + 自研期权 | 忽略 royalty、里程碑和剩余权益 |

## 推断

- **medium**：最可能形成长期平台溢价的是能够重复产出全球随机证据、保留合理权益并拥有商业现金流的公司，而不是管线列表最长者。
- **medium**：15 家公司中，合作方集中度是被低估的共同风险；单一国际伙伴可能同时影响临床优先级、里程碑和估值情绪。
- **low**：传统药企与 Biotech 的边界将继续模糊，分类应每年随创新收入、全球权益和现金流更新。
