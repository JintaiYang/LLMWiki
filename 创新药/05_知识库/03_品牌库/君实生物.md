# 君实生物

## 一句话投资判断

君实生物凭 [[特瑞普利单抗]] 完成中国 PD-1 商业化并实现首个美国获批的中国自主研发 PD-1，但国内同质化竞争、海外伙伴兑现和持续亏损压低确定性；估值重建需要海外收入、[[昂戈瑞西单抗]] 等第二产品与现金流同步改善。

## 公司定位与类型标记

- **定位**：覆盖抗体发现、临床、生产与商业化的 A+H 创新药公司，重点布局肿瘤、自身免疫、代谢与神经系统疾病。
- **类型**：**成长型 + 高风险型**；特瑞普利建立商业底座，第二增长曲线尚在验证。
- **上市地/币种**：上交所科创板 688180.SH、港交所 1877.HK；估值需统一 A/H 股本、人民币财务和不同市场价格。

## 核心投资逻辑

1. [[特瑞普利单抗]]（拓益/LOQTORZI）已在中国多适应症获批，并于 2023-10 获 FDA 批准用于鼻咽癌，证明公司具有从中国临床证据走向美国注册的能力。[来源：NMPA、FDA]
2. FDA 审评引用 JUPITER-02：一线复发/转移鼻咽癌中，特瑞普利联合化疗相较安慰剂联合化疗改善 PFS 和 OS；这是海外标签的核心证据。[来源：FDA 批准公告]
3. [[昂戈瑞西单抗]]（PCSK9）代表肿瘤外商业化，若能在降脂市场形成差异化，可降低 PD-1 单资产风险。
4. 研发广度较大，但在资本约束下，价值取决于是否聚焦能产生注册、BD 或销售的少数项目，而非管线数量。

## 产品与管线组合

| 资产 | 靶点/形式 | 阶段（截至 2026-07-19） | 投资意义 |
|---|---|---|---|
| [[特瑞普利单抗]]（toripalimab，拓益/LOQTORZI） | PD-1 单抗 | 中国多适应症上市；美国鼻咽癌上市 | 核心收入、全球化验证 |
| [[昂戈瑞西单抗]]（JS002） | PCSK9 单抗 | 中国获批/商业化 | 第二商业产品、肿瘤外扩张 |
| JS005 | IL-17A 单抗 | 自免临床开发 | 银屑病等自免期权 |
| JS006 | TIGIT 单抗 | 肿瘤联合临床 | 高竞争机制，价值待随机数据 |
| JS207 等多抗/ADC | 新型抗体 | 早期临床/临床前 | 平台期权，低权重计值 |

## 商业化能力

- 公司在中国自建肿瘤商业化体系，特瑞普利纳入国家医保后提高可及性，同时面临 PD-1 价格和医院准入竞争。
- 美国 LOQTORZI 由 Coherus 等合作体系商业化；伙伴商业资源、库存、净价与适应症拓展决定君实可得收入。[来源：君实与 Coherus 公告]
- 昂戈瑞西进入心血管慢病市场后，需要与成熟 PCSK9 和降脂药物竞争，渠道与患者长期依从性不同于肿瘤药。
- **推断（medium）**：海外获批的战略意义高于短期财务贡献；在鼻咽癌相对小适应症之外扩大标签，才可能形成显著利润支柱。

## 研发平台与组织能力

- 建立从分子发现、转化研究、临床到大规模抗体生产的平台，并经历中美监管申报。
- PD-1 的成功证明单抗开发能力，但 TIGIT、多抗及自免项目能否复制仍需独立人体证据。
- **推断（medium）**：未来研发效率应以“每亿元研发投入产生的关键读出/获批/BD”衡量，削减低优先级项目可能比维持管线数量更重要。

## BD 与合作网络

- 与 Coherus 围绕特瑞普利美国/加拿大权益开展合作；交易后续曾发生资产和权利调整，具体区域、里程碑与 royalty 应以最新正式文件为准。
- 与 Dr. Reddy's 等伙伴推进部分海外市场，国内亦存在商业与联合开发安排。[来源：公司公告]
- **推断（medium）**：多区域伙伴可降低自建成本，但也造成收入确认、库存和执行透明度较低；需逐份合同追踪而非汇总“海外覆盖国家数”。

## 估值框架

- **方法**：特瑞普利中国产品 DCF + 海外分成/里程碑 rNPV + 昂戈瑞西 DCF + 自免/其他后期 rNPV + 净现金减净债务。
- **关键假设**：中国医保净价和份额、美国 NPC 患者数与净价、伙伴分成、标签拓展概率、昂戈瑞西患者依从性、销售费用、研发聚焦、上市时间与股本稀释。
- **三情景**：悲观为国内 PD-1 下滑、海外规模有限且持续融资；基准为国内稳定、美国 NPC 渐进放量和第二产品贡献；乐观为海外新增适应症与自免/代谢产品形成第三支柱。
- **敏感性**：中国特瑞普利峰值/衰减率、海外经济权益、年度现金消耗和完全摊薄股本最关键。
- **当前市值隐含预期（推断，medium）**：市场给予海外批准一定平台信用，但持续亏损和 PD-1 竞争形成折价；2026-07-19 A/H 市值应分别取价后合并股本测算。

## 核心风险

- 中国 PD-1 市场高度竞争、医保降价和同适应症拥挤压制价格及份额。
- 海外鼻咽癌市场相对有限，合作伙伴执行或资本能力变化影响放量。
- 昂戈瑞西面对成熟降脂标准治疗，商业教育和长期依从性不确定。
- 持续亏损、研发项目较多可能导致融资稀释和现金跑道压力。
- 新型免疫组合存在机制失败与安全性风险，跨试验早期信号不可直接外推。

## 多头论点与空头论点

| 多头 | 空头 |
|---|---|
| 首个获 FDA 批准的中国自主研发 PD-1 具全球注册信用 | 美国首发适应症患者规模有限 |
| 国内多适应症、医保和生产体系构成收入底座 | PD-1 同质化和价格竞争激烈 |
| PCSK9、自免与下一代抗体提供第二曲线 | 第二产品尚未证明足以覆盖费用 |
| A/H 融资渠道和合作网络较完整 | 持续亏损带来显著每股稀释风险 |

## 证伪条件

- 特瑞普利中国收入连续显著下降，新增适应症无法抵消降价与份额流失。
- LOQTORZI 海外销售长期低于鼻咽癌患者池和中心覆盖所支持的水平。
- 昂戈瑞西商业化两年以上仍未形成有意义收入或单位销售效率明显偏低。
- 研发费用未随聚焦改善、现金快速下降并被迫大幅折价融资。

## 事实

- FDA 于 2023-10-27 批准 toripalimab-tpzi 联合顺铂/吉西他滨用于一线复发或转移鼻咽癌，并批准单药用于含铂治疗后进展患者。[来源：FDA]
- JUPITER-02 为 289 例随机、双盲、安慰剂对照试验，FDA 公告披露 PFS 与 OS 均有统计学改善。[来源：FDA]
- 特瑞普利已在中国多适应症获批并进入医保目录。[来源：NMPA、国家医保局]

## 推断

- **high**：特瑞普利仍是未来两年收入和估值主导资产。
- **medium**：美国批准提高平台可信度，但短期财务贡献取决于合作方销售而非批准本身。
- **low**：在昂戈瑞西或自免资产形成稳定收入前，不宜假设公司已完成多产品转型。
