# 石药集团

## 一句话投资判断

石药集团以纳米制剂与递送平台为核心差异化能力，恩必普 等成熟产品提供现金流底座，mRNA/LNP 递送与 ADC 等新平台是估值上行期权；核心风险是恩必普等主力产品集采/仿制压力与创新管线尚未形成第二曲线。

## 公司定位与类型标记

- **定位**：以递送技术（纳米制剂、mRNA/LNP）为差异化核心、覆盖肿瘤、心脑血管、代谢与感染的综合性制药企业。
- **类型**：**核心型 + 平台型**；成熟现金流 + 递送平台创新。
- **上市地/币种**：港交所 1093.HK；财务为人民币，市值为港币。

## 核心投资逻辑

1. 恩必普（丁苯酞/NUBETA）为中国脑卒中领域重磅产品，长期提供稳定现金流，但专利到期与仿制进入是确定性风险。[来源：公司年报]
2. 多美素（脂质体阿霉素/DOXORUBICIN-LNP）和 津优力（PEG-rhG-CSF）依托纳米制剂平台，为肿瘤支持治疗领域标杆。[来源：公司年报]
3. mRNA/LNP 递送平台（与康宁杰瑞/信致等合作）切入疫苗与核酸药物，技术差异化显著但商业验证尚早。
4. ALMB-0168（ACL 抗体）、SYH2055 等创新管线进入临床后期，提供增长期权。
5. 成仿结合的经营模式降低单一管线风险。

## 商业化能力

- 恩必普在中国脑卒中领域品牌认知与医院覆盖深厚，但面临仿制竞争与医保谈判压力。[来源：公司年报]
- 多美素和津优力在肿瘤支持治疗领域市占率领先。
- **推断（high）**：成熟产品现金流是核心壁垒；但恩必普专利到期后收入下降斜率需密切跟踪。

## 研发平台与组织能力

- 纳米制剂与脂质体递送平台是核心差异化技术，已产出多美素等上市药。[来源：公司年报/专利]
- mRNA/LNP 递送平台为下一代技术方向，与康宁杰瑞/信致等合作开发。
- **推断（medium）**：递送平台价值需用第二款独立上市/授权产品验证可复制性。

## BD 与合作网络

- 与康宁杰瑞合作开发 mRNA 管线。
- 与信致等核酸药物企业合作。
- **推断（low）**：BD 出海案例尚少，递送平台的授权价值需用交易首付款验证。

## 估值框架

- **方法**：SOTP。成熟产品 DCF + 创新管线 rNPV + 递送平台期权 + 净现金。
- **三情景**：悲观看恩必普加速下滑且创新管线失败；基准看恩必普缓降 + ALMB-0168 获批；乐观看 mRNA 平台验证 + ADC 出海。
- **敏感性**：恩必普衰退速度、ALMB-0168 成功概率、mRNA 平台验证时点。
- **当前市值隐含预期（推断，medium）**：市场主要按成熟产品估值，递送平台期权尚未充分计入。

## 核心风险

- 恩必普仿制竞争与集采导致收入加速下降。
- mRNA/LNP 递送平台临床验证不及预期。
- 创新管线 PoC 失败或差异化不足。
- 递送技术保护（专利与 know-how）不足以阻止竞品。
- 成仿结合模式下仿制药利润持续萎缩。

## 证伪条件

- 恩必普收入连续加速下降且创新药无法补位。
- ALMB-0168 和 SYH2055 核心后期项目连续失败。
- mRNA/LNP 首次人体数据出现安全性或递送效率根本问题。
- 递送平台无法产出第二个独立商业化或授权产品。

## 事实

- 恩必普为中国脑卒中领域重磅产品，已上市多年。[来源：NMPA、公司年报]
- 石药拥有纳米制剂和 mRNA/LNP 递送技术平台。[来源：公司年报/专利]

## 推断

- **high**：成熟产品现金流是核心下行保护，但恩必普衰退是确定性事件。
- **medium**：递送平台期权是估值弹性的主要来源，但需要临床验证。
