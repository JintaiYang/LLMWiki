# 创新药验证日志

## 一句话判断
投资假设只有在预先写明成功/失败标准并用一手证据更新后才有价值；会议摘要、公司口径和非头对头比较只能形成阶段性结论。

## 事实
- ClinicalTrials.gov 提供试验状态、设计、终点和时间线，但结果发布与登记更新可能滞后，需与论文、会议摘要及监管标签交叉验证。[来源：https://clinicaltrials.gov/，核验 2026-07-19，证据 high]
- NMPA/CDE 与 FDA/Drugs@FDA 是监管结论的优先来源。[来源：https://www.nmpa.gov.cn/；https://www.cde.org.cn/；https://www.accessdata.fda.gov/scripts/cder/daf/，证据 high]

## 冲突与异常记录
| 冲突项 | 现象 | 处理 |
|---|---|---|
| 试验状态不同步 | 公司称“完成入组”，注册库仍为 recruiting | 同时保留两个日期，以更晚更新为准；待验证 |
| ORR 数值变化 | 数据截止日、分析集或独立评审口径不同 | 并列记录 n、cut-off、ITT/可评估集、BICR/研究者评估 |
| BD 总额与会计收入 | headline value 远高于当期现金收入 | 仅首付款计入已确认现金，其余按概率与时间折现 |
| 市场规模差异 | 第三方报告口径不透明 | 以患者漏斗×净价×渗透率自下而上，报告仅交叉验证 |
| 港股市值与人民币现金 | 币种、股本日不同 | 统一交易日、fully diluted 股本与汇率，差异未解决前降级证据 |

## 推断
- **中等证据**：越接近关键读出的资产，越应先固定失败标准，以避免事后修改叙事。
- **中等证据**：随机、盲法、对照、独立评审和成熟随访通常比单一高 ORR 更能提高证据等级。
