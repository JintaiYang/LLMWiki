# 创新药来源索引

## 一句话判断
来源可信度取决于它能证明什么：监管数据库可证明批准与标签，公司公告可证明公司披露，会议摘要可证明某次分析结果，但任何单一来源都不能包办全部投资结论。

## 可信度评级
- **A / high**：监管、法定披露、标签、审评文件、经审计财报；仍需确认适用口径。
- **B / medium-high**：注册库设计、同行评议论文、会议原始摘要；结果受设计和成熟度限制。
- **C / medium/low-medium**：券商、媒体、行业报告；用于交叉验证和发现线索。
- **D / low**：匿名纪要、社媒、未提供原始数据的公司叙事；只能进入“待验证”。

## 获取与归档规范
1. 保存标题、URL、发布日期、访问日、数据截止日、适用对象。
2. 临床数据保存 n、分析集、线次、标志物、随访、终点、安全性和是否 BICR。
3. 公司与合作方公告双向核对；BD 总额拆分首付款、里程碑、royalty、选择权。
4. PDF/网页失效时保留原始资料副本，但不改写原文。
5. 搜索引擎摘要不作为最终来源；网页无法访问时标“待验证”。

## 推断
- **高证据**：来源优先级不等于结论强度；高可信来源中的前瞻性预测仍只是预测。
- **中等证据**：同一临床结果若能被注册方案、会议原文、论文与监管文件串联，最有利于减少选择性披露风险。
