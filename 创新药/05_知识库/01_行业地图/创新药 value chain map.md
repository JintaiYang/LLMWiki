# 创新药 value chain map

> **资料截止日：2026-07-19。** 本页描述产业结构；单家公司实际权益、供应与合作关系必须回到合同和年报核验。

## 一句话判断

创新药价值链不是线性“研发—销售”，而是**证据、权益、现金和药品**四条流在发现、临床、监管、生产、支付与商业化之间反复重分配；投资者最容易高估的是远期权益，最容易低估的是失败成本与准入摩擦。

## 事实

### 1. 全景图

```text
患者/医生/支付方提出未满足需求
        ↓
基础研究 → 靶点验证 → 候选发现 → 临床前/CMC → IND
        ↓                         ↑
Biotech / Pharma ← CRO / 实验室 / 数据与模型 / 原料设备
        ↓
I期安全与剂量 → II期概念验证 → III期确证 → NDA/BLA
        ↓             ↕ License-in/out / 共同开发 / 并购
CDE技术审评 → NMPA批准与标签 → GMP生产/放行 → 流通
        ↓
医保/商保/自费 → 医院准入/双通道/DTP → 医生处方 → 患者治疗
        ↓
真实世界疗效、安全、续方和净收入反馈到研发、定价与再投资
```

监管边界以 [NMPA](https://www.nmpa.gov.cn/) 与 [CDE](https://www.cde.org.cn/) 为准；医保边界以 [国家医保局](https://www.nhsa.gov.cn/) 为准，均核验至 2026-07-19（high）。

### 2. 分环节价值与风险

| 环节 | 核心参与者 | 主要投入 | 可验证产出 | 价值捕获 | 核心风险 |
|---|---|---|---|---|---|
| 基础研究/靶点 | 高校、科研院所、Biotech | 人才、实验、数据、IP | 人体遗传/机制证据、专利 | IP许可、平台期权 | 转化失败、FTO |
| 药物发现 | Biotech、Pharma、AI/CRO | 筛选、设计、药化/抗体工程 | 候选物、体外/体内数据 | 管线权益、早期授权 | 可开发性、选择偏差 |
| 临床前/CMC | 药企、CRO/CDMO | 毒理、PK/PD、工艺与分析 | IND 支持包、可放大工艺 | 服务费、资产去风险 | 毒性、工艺、批次一致性 |
| 临床开发 | Sponsor、医院/PI、SMO/CRO、患者 | 试验费用、药物、中心、入组 | 安全、剂量、疗效和确证证据 | 管线 PoS 提升、里程碑 | 入组、终点、对照、数据质量 |
| 监管 | CDE、NMPA、申办方 | 申报、沟通、补充资料 | 受理、审评、批准、标签 | 获得市场准入权 | 延期、补试验、标签收窄 |
| 生产供应 | MAH、CMO/CDMO、原料/设备商 | 产能、验证、质量系统 | 稳定供货、批次放行 | 制造毛利/供应控制 | 良率、产能、冷链、召回 |
| 支付准入 | NHSA、地方医保、商保、医院 | 谈判、药经、预算、目录 | 支付资格、院内/双通道准入 | 可及患者增加 | 降价、进院慢、预算约束 |
| 商业化 | Pharma、CSO、医院、药房 | 医学事务、销售、渠道、患者服务 | 处方、持续治疗、净收入 | 产品毛利与现金流 | 竞争、合规、销售效率 |
| 上市后 | MAH、监管、医院 | IV期、药物警戒、真实世界研究 | 长期安全/有效、适应症扩展 | 生命周期价值 | 安全信号、撤回、专利到期 |

### 3. 四条关键流

#### 证据流

基础机制 → IND 支持数据 → I 期剂量/安全 → II 期 PoC → III 期确证 → 标签 → 真实世界证据。证据强度通常上升，但新数据可推翻旧判断；试验登记只证明设计/状态，不证明结果。[ClinicalTrials.gov](https://clinicaltrials.gov/)，核验日 2026-07-19（high for design）。

#### 权益流

- 自研自营：保留大部分经济权益，也承担全部研发、生产与销售成本。
- License-out：转让特定区域/适应症/资产权益，换取 upfront、里程碑、royalty 或利润分成。
- License-in：用现金/股权/里程碑取得权益，缩短组合建设，但承担外部资产和合同依赖。
- 共同开发/共同商业化：按区域、成本和利润约定分配；必须记录终止权、控制权、供应权。
- 并购：权益与组织一体化，但面临整合、商誉和关键人才流失。

[[科伦博泰]]、[[康方生物]]体现 License-out；[[再鼎医药]]体现 License-in/自研转型；[[百济神州]]、[[恒瑞医药]]更接近综合型全球开发。

#### 现金流

```text
股权/债务/经营现金/BD upfront
            ↓
早研 + 临床 + CMC + 产能 + 商业化
            ↓
产品净收入 + 里程碑 + royalty
            ↓
税费/销售分成/再投资/股东回报
```

headline value 不是现金；产品收入也应扣除折扣、返利、患者援助、渠道和销售成本。现金 runway 与关键催化剂的先后关系见 [[创新药 company comparison]]。

#### 药品与患者流

GMP 生产/放行 → 经销/冷链 → 医院或 DTP/双通道 → 诊断检测 → 医生决策 → 患者治疗 → 随访/续方。CAR-T 等复杂疗法还包含采集、生产、回输和中心资质，其瓶颈与口服药显著不同。

### 4. 价值池与议价权

| 价值来源 | 议价权增强条件 | 议价权削弱条件 |
|---|---|---|
| 靶点/资产权益 | 人体 PoC、差异化随机数据、全球权益清晰 | 同靶点拥挤、专利/安全不确定 |
| 平台 | 多个独立资产重复成功、工艺可复用 | 只有单一资产成功、资产高度相关 |
| 临床执行 | 入组快、数据质量高、全球多中心能力 | 患者资源冲突、终点/对照过时 |
| 生产 | 高壁垒工艺、稳定良率、稀缺产能 | 标准化产能过剩、质量问题 |
| 支付/渠道 | 明显临床价值、指南地位、可及网络 | 可替代药多、预算影响大 |
| 商业化 | 专科覆盖、医学事务、组合协同 | 单品销售、进院慢、费用率高 |
| BD | 多家竞价、资产已去风险、伙伴高质量 | 单一买方、远期条款、终止权宽 |

### 5. 投资者沿链条应问什么

1. **患者价值**：疗法是否改变 OS/PFS、生活质量、治疗负担或总医疗成本？
2. **证据所有权**：关键数据由谁控制，是否完整披露？
3. **经济权益**：地区、适应症、供应、分成和成本边界是什么？
4. **资金充分性**：现金能否覆盖至下一次显著去风险事件？
5. **监管与支付**：获批标签、医保和进院漏斗是否被高估？
6. **可复制性**：平台是否有第二/第三个相互独立的成功资产？
7. **退出/证伪**：什么数据、条款变化或现金事件会使价值链断裂？

## 推断

- **medium**：中国创新药的价值捕获正从“国内独占销售”扩展到“海外权益、共同开发与供应”，但合同复杂度使会计收入与经济价值更易错配。
- **medium**：当资本收紧时，拥有商业现金流、可授权资产或低成本临床执行能力的公司议价权更强，早期单资产公司更易让渡权益。
- **medium**：未来行业整合更可能围绕资产与权益发生，而非仅按公司整体并购；因此管线级权益台账比公司标签更重要。
