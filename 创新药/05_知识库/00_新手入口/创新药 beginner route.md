# 创新药 beginner route

> **资料截止日：2026-07-19。** 本页是阅读顺序，不构成投资建议；事实应回到监管、交易所公告及年报核验。

## 一句话判断

创新药研究应沿着**制度与患者需求 → 行业与价值链 → 公司与管线 → 财务与估值 → 催化剂与证伪**逐层收敛，而不是从新闻、单个 ORR 或远期 BD 总额直接跳到投资结论。

## 事实

### 先记住四条边界

1. **获批不等于商业成功**：NMPA 批准证明监管收益风险判断，不证明医保准入、医院进院、峰值销售或投资回报。[NMPA](https://www.nmpa.gov.cn/)，访问/核验：2026-07-19，high。
2. **受理不等于批准**：CDE 受理、优先审评或突破性治疗认定均不能写成已获批。[CDE](https://www.cde.org.cn/)，访问/核验：2026-07-19，high。
3. **交易总额不等于收入**：License-out headline value 通常包含低概率、远期里程碑；必须拆分 upfront、开发/注册/销售里程碑、royalty、成本分担和区域权益。
4. **跨试验比较不是头对头证据**：不同人群、线次、随访和终点下的 ORR/PFS 不可直接排序，详见 [[创新药 key concepts]] 与 [[创新药 risk map]]。

### 一页投资卡的最低字段

| 模块  | 要记录的内容                     | 首选证据                 |
| --- | -------------------------- | -------------------- |
| 公司  | 权益归属、核心产品、管理层、股本与币种        | 年报、交易所公告             |
| 管线  | 机制、适应症、阶段、试验设计、数据截止日       | NMPA/CDE、注册库、论文/会议原文 |
| 临床  | n、线次、标志物、对照、主要终点、疗效与安全性    | 论文、标签、会议原始摘要         |
| 商业化 | 净价、患者池、渗透率、准入、销售费用         | 年报、医保目录、公司披露         |
| BD  | upfront、里程碑、royalty、成本、终止权 | 双方公告、合同摘要            |
| 财务  | 收入性质、R&D、经营现金流、净现金、runway  | 经审计财报                |
| 估值  | 悲观/基准/乐观、PoS、折现率、股本、汇率     | 自建模型，假设透明            |
| 风险  | 预先写明证伪标准                   | [[创新药 risk map]]     |

### 来源优先顺序

- 监管/标签：NMPA、CDE、FDA、EMA。
- 试验：注册平台用于设计与状态，论文/会议原文用于结果；预计完成日只作计划。
- 财务/交易：交易所公告和经审计年报优先于 IR、数据库和媒体。
- 支付：国家医保局目录及政策原文；实际净价仍可能未知。
- 完整规则见 [[创新药 source index]]，不确定项进入 [[创新药 validation log]]。

## 推断

- **medium**：新手首家公司宜选择“已有可拆分收入、核心资产清晰、年报披露充分”的综合型公司；单一早期资产会放大 PoS 与融资假设误差。
- **medium**：最有信息量的问题往往不是“数据好不好”，而是“相对当前标准疗法、当前市值隐含预期和剩余现金，这项证据改变了多少概率”。
- **low**：若 60 分钟内无法说清权益、关键终点、现金跑道和证伪条件，说明研究仍停留在叙事层。
