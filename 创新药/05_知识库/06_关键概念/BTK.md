# BTK

## 一句话判断

BTK 是 B 细胞淋巴瘤最验证的靶点之一，泽布替尼头对头优效伊布替尼确立新一代共价 BTK 标准，但非共价 BTK、BTK 降解剂和 BTK + BCL-2 联合方案正在重塑赛道，单品长期价值取决于耐药管理策略和专利保护。

## 生物学 / 机制

- BTK（Bruton 酪氨酸激酶）是 BCR 信号通路核心节点，驱动 B 细胞活化、增殖和存活。
- BTK 抑制剂阻断 BCR 信号，抑制恶性 B 细胞生存；在 CLL/SLL、MCL、MZL、WM 等 B 细胞淋巴瘤中疗效明确。
- 共价 BTK 抑制剂不可逆结合 BTK C481 残基；C481S 突变导致耐药。
- 非共价 BTK 抑制剂不依赖 C481 结合，理论上克服共价耐药；但持久缓解率仍需验证。
- BTK 降解剂（PROTAC/CDAC）通过降解 BTK 蛋白而非抑制其活性，为第三种策略。

## 验证等级

- **等级 5（多药/多适应症验证）**：伊布替尼、阿可替尼、泽布替尼在全球多个 B 细胞淋巴瘤适应症获批，机制风险极低。

## 适应症

- CLL/SLL、MCL、MZL、WM 为主；FL 和其他 B 细胞淋巴瘤探索中。
- BTK 在实体瘤中活性有限，研发重点仍在血液瘤。

## 全球与中国竞争格局

- **全球**：泽布替尼 2025 年全球收入约 $2.6B，份额持续提升；伊布替尼份额下滑；阿可替尼保持中等份额。pirtobrutinib 在耐药人群获批但前线推进受限。
- **中国**：泽布替尼和奥布替尼为主要国产品种；伊布替尼和阿可替尼进口。国产 BTK 价格优势明显。

## 差异化标准

1. **头对头数据**：是否拥有优效伊布替尼的 III 期随机证据（泽布替尼独有）。
2. **选择性 / 安全性**：off-target AE（房颤、出血）发生率是否更低。
3. **耐药管理**：是否有非共价 BTK 或 BTK 降解剂管线接力。
4. **全球化**：海外获批国家和处方份额。
5. **联合策略**：BTK + BCL-2 等组合是否拓展一线 MRD 阴性缓解路径。

## 拥挤度

- **高**：全球 3 款共价 BTK 上市 + 1 款非共价上市 + 多款在研（包括 BTK 降解剂）。中国 2 款国产 + 2 款进口上市。
- 竞争从共价 → 非共价 → 降解剂三维推进，赛道正在扩宽而非收敛。

## 风险

- 非共价 BTK 前线推进成功，侵蚀共价 BTK 市场份额。
- 泽布替尼等关键专利到期后仿制药快速进入。
- BTK 降解剂若实现突破，可能替代抑制模式。
- BTK + BCL-2 联合若成一线标准，单药 BTK 峰值可能被压缩。

## 事实

- 泽布替尼在 ALPINE III 期中 ORR 和 PFS 显著优于伊布替尼。[来源：NEJM，证据 high]
- 伊布替尼因房颤等安全性劣势，全球份额持续下滑。[来源：J&J 年报，证据 high]
- pirtobrutinib 已获 FDA 批准用于共价 BTK 耐药后 R/R CLL/SLL。[来源：FDA，证据 high]

## 推断

- **high**：BTK 共价抑制剂仍是 CLL/SLL 标准治疗，泽布替尼份额将持续提升至伊布替尼专利到期。
- **medium**：非共价 BTK 在前线能否替代共价，取决于持久缓解和安全性数据。
- **low**：BTK 降解剂尚处早期，对当前格局影响有限但需持续跟踪。
