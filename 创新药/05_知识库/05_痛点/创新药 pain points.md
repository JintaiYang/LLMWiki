# 创新药 pain points

## 一句话判断

中国创新药的主要矛盾已从“能否做出创新药”转向“能否在同质化研发、稀缺临床资源、强支付约束和紧融资环境下，持续做出有临床价值且可商业化、可全球化的差异化产品”。

## 痛点地图

| 环节 | 核心痛点 | 直接后果 | 最关键验证指标 |
|---|---|---|---|
| 研发端 | me-too 扎堆、研发效率下降 | 重复投入、竞争前置、项目淘汰 | 同靶点拥挤度、First-in-human 至上市时间、研发回报率 |
| 临床端 | 入组竞争、对照药与终点设计、监管沟通 | 延期、方案变更、结果不可解释 | 入组速率、中心启动率、方案修订次数、主要终点达成率 |
| 支付端 | 医保谈判降价、DRG/DIP、商保不足 | 量增价减、院内使用受限 | 医保降幅、进院率、患者自付、院均用量 |
| 商业化端 | 销售效率、竞争性进入、出海门槛 | 高销售费用、峰值销售下修 | 单销售产出、新患份额、销售费用率、海外获批/报销 |
| 融资端 | 18A/科创板流动性、再融资困难、现金跑道 | 缩管线、低价融资、BD 被动 | 净现金/月均消耗、成交额、融资折价、未来 24 月里程碑 |

## 事实

### 研发端

1. **靶点同质化（me-too 扎堆）**：热门靶点和机制在中国常出现大量重复申报，造成临床资源、患者和资本重复竞争。CDE 的“以临床价值为导向的抗肿瘤药物临床研发指导原则”明确要求以患者需求和临床价值为导向，而非低水平重复。[来源：CDE 指导原则]
2. **研发效率下降**：项目数量增长不等于有效产出；复杂 modality、联合疗法和全球多区域试验抬高 CMC、临床及监管成本。[来源：各公司年报研发投入；行业公开资料，证据等级 medium]
3. **差异化门槛提高**：仅有非头对头单臂数据或替代终点，越来越难证明对标准治疗的增量价值。[来源：CDE/FDA 指导原则，证据等级 high]

### 临床端

1. **临床入组竞争**：同靶点、同癌种、同线次试验争夺有限合格患者和优质研究中心，容易导致入组延迟和中心成本上升。[来源：药物临床试验登记平台/ClinicalTrials.gov 可检索项目密度；证据等级 medium]
2. **对照药选择**：标准治疗快速变化；若对照组在读出时已落后，可能影响伦理、监管可接受性和商业定位。[来源：CDE 抗肿瘤研发指导原则]
3. **终点设计**：PFS、OS、ORR、DoR、PRO 之间需匹配疾病阶段和未满足需求；替代终点获批后仍可能面临确认性试验要求。[来源：CDE/FDA 指导原则]
4. **监管沟通**：中美欧在对照、族群、CMC、伴随诊断和加速批准上的要求并不完全一致，晚沟通可能造成返工。[来源：NMPA CDE、FDA Oncology Center of Excellence]

### 支付端

1. **医保谈判降价压力**：创新药进入国家医保通常以显著降价换取覆盖，扩大可及性但压低单患者收入；续约和竞品进入继续影响价格。[来源：国家医保局历年目录调整与谈判结果]
2. **DRG/DIP 影响**：按病组/病种分值付费强化医院总成本约束；高价创新药即使已进医保，也可能因院内预算、药占比和病组结余压力使用不足。国家医保局推进 DRG/DIP 2.0，并设置特例单议等机制缓解创新技术支付冲突。[来源：国家医保局 DRG/DIP 2.0 政策]
3. **商业保险不足**：惠民保、城市定制险和高端商保覆盖碎片化，创新药目录、续保与赔付可持续性有限，尚不足以普遍补齐基本医保之外的支付缺口。[来源：金融监管与地方惠民保公开条款，证据等级 medium]

### 商业化端

1. **销售团队效率**：新品集中上市导致企业同步扩张销售队伍；若适应症窄、医院准入慢，单销售产出下降、销售费用率上升。[来源：上市公司年报，证据等级 high]
2. **竞争性进入**：同机制产品获批间隔缩短，首发优势窗口变短；医保竞价、适应症覆盖和真实世界证据成为持续竞争变量。
3. **出海门槛**：全球 III 期设计、FDA/EMA 沟通、CMC 检查、供应链、知识产权、定价报销和海外商业团队均需要能力；license-out 可降低资本需求，但也让渡控制权与经济权益。

### 融资端

1. **18A/科创板流动性**：未盈利 Biotech 可通过港股 18A 或科创板上市，但二级市场成交、估值和投资者风险偏好具有明显周期性；小市值公司再融资折价更敏感。[来源：港交所 18A 规则、上交所科创板规则；证据等级 high]
2. **再融资困难**：临床失败或市场转弱时，配售、定增、可转债的折价和摊薄扩大，私募融资也更偏好临床后期或有 BD 验证资产。[来源：上市公司融资公告；证据等级 medium]
3. **现金跑道压力**：高研发投入、商业团队建设与里程碑付款叠加，使“账面现金 ÷ 静态月均支出”经常高估真实跑道；应纳入未来试验启动、生产放大与债务偿还。

## 分环节分析

### 1. 研发：从“跟随速度”转向“临床差异化”

- **根因**：热门靶点信息透明、资本追逐短周期项目、早期评价偏重可申报性而非临床价值。
- **传导**：同靶点项目多 → 动物/早期数据趋同 → 临床入组竞争 → 对照标准升级 → 峰值销售下降。
- **解法方向**：用 Target Product Profile 倒推研发；优先头对头或生物标志物明确的人群；建立终止规则，减少沉没成本。
- **关联**：靶点同质化、研发效率、[[创新药 key concepts|双特异性抗体]]、[[ADC技术平台|ADC]]。

### 2. 临床：稀缺患者与快速变化的标准治疗

- **根因**：试验数量快于优质中心和适格患者增长，热门癌种/线次高度集中。
- **传导**：入组慢 → 数据读出推迟 → 现金消耗增加 → 对照组过时 → 商业窗口缩短。
- **解法方向**：前置可行性调研、中心分层、数字化预筛；与 CDE/FDA 尽早开展 EOP/关键方案沟通；同步规划伴随诊断和全球 MRCT。
- **关联**：临床试验风险、临床终点、对照组、监管风险。

### 3. 支付：医保可及性与创新回报的张力

- **根因**：基本医保强调“保基本”和基金可持续，高价药对单病组预算冲击大，商保补位仍弱。
- **传导**：医保降价 → 名义患者池扩大；DRG/DIP/进院限制 → 实际使用爬坡慢；销售投入回收期延长。
- **解法方向**：谈判前建立量价敏感性；发展按疗效付费、风险共担、特例单议；用真实世界证据支持续约和适应症价值分层。
- **关联**：医保谈判、DRG-DIP、商业保险、药品可及性。

### 4. 商业化：从“获批即价值”转向“单位经济性”

- **根因**：获批产品密集、医院准入周期长、销售团队复制速度快于处方需求。
- **传导**：竞争性进入 → 价格/返点/学术推广压力 → 销售费用率高 → 盈利拐点后移。
- **解法方向**：按疾病网络而非产品堆团队；监控单销售产出、进院转化、首方到续方；适度借助成熟药企合作。
- **关联**：商业化风险、销售效率、License-in、出海。

### 5. 融资：现金跑道成为研发战略约束

- **根因**：资本市场周期、临床二元风险、上市通道与二级流动性并不等于持续融资能力。
- **传导**：估值下降 → 融资折价 → 股权摊薄 → 管线收缩/低价 BD → 长期价值受损。
- **解法方向**：至少保持 24 个月风险调整现金；按项目里程碑分配资本；提前准备 BD、债务和股权多渠道；把非核心项目主动终止而非平均投入。
- **关联**：融资风险、现金跑道、港股18A、科创板第五套标准、BD。

## 交叉反馈回路

1. **同质化—入组—融资负循环**：me-too 增多 → 入组变慢 → 数据延后 → 现金跑道缩短 → 被迫低价融资/授权。
2. **医保—商业化负循环**：医保降价 → 需更大销量才能覆盖销售费用；若 DRG/DIP 限制使用，则量价逻辑不能兑现。
3. **出海—研发正循环**：高质量全球数据 → 高质量 BD/海外获批 → 现金回流 → 支持下一代原创研发。
4. **平台扩张风险**：单资产早期成功 → 同平台项目快速扩张 → 组织和现金超载；必须以临床 PoC 分阶段投资。

## 推断

- **medium**：2026 年后行业分化将更多体现为“临床价值密度、全球执行力、现金效率”，而非 IND 数量。
- **medium**：医保并非单向利空；对有明确差异化、可快速进院的药物，降价可换来销量和竞争壁垒，但需逐品种测算量价弹性。
- **low**：商保短期难成为普遍主支付方，更可能先在特药目录、CAR-T/罕见病和院外药形成局部补充。
