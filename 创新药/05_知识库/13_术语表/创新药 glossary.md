# 创新药术语表

> 本页覆盖监管、临床、支付、技术、估值与 BD 六大类中英文术语及缩写。

## 一、监管（Regulatory）

|---|---|---|---|
| NMPA | 国家药品监督管理局 | 中国药品与医疗器械最高监管机构，负责批准与安全监管 | https://www.nmpa.gov.cn/ |
| CDE | 药品审评中心 | NMPA 下属技术审评机构，负责药品注册审评、沟通交流与指导原则 | https://www.cde.org.cn/ |
| IND | 临床试验申请/新药临床试验申请 | 申办方向监管提交的临床试验许可申请；中国需获 CDE 许可后方可开展 | [[创新药 drug development system]] |
| NDA | 新药上市申请 | 化学药品注册上市申请 | [[创新药 drug development system]] |
| BLA | 生物制品上市申请 | 生物制品（抗体、细胞治疗等）注册上市申请 | [[创新药 drug development system]] |
| CRL | 完整回复函 | FDA 审评不通过时发出的函件，列出需补充的信息 | FDA 官网 |
| BTD | 突破性治疗药物认定 | CDE 认定用于严重/危及生命疾病且临床优势明显的药物 | CDE 指导原则 |
| PR | 优先审评审批 | 缩短审评周期的审评通道 | CDE 指导原则 |
| CAC | 附条件批准 | 基于中期/替代终点先行批准，需后续确证 | NMPA 法规 |
| MAH | 药品上市许可持有人 | 对药品全生命周期负责的主体 | 《药品管理法》 |
| GMP | 药品生产质量管理规范 | 药品生产必须遵守的质量管理体系 | NMPA 法规 |
| GCP | 药物临床试验质量管理规范 | 临床试验必须遵守的质量管理标准 | NMPA 法规 |

## 二、临床（Clinical）

| 缩写/英文 | 中文 | 定义 | 备注 |
|---|---|---|---|
| PoC | 概念验证 | II 期阶段证明药物在目标人群有生物学效应与临床信号 | [[创新药 key concepts]] |
| RP2D | 推荐II期剂量 | I 期确定的安全有效剂量，用于后续临床 | — |
| ORR | 客观缓解率 | CR + PR 占可评价患者比例 | 肿瘤疗效核心指标 |
| CR | 完全缓解 | 所有靶病灶消失且无新病灶 | — |
| PR | 部分缓解 | 靶病灶直径总和缩小≥30% | — |
| DCR | 疾病控制率 | CR + PR + SD 比例 | — |
| DoR | 缓解持续时间 | 从首次缓解到进展或死亡的时间 | — |
| PFS | 无进展生存期 | 从随机化到进展或死亡的时间 | 常作主要终点 |
| OS | 总生存期 | 从随机化到死亡的时间 | 金标准终点 |
| HR | 风险比 | 试验组与对照组风险之比；<1 示试验组优 | 须配合 CI 与 p 值 |
| CI | 置信区间 | 参数估计的不确定性范围 | 通常报告 95% CI |
| TRAE | 治疗相关不良事件 | 与研究药物相关的不良事件 | — |
| SAE | 严重不良事件 | 导致死亡、危及生命、需住院等的不良事件 | — |
| BICR | 盲法独立中心评审 | 由不知分组情况的独立影像评审委员会评估 | 减少评估偏差 |
| ITT | 意向性治疗 | 所有随机化患者均纳入分析 | 减少选择偏差 |
| mRECIST | 修改版RECIST | 针对肝癌等靶病灶测量的修改标准 | — |
| PSA | 无进展生存期替代 | 用替代指标预测 OS 的方法学 | 需验证 |
| R/R | 复发/难治 | 既往治疗后复发或难治的患者亚组 | — |
| 1L / 2L / 3L+ | 一线/二线/三线及以上 | 治疗线次 | 影响患者基线与疗效预期 |
| Biomarker | 生物标志物 | 用于患者选择、疗效预测或监测的生物学指标 | 如 PD-L1、HER2、BCMA |
| 单臂试验 | Single-arm trial | 所有患者接受研究治疗，无对照组 | 适用于罕见病/显著效应 |
| 随机对照 | RCT | 受试者随机分配至试验组或对照组 | 证据等级高于单臂 |
| 双盲 | Double-blind | 受试者和研究者均不知分组 | 减少行为与评估偏差 |
| 非头对头比较 | Non-head-to-head | 不同试验之间的间接比较 | 只能生成假设，不能证明优效；[[创新药 key concepts]] |

## 三、支付（Payment / Access）

| 缩写/英文 | 中文 | 定义 | 备注 |
|---|---|---|---|
| NRDL | 国家基本医疗保险药品目录 | 中国基本医保可报销药品清单 | 国家医保局发布 |
| 医保谈判 | NRDL negotiation | 药企与医保局就价格与纳入目录的谈判 | 降价换取放量 |
| VBP / 集采 | 集中带量采购 | 政府主导的药品集中招标采购，通常大幅降价 | 仿制药与创新药均受影响 |
| DTP | 直面患者药房 | 直接向患者销售特殊药品的药房渠道 | 创新药重要准入渠道 |
| 双通道 | Dual-channel | 医院与 DTP 药房均可医保报销 | 扩大创新药可及性 |
| 药事会 | 医院药事管理与治疗学委员会 | 医院内部决定药品进院的机构 | 进院是放量的关键门 |
| 净价 | Net price | 扣除返利、折扣与回款后的实际价格 | 估值使用净价而非标价 |
| co-pay | 共付/自付部分 | 患者自付比例 | 影响治疗可及性与依从性 |
| 商保 | 商业健康保险 | 医保外的补充支付方式 | 逐步成为创新药支付增量 |

## 四、技术（Technology / Platform）

| 缩写/英文 | 中文 | 定义 | 备注 |
|---|---|---|---|
| ADC | 抗体偶联药物 | 抗体靶向递送细胞毒性小分子的药物形式 | [[ADC技术平台|ADC 技术平台]] |
| DAR | 药物抗体比 | 每个 ADC 抗体上平均连接的 payload 分子数 | 影响疗效与安全性 |
| Linker | 连接子 | ADC 中连接抗体与 payload 的化学结构 | 决定稳定性与释放 |
| Payload | 有效载荷/毒素 | ADC 递送的细胞毒性分子 | 影响杀伤力与安全窗 |
| BsAb / 双抗 | 双特异性抗体 | 同时结合两个不同抗原或表位的抗体 | [[创新药 key concepts|双特异性抗体]] |
| CAR-T | 嵌合抗原受体 T 细胞 | 基因工程改造 T 细胞表达靶向 CAR 的细胞疗法 | CD19 CAR-T · [[BCMA CAR-T]] |
| PROTAC | 蛋白降解靶向嵌合体 | 利用泛素-蛋白酶体系统降解靶蛋白的双功能分子 | 新模态 |
| mRNA | 信使 RNA | 编码蛋白质的核酸分子，可作为药物/疫苗 | mRNA 递送平台 |
| LNP | 脂质纳米颗粒 | 递送 mRNA 等核酸药物的纳米载体 | — |
| mAb | 单克隆抗体 | 针对单一抗原表位的高度均一抗体 | — |
| TKI | 酪氨酸激酶抑制剂 | 抑制特定酪氨酸激酶的小分子 | 如 BTKi、VEGFRi |
| MoA | 作用机制 | 药物产生生物学效应的分子机制 | — |
| CMC | 化学、制造与控制 | 药品化学、生产与质量控制的统称 | [[创新药 drug development system]] |
| PK/PD | 药代动力学/药效学 | 药物在体内的吸收、分布、代谢、排泄与效应关系 | — |
| IoR / 内部研发 | Internal R&D | 公司自主开展的研发活动 | 区别于 License-in |
| PoS | 成功概率 | 从当前阶段到最终上市的概率 | [[创新药 key concepts]] |
| FTO | 自由实施权 | 不侵犯第三方专利的权利 | 影响管线权益 |

## 五、估值（Valuation）

| 缩写/英文 | 中文 | 定义 | 备注 |
|---|---|---|---|
| rNPV | 风险调整净现值 | 用成功概率加权的未来现金流折现值 | [[创新药 key concepts]] |
| SOTP | 分部估值法 | 将公司拆为多个业务分部分别估值后加总 | 适用于多管线/多产品公司 |
| DCF | 折现现金流 | 预测未来自由现金流并以折现率折现 | 适用于成熟现金流 |
| WACC | 加权平均资本成本 | 权益与债务资本的加权成本 | DCF 折现率 |
| PE / PEG | 市盈率 / 市盈增长比 | 股价/每股收益；PE/增长率 | 适用于利润稳定的公司 |
| EV/Sales | 企业价值/收入 | 企业价值除以收入 | 适用于利润未稳定的公司 |
| Peak Sales | 峰值销售 | 产品生命周期中的最大年销售额 | 估值核心输入 |
| Cash Runway | 现金跑道 | 可用现金覆盖月均净消耗的月数 | [[创新药 key concepts]] |
| 净现金 | Net Cash | 现金+短期投资-有息债务 | SOTP 中需单独加减 |
| Fully Diluted | 完全摊薄 | 含期权、可转债等全部潜在股本的口径 | 港股估值须注明 |
| EV | 企业价值 | 市值 + 净债务 - 关联方/非经营资产 | 比市值更准确反映经营价值 |
| 敏感性分析 | Sensitivity analysis | 关键假设变化对估值结果的影响 | 每个估值必须包含 |

## 六、BD（Business Development）

| 缩写/英文 | 中文 | 定义 | 备注 |
|---|---|---|---|
| License-out | 对外授权 | 将自有管线在特定区域的开发与商业化权授权给第三方 | 保留 royalty 与里程碑 |
| License-in | 引进授权 | 获得第三方管线在特定区域的开发与商业化权 | 需支付首付款、里程碑与 royalty |
| Upfront payment | 首付款 | 签约时一次性支付的不可退还金额 | 已确定收入 |
| Milestone | 里程碑付款 | 达成特定开发/监管/销售事件时支付的金额 | 按概率折现 |
| Royalty | 特许权使用费/分成 | 按销售额一定比例支付的分成 | 通常为阶梯式 |
| Tiered royalty | 阶梯式分成 | 随销售额不同区间采用不同比例 | — |
| Deal value / Headline | 交易总金额 | 首付+所有里程碑+潜在付款的名义总额 | 不等于确定收入 |
| Co-development | 联合开发 | 双方共同承担开发成本与权益 | — |
| Opt-in / Opt-out | 选择加入/退出 | 合作方在特定节点选择是否继续参与 | 影响权益分配 |
| Exclusivity | 独占权 | 在特定区域/适应症的排他性权利 | — |
| Territorial rights | 地域权益 | 授权交易中约定的地理区域划分 | 中国/全球/美国等 |
