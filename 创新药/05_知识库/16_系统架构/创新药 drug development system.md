# 创新药 drug development system

> **资料截止日：2026-07-19。** 本页为通用系统；具体产品的受理、阶段、批准和标签必须以 NMPA/CDE 及试验登记逐项核验。

## 一句话判断

药物开发本质是用逐级增强的人体证据、可控 CMC 与持续资本，依次消除**机制、毒理、剂量、疗效、确证、监管、生产、支付和真实世界安全**风险；任何单个“加速”状态都不能跳过完整收益—风险判断。

## 事实

### 1. 端到端状态机

```text
疾病与靶点假设
  ↓
候选发现/优化 → 临床前药效、PK/PD、毒理、CMC
  ↓
IND申报 → CDE审评/临床试验许可
  ↓
I期（安全、耐受、PK/PD、剂量）
  ↓
II期（概念验证、剂量选择、目标人群）
  ↓
III期/注册性试验（与对照确证获益—风险）
  ↓
NDA/BLA申报 → CDE技术审评 → NMPA批准与标签
  ↓
GMP生产/批次放行 → 定价 → 医保/商保/自费 → 医院/双通道准入
  ↓
处方、患者治疗、药物警戒、IV期/确证研究、适应症扩展
  ↓
专利/独占期结束、竞争进入与生命周期管理
```

中国法定状态和指导原则以 [NMPA](https://www.nmpa.gov.cn/) 与 [CDE](https://www.cde.org.cn/) 为准（核验日 2026-07-19，high）。

### 2. 每阶段解决什么问题

| 阶段 | 核心问题 | 关键输出 | 投资者不能误读为 |
|---|---|---|---|
| 靶点/发现 | 机制是否可干预，分子是否有选择性和可开发性？ | 候选物、IP、体外/动物证据 | 已证明人体有效 |
| 临床前/CMC | 安全窗口、暴露、制剂与工艺能否支持人体试验？ | 毒理包、IND 批次、分析方法 | 可规模化商业生产 |
| IND | 方案是否可进入人体研究？ | 受理/许可、试验方案 | 药物获批上市 |
| I期 | 安全、PK/PD、剂量和早期信号如何？ | RP2D/剂量范围、初步安全 | 已证明临床获益 |
| II期 | 特定人群是否有 PoC，剂量/终点如何选？ | 效应量、患者选择、III期设计 | 单臂结果必可复制 |
| III期/注册性 | 相对合适对照是否有统计和临床意义？ | 主要终点、完整安全、亚组 | 所有亚组均受益 |
| NDA/BLA审评 | 总体收益—风险、CMC、标签是否可接受？ | 批准、CRL/补充要求、标签 | 商业成功或医保纳入 |
| 上市/支付 | 药能否稳定供应、支付并进入诊疗路径？ | 准入、处方、净收入 | 患者池全部转化 |
| 上市后 | 长期/罕见风险和真实世界获益如何？ | 药物警戒、确证、标签变化 | 风险已完全消失 |

### 3. 中国监管角色与状态

| 主体/系统 | 主要职责 | 研究使用规则 |
|---|---|---|
| NMPA | 行政批准、法规、说明书、安全监管 | “获批”只以正式批准与标签为准 |
| CDE | 技术审评、沟通交流、指导原则、部分公示 | 受理/纳入程序不等于批准 |
| 中国药物临床试验登记平台 | 登记方案、中心、状态等 | 保存登记号和版本；状态可能滞后 |
| 伦理委员会/研究机构 | 伦理、受试者保护、研究实施 | 获伦理同意不代替监管许可 |
| MAH | 对研发、生产、药物警戒与产品质量负责 | 委托生产不转移最终责任 |
| 国家医保局 | 基本医保目录和相关支付政策 | 医保准入不等于实际净价/销量 |

- 试验登记入口：[中国药物临床试验登记与信息公示平台](http://www.chinadrugtrials.org.cn/)；全球试验可交叉 [ClinicalTrials.gov](https://clinicaltrials.gov/)（核验日 2026-07-19）。
- “突破性治疗药物”“优先审评审批”“附条件批准”解决的问题不同；其纳入/适用条件和当前名单应以 CDE/NMPA 实时公示为准。
- 附条件批准后的确证研究若失败、延迟或安全性改变，可能导致标签调整或其他监管行动；不能将附条件批准视为最终不变状态。

### 4. 临床试验数据结构

每次数据读出至少保存：

- 试验编号、版本、申办方、地区与中心；
- 设计：随机/单臂、盲法、对照、分层、样本量、统计假设；
- 人群：适应症、线次、标志物、既往治疗、可测量病灶、基线；
- 治疗：剂量、频率、联合方案、暴露时间；
- 截止日、随访、分析集、数据成熟度；
- 主要/次要终点：ORR、DoR、PFS、OS、PRO 等及 HR、CI、p 值；
- 安全性：任意级、≥3 级 TRAE、SAE、停药、减量、治疗相关死亡；
- 评审：研究者或 BICR；
- 来源层级：标签/论文/会议摘要/公司演示。

跨试验比较统一写明**非头对头比较**，详见 [[创新药 key concepts]]。

### 5. CMC 与生产是并行系统

| CMC 模块 | 关键问题 | 高风险信号 |
|---|---|---|
| 原液/制剂 | 分子和制剂是否稳定、可放大？ | 聚集、降解、低溶解度、低产率 |
| 分析方法 | 身份、纯度、效价与杂质能否可靠测量？ | 方法不稳定、变更后不可比 |
| 工艺控制 | 关键质量属性和参数是否受控？ | 批间差异、偏差频发 |
| 变更可比性 | 临床批到商业批是否保持可比？ | 工艺放大导致暴露/活性变化 |
| 产能/供应链 | 原料、设备、冷链和产能是否冗余？ | 单点供应、交付周期长 |
| 特殊疗法 | ADC 偶联/游离 payload、CAR-T 周转与放行 | 治疗窗、失败批次、中心瓶颈 |

临床成功不自动消除 CMC 风险；[[传奇生物]]等细胞治疗公司要额外评估 vein-to-vein 周期和产能，[[科伦博泰]]、[[荣昌生物]]等 ADC 公司要评估偶联一致性与 payload 安全窗。

### 6. 审批后的支付与商业化系统

```text
NMPA标签
  ↓
价格与证据包 → 医保谈判/竞价或自费/商保
  ↓
省级/医院流程、药事会、双通道/DTP、处方限制
  ↓
检测与诊断 → 医生认知 → 患者支付 → 治疗持续
  ↓
净收入、真实世界证据和再谈判
```

- 国家医保目录与政策原文见 [国家医保局](https://www.nhsa.gov.cn/)（核验日 2026-07-19，high）。
- 医保后销售影响取决于降价、患者覆盖、进院速度、检测、治疗持续和竞争；不使用“纳入医保必然放量”的确定性表达。
- 复杂疗法、罕见病药、慢病药应建立不同的患者漏斗，详见 [[创新药 patient and payer landscape]]。

### 7. 系统中的反馈回路

1. I/II 期数据改变人群、剂量与 III 期设计。
2. 竞品读出改变对照组、效应量门槛和患者入组速度。
3. 监管沟通改变终点、CMC 与上市后义务。
4. 医保和真实世界使用改变净价、市场规模与后续适应症策略。
5. 安全性信号可从上市后反向改变标签、临床和估值。
6. 融资/BD 改变项目优先级与权益，但不能改变已产生的临床事实。

### 8. 阶段门与估值去风险

| 证据门 | 主要新增信息 | 仍未解决 |
|---|---|---|
| IND 获许可 | 可进入人体、基础 CMC/毒理可接受 | 人体安全与疗效 |
| I期可接受 | 剂量、PK/PD、初步安全 | 确证疗效、商业剂量 |
| II期 PoC | 特定人群效应信号 | 随机复制、长期安全 |
| III期达标 | 相对对照确证证据 | 审评、CMC、标签、支付 |
| 正式批准 | 特定标签收益—风险获认可 | 商业渗透、长期安全 |
| 医保/准入 | 支付和渠道条件改善 | 净价、量、持续治疗 |
| 经常性现金流 | 商业模式得到一定验证 | 竞争、专利、生命周期 |

估值 PoS 应随证据更新，而不是机械按阶段套固定概率；具体方法见 [[创新药 complete research framework]]。

## 推断

- **medium**：行业竞争加快后，开发速度的价值来自“在标准疗法变化前获得有效随机证据”，而非单纯更早进入临床。
- **medium**：同一资产在中国获批与全球获批之间仍存在对照、人群、CMC、统计和监管差异，国内成功不能等比例外推全球 PoS。
- **medium**：商业化失败经常不是单点问题，而是标签、价格、进院、检测、产能和销售效率多个漏斗相乘。
