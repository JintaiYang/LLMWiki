# 建仓前检查清单

> 在买入任何新标的前，完成此清单。冲动买入的最大预防机制。

---

## 强制暂停规则

> 在完成此清单前，**不得执行买入操作**。  
> 如果填写过程中发现无法回答某个问题，这就是一个信号：研究还不够充分。

---

## 一、商业理解确认

- [ ] 我能用2分钟解释这家公司如何赚钱
- [ ] 我理解这个行业的竞争格局
- [ ] 我知道公司的护城河是什么，以及它是否在加宽/缩窄
- [ ] 我看过至少最近2年的年报
- [ ] 我理解公司的主要风险

**商业理解自评**：[ ] 充分理解 [ ] 基本理解 [ ] 理解不足（理解不足→不买）

---

## 二、估值确认

- [ ] 当前PE/PB/PS是多少？处于历史什么分位？
- [ ] 市场隐含的增速/利润率假设是多少？我认为这个假设合理吗？
- [ ] 我做了情景分析（乐观/中性/悲观），期望价值是多少？
- [ ] 当前价格相对期望价值的安全边际是多少？（建议≥15%）
- [ ] 我能接受悲观情景下的损失吗？

**安全边际**：____% → [ ] 足够 [ ] 勉强 [ ] 不足（不足→不买）

---

## 四、组合适配性

- [ ] 加入这个标的后，单一持仓不超过20%
- [ ] 加入后，单一行业敞口不超过40%
- [ ] 这个标的与现有持仓的相关性是否过高？（避免实质上的重复押注）
- [ ] 我有足够的精力持续跟踪这个标的吗？

---

## 五、情绪检查

**触发本次买入的原因是什么？**
- [ ] 基于自己的长期研究
- [ ] 看到了别人的推荐（⚠️ 需要特别审慎）
- [ ] 股价大跌想"抄底"（⚠️ 需要确认是否基于基本面）
- [ ] 股价大涨想追涨（⚠️ 高风险，必须慎重）

**最近24小时内是否有外部信息影响了这个决定？**
（如果是，给自己一天冷静期，重新评估）

- [ ] 继续持有，因为基本面未变
- [ ] 考虑加仓
- [ ] 可能慌张，说明仓位偏重
