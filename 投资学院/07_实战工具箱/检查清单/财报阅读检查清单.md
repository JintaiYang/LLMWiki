# 财报阅读检查清单

> 每次阅读一份新年报时，用此清单确保覆盖关键问题。

---

## 第一步：快速定向（15分钟）

- [ ] 查看年报目录，了解整体结构
- [ ] 先看**管理层讨论与分析**（MD&A），了解他们自己怎么说这一年
- [ ] 先看**现金流量表**（不是利润表），判断盈利质量

---

## 第二步：业务理解

- [ ] 公司主要业务有哪些？收入占比如何？
- [ ] 收入是来自产品还是服务？一次性还是重复性？
- [ ] 主要客户是谁？有没有客户集中度风险（前5大客户超过30%）？
- [ ] 公司处于产业链哪个位置？对上下游议价能力如何？

---

## 第三步：损益表分析

- [ ] 营收同比增速：____%（合理吗？增速说明了什么？）
- [ ] 毛利率：____% → 同比变化：____% → 行业对比如何？
- [ ] 净利率：____% → 同比变化：____%
- [ ] 费用率变化：销售费用/管理费用/研发费用是否合理？
- [ ] 非经常性损益占净利润比例：____% （超过20%需要注意）
- [ ] 扣非净利润：____元（这才是真实的可持续盈利）

---

## 第四步：现金流量表分析

- [ ] 经营现金流：____元
- [ ] 净利润：____元
- [ ] **经营现金流/净利润 = ____%**（< 70%需要深入调查）
- [ ] 资本支出（CapEx）：____元
- [ ] 自由现金流（FCF = 经营现金流 - CapEx）：____元
- [ ] 公司是否在靠借贷或发股来维持运营？

---

## 第五步：资产负债表分析

- [ ] 货币资金：____元（是否真实可用？）
- [ ] 应收账款：____元 → 占营收比例：____% → 同比变化：____%
- [ ] 存货：____元 → 存货周转天数：____天 → 是否在积压？
- [ ] 商誉：____元（占总资产比例：____%，是否有减值风险？）
- [ ] 其他应收款：____元（是否有大股东占款？）
- [ ] 有息负债：____元 → 资产负债率：____% → 行业对比合理吗？

---

---

## 第七步：风险识别

- [ ] 管理层是否提到了哪些风险？（有没有被遮掩的关键风险？）
- [ ] 审计师意见是否标准无保留意见？（任何非标意见都要深入调查）
- [ ] 关联交易是否透明合理？
- [ ] 是否有大额未决诉讼或监管调查？

---

## 第八步：对比历史与同行

- [ ] 三年主要指标趋势（毛利率/ROE/现金转化率）是改善还是恶化？
- [ ] 与主要竞争对手相比，差异在哪里？
- [ ] 管理层过去的预测（业绩指引）实现了吗？
