# 阶段1 详细计划：基础构建期（0–12个月）

→ 返回 [[培养方案总览]]

---

## 阶段目标

**从"有一些认知"到"能做基础研究"**

完成本阶段后，你应该能够：
- 独立阅读一份上市公司年报，识别关键财务信号
- 理解主流估值方法，能对一家公司给出合理估值区间
- 建立一个简单的模拟组合，并开始记录决策逻辑
- 形成基本的信息筛选能力，不被市场噪音干扰

---

## 学习路线（按月推进）

### 月1–2：财务基础

**学习内容**

| 主题    | 核心问题                    | 学习资源       |
| ----- | ----------------------- | ---------- |
| 损益表   | 收入是真实的吗？利润是现金吗？毛利率说明什么？ | [[财务分析入口]] |
| 资产负债表 | 资产质量如何？负债是否可控？净资产是否可信？  | 同上         |
| 现金流量表 | 经营现金流与净利润的差异意味着什么？      | 同上         |
| 三表联动  | 利润增长但现金流下降，意味着什么？       | 同上         |

**实践任务**
- [ ] 下载贵州茅台最近一年年报，完成 [[财报阅读检查清单]]
- [ ] 用三张表回答：茅台的利润质量如何？
- [ ] 对比茅台与一家普通白酒企业的毛利率差异，尝试解释原因

---

### 月3–4：估值基础

**学习内容**

| 主题 | 核心问题 | 学习资源 |
|------|---------|---------|
| PE估值 | PE适用什么类型的公司？高PE一定贵吗？ | [[估值定价入口]] |
| PB估值 | PB适用什么场景？银行为什么用PB？ | 同上 |
| DCF逻辑 | 公司价值的本质是什么？折现率如何影响估值？ | 同上 |
| 估值的局限 | 为什么估值是"艺术"而非"科学"？ | 同上 |

**实践任务**
- [ ] 对茅台做简单PE历史区间分析（近5年PE中位数是多少？）
- [ ] 尝试用极简DCF（假设固定增长率）估算茅台的合理价值区间
- [ ] 思考并记录：市场现在隐含的假设是什么？

---

### 月5–6：行业与竞争分析

**学习内容**

| 主题 | 核心问题 | 学习资源 |
|------|---------|---------|
| 商业模式 | 公司如何赚钱？收入来源是否稳定？ | [[行业研究入口]] |
| 护城河 | 什么阻止竞争对手复制这家公司？ | 同上 |
| 竞争格局 | 行业集中度如何？谁在赢？谁在输？ | 同上 |
| 先行指标 | 用什么数据可以提前判断公司基本面变化？ | 同上 |

**实践任务**
- [ ] 画出白酒行业的竞争格局图（5家主要公司的市场份额、定位）
- [ ] 识别贵州茅台的护城河类型（参考《护城河投资优势》分类）
- [ ] 找出茅台最重要的3个先行指标，并建立跟踪表

---

### 月7–8：投资心理与决策框架

**学习内容**

| 主题 | 核心问题 | 学习资源 |
|------|---------|---------|
| 认知偏差 | 什么让投资者系统性地做出错误决策？ | [[心理与决策入口]] |
| 市场先生 | 如何理解市场情绪与价格的关系？ | 同上 |
| 安全边际 | 为什么要在"便宜"时买入？如何定义便宜？ | 同上 |
| 决策日志 | 如何记录决策过程以便未来复盘？ | 同上 |

**实践任务**
- [ ] 回顾过去的1–2次投资决策，用 [[投资命题备忘录模板]] 重新记录
- [ ] 开始维护 [[决策日志索引]]，每次投资判断都记录
- [ ] 读完《聪明的投资者》并写读书笔记

---

### 月9–10：宏观框架入门

**学习内容**

| 主题 | 核心问题 |
|------|---------|
| 利率与估值 | 利率上升为什么会压低估值倍数？ |
| 货币信用周期 | 当前处于哪个周期阶段？对哪类资产有利？ |
| 汇率与行业 | 人民币升/贬值对哪些行业有直接影响？ |
| 宏观与自下而上的关系 | 宏观判断应该在投资中占多大权重？ |

**实践任务**
- [ ] 整理近10年A股主要行情的宏观背景（货币宽松/收紧、政策转向）
- [ ] 思考并记录：宏观研判在我的投资体系中扮演什么角色？

---

### 月11–12：综合整合与阶段复盘

**任务**
- [ ] 完成第一次完整的公司深度研究（选一家自己熟悉的公司）
- [ ] 做阶段1全面复盘：哪些认知有了实质性提升？哪些还有盲区？
- [ ] 确定进入阶段2的主攻行业（1–2个）
- [ ] 评估模拟组合表现，归因分析（做对了什么？做错了什么？）
