## 阶段目标

**从"能做基础研究"到"具备独立定价能力"**

完成本阶段后，你应该能够：
- 在1–2个选定行业建立深度认知，能识别真正的投资机会
- 独立构建情景分析（乐观/中性/悲观），估算合理价值区间
- 识别市场预期差，知道"为什么市场错了"
- 建立30家左右的标的观察池，持续跟踪核心数据
- 形成初步的组合管理意识

---

## 行业选择策略

**先选行业，再选公司**。进入阶段2前，必须确定主攻行业。

**选行业的原则**：
1. **理解优势**：选你有信息优势或认知优势的行业（如你从事的行业、你深度使用的产品）
2. **可追踪**：关键指标数据容易获取，产业链可以调研
3. **生命力**：行业有合理的长期增长逻辑，不是夕阳行业
4. **复杂度适中**：避免过于复杂的金融工具行业（如保险精算）作为首选

**本知识库的推荐练习行业**（结合已有研究库）：
- **消费/白酒**：贵州茅台已有深度研究，可作为参照
- **银行**：银行知识库有完整数据和框架
- **半导体/芯片**：芯片行业有产业链地图

## 核心学习内容

### 行业研究体系

**目标**：建立一个行业的"完整认知地图"

| 维度 | 需要回答的问题 |
|------|-------------|
| 产业链 | 上下游是谁？定价权在哪里？谁的利润率最高？ |
| 竞争格局 | CR3/CR5多少？集中度在提升还是下降？为什么？ |
| 关键变量 | 什么因素决定了行业景气度？频率是月/季/年？ |
| 政策敏感性 | 哪些政策会根本性影响这个行业？如何跟踪？ |
| 历史复盘 | 过去10年的大起大落分别发生在什么背景下？ |

**产出**：每个主攻行业完成一份《行业研究手册》

---

### 公司深度研究

**目标**：能对一家公司做出独立的、可证伪的投资判断

**标准分析框架**：

```
1. 商业模式
   - 公司如何赚钱？核心业务的收入逻辑是什么？
   - 盈利来自什么驱动？量还是价？

2. 护城河评估
   - 护城河类型：品牌、转换成本、规模效应、网络效应、成本优势？
   - 护城河深度：10年后这个优势还在吗？

3. 管理层与资本配置
   - 管理层是否诚实？历史上如何对待股东？
   - 资本配置能力：分红、回购、并购的历史记录

4. 财务质量
   - 盈利质量（经营现金流/净利润 > 80%？）
   - 资产负债表健康程度
   - ROE/ROIC趋势

5. 估值与安全边际
   - 当前估值处于历史什么分位？
   - 市场隐含了什么假设？
   - 我认为更合理的假设是什么？
```

---

### 预期差分析（核心能力）

**什么是预期差**：市场对未来的定价假设 vs 你认为更可能发生的现实

**如何寻找预期差**：

1. **财报超预期/低预期**：深入拆解财报，看市场是否忽略了某个结构性变化
2. **产业链草根调研**：供应商、经销商的反馈往往领先财报2–3个季度
3. **政策误读**：市场对政策的短期过度反应或过度忽视
4. **估值体系切换**：行业成熟期/成长期的估值方法本身在变化

**记录方式**：每次建立预期差判断时，在 [[投资命题备忘录模板]] 中明确写出：
> "市场在定价X，我认为Y更可能发生，因为Z。"

### 组合管理初步

| 主题 | 学习重点 |
|------|---------|
| 仓位管理 | 凯利公式的概念；集中与分散的权衡 |
| 风险归因 | Brinson模型（行业配置 vs 个股选择） |
| 再平衡逻辑 | 什么情况下加仓/减仓/清仓？ |
| 组合相关性 | 为什么看似分散的组合在熊市中会一起跌？ |

## 实践安排

### 标的池建设

建立并维护一个**观察清单**（初期20家，逐步扩展到30–40家）：

| 字段 | 说明 |
|------|------|
| 公司名 | 含A股代码 |
| 行业 | 细分赛道 |
| 商业模式一句话 | 用一句话说清楚公司怎么赚钱 |
| 护城河评级 | 强/中/弱（附理由） |
| 当前估值 | PE/PB/PS + 历史分位 |
| 关键跟踪指标 | 最重要的1–3个先行指标 |
| 投资命题状态 | 感兴趣/已研究/持仓/已排除 |

---

### 季度研究节奏

**每季度**：
- 跟踪所有标的的季报/半年报/年报
- 更新标的池中核心公司的关键变量
- 完成1次季度组合复盘
- 新增1–2家公司的深度研究

**每年**：
- 完成1–2篇行业深度研究（行业年度综述）
- 更新行业研究手册
- 年度复盘：总结认知升级点
