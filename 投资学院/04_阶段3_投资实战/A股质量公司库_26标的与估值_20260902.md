# A 股质量公司库：26 标的护城河与估值

> 质量（护城河+盈利+ROE+现金流）优先、暂不考虑价格的研究清单 | 生成 2026-09-02 | 数据：iFinD 筛选+2025 年报+腾讯行情（09-01 收盘）

## 一、筛选方法

两轮量化筛选（iFinD，2026-09-02）：
1. **核心筛选**：2023/2024/2025 连续三年 ROE>15% + 2025 负债率<50% + OCF>10 亿 + 市值>100 亿 → 命中 70+
2. **补充筛选**：连续三年 ROE>12% + 负债率<65% + OCF>30 亿 + 股息率>2.5% + 市值>200 亿 → 补充成熟护城河公司

**定性过滤**（质量维度，不看价格）：剔除盈利随商品价格摆动的矿业/化工（藏格/神火/云铝/云天化/宝丰——高 ROE 来自周期顶部而非持久护城河）、技术路线快速迭代的科技硬件（中际旭创/新易盛/沪电——当期盈利强但十年可预测性弱）、游戏（产品生命周期短）、以及 2025 年报尚未验证的新标的。**保留标准：业务模式十年后仍可理解、盈利来源可解释为结构性优势而非周期。**

**最终 26 只**，按行业分组呈现。全部满足或接近：三年 ROE≥15%（个别优质公用事业/银行 ≥12%）、低负债、OCF/净利润 ≥ 80%。


**三点观察**：
1. **格力/招行是估值洼地里的质量双雄**——ROE 20%/12% 却只有 7.8x/6.8x PE，市场分别给"治理折扣"和"地产周期折扣"；两者股息率 7.5%/4.8% 提供持有底仓回报。
2. **白酒集体落入 15x 附近**——历史从未有过的四家（茅/汾/窖/缘）同时 ≤16x，行业出清后的赔率已经很好。
3. **成长溢价带的四只**（迈瑞/海天/新产业/爱美客）质量毋庸置疑，但需要增长兑现来消化估值，买的是"以合理价格买卓越公司"。

## 五、与"十标的深度研究"的关系

本清单是 [[巴菲特选股_A股十标的深度研究_20260902]] 的扩展池：原十标的全部包含在内；新增 16 只中，**格力电器、山西汾酒、华润三九、珀莱雅、海尔智家、中国海油**值得纳入下一轮深度研究优先级（质量达标 + 估值处于历史低位区）。

**建议的后续动作**：
1. 按 DCF 空间 + 质量分排序，圈定第二梯队深度研究对象
2. 白酒四家已具备"行业出清底部 + 估值 15x"的赔率特征，可做行业专题
3. 格力（7.8x/7.5% 股息）单独做治理风险评估——折价是否为永久性

## 局限

- 股息率标 * 者为估算或快照口径 `[待验证]`；药明康德 2025 ROE 28.6% 含一次性因素
- 迈瑞/爱美客/分众的 2025 利润为周期低点，"盈利持续性"评分已考虑但趋势待确认
- 未做 DCF（本清单定位为质量库+估值快照；DCF 留给深度研究对象）
- 银行仅招行入选（负债率指标对银行不适用，用不良/拨备替代判断）
