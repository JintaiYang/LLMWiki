# 优质信息源

> 原则：少而精。每天30分钟优质阅读 > 3小时噪音浏览。

---

## 一手信息源（最高优先级）

| 来源        | 获取方式                    | 内容          |
| --------- | ----------------------- | ----------- |
| 上市公司年报/季报 | cninfo.com.cn / 上交所/深交所 | 最原始的事实来源    |
| 公司投资者关系   | 各公司官网IR页面               | 路演PPT、分析师日等 |
| 监管公告      | 证监会、交易所                 | 重大事项公告      |

## 应该避免的信息源

| 类型 | 原因 |
|------|------|
| 股票群/微信群推票 | 利益不透明，信息不可靠 |
| 财经短视频（无来源）| 碎片化，缺乏深度 |
| 匿名分析师报告 | 无法验证可信度 |
| 单一来源的"内部消息" | 可能是误导性信息 |
| 基于技术分析的买卖建议 | 短期噪音，无法帮助基本面判断 |

---

## 信息处理原则

1. **来源追溯**：任何结论都要问"原始数据在哪里？"
2. **利益识别**：提供信息的人有什么动机？
3. **时效判断**：信息是过期的吗？市场是否已经定价？
4. **深度优先**：一个深度研究 > 十个浅层资讯
