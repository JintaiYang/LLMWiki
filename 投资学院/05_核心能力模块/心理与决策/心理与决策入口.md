# 心理与决策模块

> **核心问题**：为什么聪明的人在投资中系统性地犯错？如何建立抵御偏差的决策机制？

---

## 核心认知

> 投资失败的最大原因，通常不是缺乏知识，而是无法管理自己的心理。

格雷厄姆的"市场先生"寓言：
> 把市场想象成一个情绪不稳定的合伙人，他每天都会给你一个买卖报价。有时他极度乐观，报价远高于价值；有时他极度悲观，报价远低于价值。你的工作是：在他悲观时买入，在他乐观时卖出——而不是被他的情绪带着走。

---

## 一、必须了解的12个认知偏差

| 偏差 | 描述 | 在投资中的表现 |
|------|------|-------------|
| **锚定效应** | 对第一个信息过度依赖 | 买入价格成为"锚点"，影响后续判断 |
| **确认偏差** | 只寻找支持自己观点的信息 | 看多时只看利好，忽视利空 |
| **损失厌恶** | 损失的痛苦 > 同等收益的喜悦（约2倍） | 亏损时不愿止损，赚钱时过早获利了结 |
| **过度自信** | 高估自己的判断能力 | 仓位过重，缺乏分散 |
| **可得性偏差** | 对容易想到的信息赋予更高权重 | 过度关注近期新闻和短期市场波动 |
| **羊群效应** | 跟随大众行为 | 追涨杀跌，在高点入市低点出场 |
| **近因效应** | 过度重视最近发生的事 | 熊市末期认为会一直跌；牛市末期认为会一直涨 |
| **禀赋效应** | 对已拥有的东西估价过高 | 死守亏损股，认为"我买的一定是好的" |
| **事后聪明偏差** | 认为事后看来显而易见的结果是当初就可以预见的 | 破坏复盘质量；高估自己的预测能力 |
| **框架效应** | 相同信息因表述方式不同而影响判断 | 同一公司"下跌了30%"和"打了7折"引发不同情绪 |
| **代表性偏差** | 根据表面特征归类，忽视基率 | 好公司 ≠ 好投资；美好故事 ≠ 合理估值 |
| **过度交易** | 认为频繁操作能提升回报 | 交易成本侵蚀收益；错失长期复利 |

## 二、决策日志系统

**为什么要写决策日志**：
- 区分运气和能力
- 对抗事后聪明偏差（记录"当时不知道"的信息）
- 持续积累，发现自己的系统性弱点

**每次重大决策必须记录**：

```markdown
## 决策日志 YYYY-MM-DD

**标的**：[公司名+代码]
**决策**：[买入/加仓/减仓/清仓]
**价格**：[成本价]
**仓位**：[占组合比例]

### 当时掌握的信息
（列出你当时知道的关键信息，不要加入后来才知道的信息）

### 投资逻辑
（为什么买？市场在定价什么？我的判断有何不同？）

### 证伪条件
（什么情况下我的判断是错的？届时我会怎么做？）

### 预期持有期
（计划持有多久？什么时候会重新评估？）

### 情绪状态
（做这个决策时我的情绪如何？是否有非理性因素影响？）
```

## 三、复盘机制

**每次复盘的核心问题**：

1. **结果与预期对比**：实际结果如何？与预期有何差异？
2. **过程评估**：决策过程本身是否正确？（正确的过程可能有坏结果，坏的过程可能有好结果）
3. **运气还是能力**：如果结果好，是因为判断正确，还是运气？如果结果坏，是判断错误，还是小概率事件？
4. **认知升级**：从这次决策中，我对哪个概念/行业/公司的理解加深了？

**四象限复盘框架**：

```
              好结果    坏结果
好的过程  | 确认学习 | 正确但倒霉 (需坚持)
坏的过程  | 侥幸成功 | 双重教训
              ↑要区分这四种情况
```

## 四、情绪管理实践

### 建立"冷却期"规则

- **冲动卖出前**：等待24小时，重新阅读当初的买入逻辑
- **追涨买入前**：先写出买入理由，确认是基于研究而非情绪
- **大跌时**：先问"基本面改变了吗？"再考虑操作

### 建立"情绪档案"

在以下时刻记录情绪状态：
- 大盘暴跌5%以上
- 个股大涨/大跌10%以上
- 组合整体回撤超过10%
- 看到市场热点/热门股推荐

事后复盘：情绪是否影响了决策？

## 五、压力测试训练

每半年做一次以下情景演练：

1. **持仓整体回撤20%**：你会如何应对？此时的标准动作是什么？
2. **持有3年无收益**：你会放弃吗？你需要重新评估什么？
3. **核心逻辑被证伪**：你的退出程序是什么？速度有多快？
4. **市场整体崩溃**：相对于赌博，你的应对原则是什么？
