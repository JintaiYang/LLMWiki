# 行业研究模块

> **核心问题**：这个行业有没有值得投资的结构性机会？谁是最终赢家？

---

## 为什么先研究行业再选公司？

> "在一个差的行业里，即使优秀的管理层也很难赚钱；在一个好的行业里，平庸的管理层也可以赚钱。" — 巴菲特

行业研究的目的：
1. 缩小范围：找到有结构性优势的行业
2. 建立背景：理解公司所处环境，才能评判公司表现
3. 识别关键变量：知道什么数据最重要，应该跟踪什么

---

## 行业研究框架

### 第一步：行业定位

| 分析维度 | 关键问题 |
|---------|---------|
| 市场规模 | 行业有多大？成长空间还有多少？ |
| 生命周期 | 导入期/成长期/成熟期/衰退期？ |
| 需求驱动 | 需求来自哪里？是必需还是可选？ |
| 供给特征 | 供给是否容易扩张？资本门槛高低？ |

---

### 第二步：竞争格局分析（波特五力）

```
              新进入者威胁
                   ↓
供应商议价 ←  行业竞争强度  → 买家议价
                   ↑
              替代品威胁
```

| 力量 | 分析要点 |
|------|---------|
| 行业竞争强度 | 集中度（CR3/CR5）；价格战程度；差异化程度 |
| 新进入者威胁 | 资本壁垒；牌照壁垒；品牌壁垒；技术壁垒 |
| 替代品威胁 | 替代品的性价比；客户转换成本 |
| 供应商议价 | 关键原材料集中度；是否可替代 |
| 买家议价 | 客户集中度；客户对本产品的依赖程度 |

---

### 第三步：产业链分析

**目标**：找到价值链中**利润率最高、护城河最深**的环节

以芯片行业为例：
```
设计（Fabless）→ 制造（Foundry）→ 封测（OSAT）→ 设备 → 材料
   高利润率        高资本壁垒       相对低壁垒     极高壁垒   高壁垒
```

产业链分析要回答：
- 哪个环节的利润率最高？
- 哪个环节有最难以复制的壁垒？
- 利润正在向哪个环节转移？

---

### 第四步：关键变量识别

**每个行业都有2–3个最重要的先行指标**

| 行业 | 关键变量（示例） |
|------|--------------|
| 白酒 | 经销商库存；飞天茅台批价；政务消费政策 |
| 银行 | 净息差；不良贷款率；资产质量迁移率 |
| 半导体 | 硅片出货量；封测厂稼动率；客户砍单情况 |
| 新能源 | 碳酸锂价格；硅料价格；招标装机量 |
| 消费电子 | 出货量预测；供应链排单情况 |

**建立跟踪器**：找到你主攻行业的关键变量，建立月度/季度跟踪表

---

### 第五步：竞争优势识别（护城河）

| 护城河类型 | 描述 | 行业/公司案例 |
|-----------|------|------------|
| 品牌壁垒 | 消费者愿意为品牌支付溢价 | 茅台、爱马仕 |
| 转换成本 | 客户更换供应商的代价很高 | ERP系统、工业软件 |
| 规模效应 | 规模越大，单位成本越低 | 台积电、美团 |
| 网络效应 | 用户越多，平台价值越高 | 微信、Visa |
| 成本优势 | 结构性的低成本来源（不是简单的管理改善） | 宁德时代（垂直整合） |
| 监管许可 | 政府牌照/准入壁垒 | 银行牌照、机场 |

## 行业研究手册模板

完成一个行业研究后，产出一份包含以下内容的手册：

```
## [行业名称] 研究手册

### 行业概览
- 市场规模与成长性
- 行业生命周期判断

### 竞争格局
- 主要参与者及市场份额
- CR3/CR5历史变化
- 竞争强度评估

### 产业链地图
- 上下游关系图
- 各环节利润率对比
- 价值链的主要赢家

### 关键变量
- 核心先行指标（3–5个）
- 数据来源与更新频率

### 标的排序
- 核心标的（3–5家）
- 各标的优劣势对比

### 风险
- 行业层面的主要风险
- 政策风险、技术变革风险

### 更新日志
- 上次更新时间及主要变化
```
