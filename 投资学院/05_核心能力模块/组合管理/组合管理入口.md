# 组合管理模块

> **核心问题**：如何在多个标的之间合理分配资金，在控制风险的同时最大化长期回报？

---

## 核心认知

> 优秀的选股能力，加上糟糕的仓位管理，同样会导致失败。

组合管理解决的问题：
1. **集中还是分散**：持有多少只股票最合理？
2. **如何定仓位**：每只股票应该配置多少？
3. **何时再平衡**：什么情况下需要调整？
4. **如何归因**：超额收益从哪里来？

---

## 一、集中 vs 分散的权衡

### 集中组合（5–10只）

**优势**：
- 迫使你只持有最高置信度的标的
- 每只标的研究更深入
- 管理精力集中

**劣势**：
- 某只股票判断失误的代价很高
- 波动更大，心理压力更强

**适合**：研究能力强、对持仓公司有深度了解的投资者

---

### 分散组合（15–25只）

**优势**：
- 单一判断失误的影响可控
- 波动更平稳，持有体验更好

**劣势**：
- 精力分散，研究深度可能下降
- 超配大量"第5名"标的而非最优标的

**个人投资者建议**：**10–15只**为宜，需要对每只都有清晰的投资逻辑

## 二、仓位管理框架

### 凯利公式（理解概念即可）

```
f* = (bp - q) / b

其中：
f* = 建议仓位比例
b  = 胜出的赔率（如买入50、目标100，赔率b=1）
p  = 判断正确的概率
q  = 1 - p（判断错误的概率）
```

**实际操作的简化规则**：

| 置信度 | 建议仓位 |
|--------|---------|
| 极高置信（核心持仓）| 10–20% |
| 高置信 | 5–10% |
| 中等置信（观察仓）| 2–5% |
| 低置信 | 0%（不持有，继续观察）|

**不建议的做法**：
- ❌ 均等分配（每只5%）：放弃了用仓位表达置信度的机会
- ❌ 单一持仓超过25%：过度集中于单一判断

## 三、仓位调整规则

### 什么时候加仓？
- 股价下跌但基本面未变，估值更有吸引力
- 重新研究后，置信度提升
- 原有持仓比例因涨幅缩小，需要恢复目标配置

### 什么时候减仓？
- 股价上涨，估值安全边际消失
- 某标的涨幅导致占比超过设定上限
- 投资命题出现弱化信号（但未完全证伪）

### 什么时候清仓？
- 投资命题被证伪
- 出现更好的机会（机会成本）
- 触达预设止损线（纪律性止损）

## 四、风险归因分析

**Brinson模型**（简化版理解）：

```
超额收益 = 行业配置贡献 + 个股选择贡献

行业配置贡献：你配置的行业比例 vs 基准的差异带来的收益
个股选择贡献：在同一行业内，你选的股票 vs 行业平均的超额
```

**实践意义**：
- 如果你在某行业超配但回报一般，说明是"赌行业"而非选股能力
- 真正的能力体现在：在你重仓的行业里，你选的股票跑赢行业平均

## 五、组合跟踪模板

每季度更新以下内容：

| 标的 | 成本价 | 当前价 | 仓位% | 投资命题 | 命题状态 | 下次评估时间 |
|------|--------|--------|-------|---------|---------|------------|
| [公司A] | | | | | 成立/弱化/证伪 | |
| [公司B] | | | | | | |

**命题状态解释**：
- **成立**：核心假设仍然有效，继续持有
- **弱化**：有信号显示假设可能出错，需要密切关注
- **证伪**：核心假设已被事实否定，考虑退出

## 六、现金管理

**现金不是"空仓"，是"等待更好机会的期权"**

| 市场环境 | 建议现金比例 | 理由 |
|---------|------------|------|
| 普遍高估（市场情绪极度乐观）| 20–40% | 好机会少，耐心等待 |
| 正常环境 | 5–15% | 保留灵活性 |
| 普遍低估（市场恐慌） | <5% | 机会多，充分配置 |
