# 财务分析模块

> **核心问题**：这家公司赚的钱是真实的吗？质量如何？可持续吗？

---

## 学习路径

```
三张报表基础 → 盈利质量分析 → 资产质量分析 → 现金流深度解读 → 跨公司比较
```

---

## 一、三张报表基础

### 损益表（利润表）

**关键指标**：

| 指标 | 计算 | 分析要点 |
|------|------|---------|
| 毛利率 | 毛利/营收 | 行业竞争优势的直接体现；同比/环比趋势 |
| 净利率 | 净利/营收 | 费用控制能力；是否在改善 |
| 营收增速 | YoY增长% | 是量驱动还是价驱动？ |
| 费用率 | 期间费用/营收 | 销售/管理/研发费用的合理性 |

**关键问题**：
- 收入是否可持续？（一次性收入？政府补贴？）
- 利润增速是否跑赢收入增速？（说明利润质量提升）
- 非经常性损益有多少？剔除后净利如何？

---

### 资产负债表

**关键指标**：

| 指标          | 分析要点             |
| ----------- | ---------------- |
| 应收账款/营收     | 比例是否在上升？是否有坏账风险？ |
| 存货周转天数      | 是否在积压？行业对比如何？    |
| 商誉          | 并购后是否面临减值风险？     |
| 资产负债率       | 杠杆水平；行业特性决定合理区间  |
| 有息负债/EBITDA | 偿债能力；>4x需要警惕     |

**关键问题**：
- 资产中有多少是"水分"（商誉、长期待摊费用、其他应收款）？
- 公司的现金是否是真实可动用的？

---

### 现金流量表

**最重要的一张表，但最容易被忽视**

| 对比项 | 正常信号 | 警示信号 |
|--------|---------|---------|
| 经营现金流 vs 净利润 | 经营现金流 ≥ 净利润 | 持续低于净利润（利润可能虚构） |
| 投资现金流 | 资本支出与发展阶段匹配 | 大量并购，商誉激增 |
| 自由现金流 | 稳定为正且在增长 | 持续为负（需要外部融资维持）|
| 分红来源 | 来自经营现金流 | 借债分红（警示） |

**公式**：
> 自由现金流（FCF）= 经营现金流 - 资本支出（CapEx）

---

## 二、盈利质量分析

**核心指标**：经营现金流/净利润（Cash Conversion Ratio）

| 比率       | 信号          |
| -------- | ----------- |
| > 100%   | 优质，现金创造能力强  |
| 80%–100% | 良好          |
| 60%–80%  | 需要关注，深入调查原因 |
| < 60%    | 警示，利润可能存在水分 |

**其他盈利质量信号**：
- 应收账款增速 vs 营收增速（应收增速持续快于营收 = 警示）
- 其他应收款规模（资金是否被大股东占用？）
- 预收款趋势（减少可能意味着预订/客户减少）

---

## 三、ROE与杜邦分析

**ROE = 净利率 × 资产周转率 × 财务杠杆**

通过拆解ROE，理解驱动因素：

| 驱动因素 | 优质信号 | 需警惕 |
|---------|---------|--------|
| 净利率提升 | 产品力提升/规模效应 | 靠降低费用投入（透支未来） |
| 资产周转率提升 | 经营效率改善 | 应收账款暴增带来的虚假提升 |
| 财务杠杆提升 | 合理扩张 | 过度借贷，风险上升 |

**茅台的ROE为什么高且稳定？** → 极高净利率 + 无需高杠杆 + 轻资产模式

---

## 四、实践练习

### 财报拆解三步法

**Step 1**：先看现金流量表（判断利润质量）  
**Step 2**：再看损益表（看收入和盈利趋势）  
**Step 3**：最后看资产负债表（判断资产质量和偿债能力）

### 跨公司比较框架

同行对比时，重点看：
1. 毛利率差异（谁的产品定价权更强？）
2. 费用率差异（谁的管理效率更高？）
3. 现金转化率差异（谁的利润更"真实"？）
4. ROE差异及驱动因素
