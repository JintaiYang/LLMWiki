# 低空经济 risk map

## 一句话判断
低空经济的核心风险，不在于有没有故事，而在于监管、适航、需求、订单兑现和估值预期能否同向推进；风险管理必须同时写清概率、影响、预警指标和证伪标准。

## 使用规则
- 风险分为行业级、赛道级、项目级、交易级四层。
- 每条风险都必须包含：概率、影响、预警指标、证伪标准、应跟踪页面。
- “概率 × 影响”用于排优先级，不代表精确预测。
- 本页用于研究风险管理，不构成买卖建议。

## 风险评级口径
| 概率 | 定义 |
| --- | --- |
| 高 | 已经出现多个信号，未来 6-12 个月较大概率触发 |
| 中 | 有明显苗头，但仍需更多证据确认 |
| 低 | 目前证据不足或更偏尾部场景 |

| 影响 | 定义 |
| --- | --- |
| 高 | 会改变赛道或核心公司的定价框架 |
| 中 | 会影响节奏或估值，但不改变长期方向 |
| 低 | 主要影响短期预期或局部项目 |

## 风险传导链
政策预期降温或适航延后
→ 项目和运营推进变慢
→ 订单从 L2 向 L3/L4 升级不足
→ 收入与回款滞后
→ 市场定价重新回到主题映射和情绪交易

## 风险处理原则
1. 先识别是否是“节奏风险”还是“逻辑风险”。
2. 若只是节奏延后，保留主线但下调兑现时间表。
3. 若证伪标准被触发，必须直接下调结论，不得只改措辞。
4. 高概率高影响风险必须对应到明确的跟踪指标和更新频率。

## 待验证问题
- 当前行业最先触发的高等级风险，会是适航延后、需求不足，还是主题交易回撤？
- 哪些风险是赛道共性，哪些风险只集中在载人 eVTOL 或地方基建项目？
- 哪些风险可以通过更高质量订单和回款数据被有效证伪？

## 下一步跟踪行动
- 为每一条高等级风险补充至少一个量化预警阈值。
- 将高优先级风险映射到重点公司和重点项目。
- 每次重大催化落地后，复核该催化是降低还是放大风险。
