# 工业级无人机技术体系

## 一句话判断
工业级无人机的核心不在“会不会飞”，而在“能否持续完成任务、稳定交付结果、满足合规要求并保持单位经济性”；因此它是平台、载荷、软件、通信和服务的系统工程。

## 核心事实
1. 工业级无人机通常由飞行平台、任务载荷、飞控航电、通信链路、地面系统和任务软件共同构成。
2. 不同场景对技术体系要求差异很大：巡检强调稳定与识别，植保强调效率与作业能力，应急强调可靠与快速部署。
3. 工业级无人机服务链往往比载人 eVTOL 更早看到真实需求和收入样本，但仍受 [[民用无人驾驶航空器监管]] 与空域管理约束。
4. 技术体系研究要与 [[飞控与航电系统]]、[[低空智联网与通信导航]] 联动看，而不是只看整机参数。

## 研究拆解
| 模块 | 作用 | 投资关注点 |
| --- | --- | --- |
| 飞行平台 | 完成飞行任务 | 成本、可靠性、适配性 |
| 任务载荷 | 完成具体业务 | 价值量、场景壁垒 |
| 飞控航电 | 决定稳定、安全和自动化 | 高壁垒、高附加值 |
| 通信与导航 | 支撑超视距和协同作业 | 规模化运行前提 |
| 软件平台 | 调度、数据处理、复盘 | 持续服务收入潜力 |
| 运维服务 | 培训、维修、任务运营 | 现金流更可持续 |

## 投资含义
- 工业级无人机更适合作为“业绩验证锚点”赛道，因为需求基础和商业模式通常早于载人场景。
- 真正值得研究的，不只是卖机，而是能否绑定长期服务、软件和运维收入。
- 若公司只强调整机参数，却缺少场景、客户和复购数据，结论应下调置信度。

## 关键指标
- 飞行小时、单机利用率、续约率、任务成功率。
- 硬件收入与服务收入结构。
- 合规能力、超视距运行能力与项目回款，见 [[核心指标跟踪器]]。
