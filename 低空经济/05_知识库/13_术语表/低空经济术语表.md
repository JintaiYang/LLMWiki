# 低空经济术语表

## 一句话判断
低空经济研究里，最容易误判的不是技术词太难，而是同一个词在“设计、生产、单机、运营、财务”里的对象根本不同，尤其是 TC/PC/AC/OC 必须严格分开。

## 核心事实
| 术语 | 简释 | 研究提示 |
| --- | --- | --- |
| eVTOL | 电动垂直起降航空器 | 不等于一定能商用，还要看证照和运营体系 |
| UAV / 无人驾驶航空器 | 不依赖机上驾驶员操纵的航空器 | 监管口径要看用途、重量、风险等级 |
| UAS | 无人驾驶航空器系统 | 不只是飞行器，还包括地面站、通信链路和控制系统 |
| TC | 型号合格证 | 针对型号设计，不是量产许可，不是运营许可 |
| PC | 生产许可证 | 针对持续稳定生产能力，不等于单机已具备运行资格 |
| AC | 标准适航证 | 针对单架航空器，证明该架机处于可安全运行状态 |
| OC | 运营合格证 | 针对运营主体，不是飞行器证；拿到前通常难做商业运营 |
| BVLOS | 超视距运行 | 需要更高等级的通信、监视和运行管理能力 |
| Remote ID | 远程识别 | 监管和城市运行的重要基础能力 |
| UTM | 无人机交通管理 | 是低空大规模飞行的数字化管理底座之一 |
| Vertiport | 垂直起降场 | 对 eVTOL 运营重要，但规划不等于高利用率 |
| C2 链路 | 指挥与控制链路 | 冗余、可靠性和抗干扰很关键 |
| 航电 | 航空电子系统 | 往往体现高门槛和高附加值 |
| 电推进 | 电机、电控、桨叶等推进系统 | 与效率、噪声、安全和维护直接相关 |
| 单位经济性 | 单次任务或单小时飞行的收益成本结构 | 场景能否长期成立的关键 |

## 投资含义
- 看到“拿证”时，必须先问：拿的是型号证、生产证、单机适航证，还是运营主体的 OC。
- 看到“订单”时，必须先问：卖的是飞行器、平台软件、运维服务，还是一次性基建项目。
- 看到“市场规模”时，必须先问：口径是否包含整机、运营、基础设施和服务。
