# 低空经济完整研究框架

## 一句话判断
低空经济研究最怕把“政策、技术、场景、订单、利润、估值”混成一句话；好的框架必须让每一层都有对应事实、指标、证伪条件和更新时间。

## 核心事实
本框架按六个问题层推进：
1. 规则是否允许：看 [[中国低空经济政策体系]]、[[空域分类与协同管理]]、[[民用无人驾驶航空器监管]]。
2. 产品是否可商用：看 [[eVTOL适航认证流程]]、[[eVTOL技术路线]]、[[工业级无人机技术体系]]。
3. 系统是否能运行：看 [[低空智联网与通信导航]]、[[起降场与低空基础设施]]、[[低空经济系统架构]]。
4. 场景是否有付费需求：看订单质量、复购、飞行小时、利用率。
5. 公司是否能兑现：看收入、毛利、现金流、资本开支和披露纯度。
6. 市场是否已提前交易：看 [[低空经济机会矩阵]]、[[低空经济 risk map]]、[[估值风险与主题交易风险]]。

## 核心研究问题清单
| 层级 | 要回答的问题 | 常见误判 |
| --- | --- | --- |
| 政策 | 这件事是否被允许、由谁管、规则是否清晰 | 把政策定调等同于可运营 |
| 适航/监管 | 产品和主体分别拿到什么证照 | 把 TC/AC/OC 混为一谈 |
| 技术 | 短板在飞控、动力、电池、网络还是制造 | 把样机进展等同于批量交付 |
| 场景 | 谁付费、多久复购、单位经济性是否成立 | 把演示场景等同于真实需求 |
| 订单 | 是意向、框架、正式合同、验收还是回款 | 把签约金额等同于收入 |
| 财务 | 能否在报表中体现收入、利润和现金流 | 把概念映射等同于主营贡献 |
| 估值 | 当前交易的是政策、订单还是业绩 | 用远期 TAM 直接给当前估值 |

## 投资含义
- 低空经济的关键不只是“有没有产业趋势”，而是每一层能否穿透到下一层。
- 研究时要优先记录“阻断点”：例如监管未明、空域未开、起降设施不足、运营主体无 OC、订单停在 L1-L2。
- 一家公司只有同时回答“真实关联、价值捕获、兑现阶段、证据等级”四个问题，才值得进入主研究池。

## 关键指标
- 规则层：实施细则数量、试点名单、预算与招标节奏。
- 证照层：TC/PC/AC/OC，见 [[适航进度跟踪器]]。
- 项目层：L1-L5 升级数量和周期，见 [[订单与项目跟踪器]]。
- 财务层：低空业务收入、毛利率、现金回款和资本开支，见 [[核心指标跟踪器]]。
