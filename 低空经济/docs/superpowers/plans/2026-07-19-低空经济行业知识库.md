# 低空经济行业知识库 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use parallel research agents for source collection, then integrate results centrally to avoid concurrent file conflicts. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在当前 Vault 建成 40–50 页、面向中国低空经济投资研究、资料尽量更新至 2026-07-19 的可持续 Obsidian LLM Wiki。

**Architecture:** 先建立维护契约、目录和模板，再让独立研究 Agent 分别完成行业政策技术、应用场景、公司标的、投资跟踪的来源调研。主 Agent 根据研究结果统一写入结构化页面，最后生成导航、索引和健康检查报告并执行链接与 frontmatter 校验。

**Tech Stack:** Markdown、YAML frontmatter、Obsidian Wiki Links、公开监管文件、上市公司公告与年报、行业协会及企业正式资料。

## Global Constraints

- 市场范围：中国市场为主，海外仅作监管、技术、商业化和代表公司对标。
- 研究目的：投资研究。
- 数据截止：尽量更新至 2026-07-19，优先采用已发布的 2025 年报和 2026 年政策、公告及经营数据。
- 首版规模：40–50 个结构化知识页面，不为凑数量创建空洞页面。
- 关键数据必须给出可追溯 URL、资料标题或正式出处。
- 明确区分事实、推断、预测、规划、意向订单、确定订单、交付、收入和回款。
- 每个知识页面必须含完整 frontmatter、至少两个有效 `[[双链]]`、待验证问题和下一步行动。
- 不提供个股买卖建议，不编造缺失数据。
- 不修改当前仓库中低空经济 Vault 之外的任何既有未提交文件，不创建 Git 提交。
