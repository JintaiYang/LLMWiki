# 通用知识页面模板

> 本模板适用于 `05_知识库/` 下除公司页（`type: player`）外的各类知识页面。
> 公司页请使用 `03_模板/公司研究页面模板.md`。
> 维护规则以 `06_维护契约.md` 为准；本模板仅提供结构与占位符，**不包含任何真实事实**。

## 使用方法

1. 复制本文件到 `05_知识库/` 下对应语义子目录，重命名为 `<页面标题>.md`。
2. 按下表填写 frontmatter，删除所有 `<>` 占位符与 `# 注释`。
3. 按正文短节填写内容，每条实质性声明按契约 §4 标注 `[事实]` / `[推断]` / `[待验证]`。
4. `related` 至少 2 项，且对应文件真实存在。
5. 完成后在 `09_操作日志.md` 追加 `update` 条目。

## Frontmatter

```yaml
---
title: <页面标题，与文件名一致>
type: <industry | player | customer | pain_point | keyword | opportunity | validation | synthesis | source | framework | tracker | glossary | risk | workload | system | map | route>
status: <seed | growing | mature>
industry: 低空经济
market: 中国
research_purpose: 投资研究
evidence_level: <low | medium | high>

created: YYYY-MM-DD
updated: YYYY-MM-DD
data_as_of: YYYY-MM-DD

tags: []
aliases: []
related: [<关联页面文件名>, <关联页面文件名>]

source_url: ""
sources: []

next_action: "<下一步维护或验证行动>"
owner: ""

verify_status: <fact | inference | unverified>
---
```

### 字段说明

| 字段 | 必填 | 取值 / 说明 |
| --- | --- | --- |
| `title` | 是 | 人类可读标题，与正文 H1 一致 |
| `type` | 是 | 枚举值，对应页面语义类型 |
| `status` | 是 | `seed` 仅有框架；`growing` 已有实质内容；`mature` 内容完整且经校验 |
| `evidence_level` | 是 | 判断与来源强度，非主题重要度；取值见契约 §3 |
| `created` / `updated` | 是 | 创建日不变；更新日为最近实质性更新 |
| `data_as_of` | 是 | 页面内关键数据的数据截止日，非写作日 |
| `related` | 是 | 文件名列表（不含路径、不含 `.md`），≥2 项 |
| `verify_status` | 是 | 页面主结论的三态标记；正文逐条声明仍须单独标注 |
| `sources` | 是 | 全部引用来源；正文每个 `[事实]` 都能在此追溯 |
| `next_action` | 是 | 下一步验证或维护行动，不可为空字符串 |

## 正文结构

以下短节为推荐顺序，`核心事实` / `推断` / `待验证问题` / `下一步跟踪行动` / `来源` 五节**不可省略**。不同页面类型可增加专属章节，但不得省略这五节。

---

<用一句话说明本页主题是什么、为什么重要，以及当前所处阶段。含推断或待验证时句尾标注。>

> 本页主题处于政策预期向产品验证迁移的阶段（推断）。

### 核心事实

> [事实] <已确认的数据或已发生事件，必须附来源。>
> 来源：<URL 或出处标识>

<可列多条，每条独立引用块。无来源的判断不得放入本节。>

### 投资含义或合理推断

> [推断] <基于事实的推论，注明证据等级与推理依据。>

- `[[<关联页面文件名>]]` — <一句话说明关联关系>

## 三态标注速查

| 标注 | 适用 | 语法 |
| --- | --- | --- |
| 事实 | high/medium 来源确认的客观数据 | `> [事实]` 引用块 + 来源 |
| 推断 | 基于事实的推论，未独立证实 | `> [推断]` + 证据等级 + 依据 |
| 待验证 | 无可靠来源的假设/线索 | `> [待验证]` + 验证行动 |

## 易错点提醒

- 规划目标、预测值、意向订单不得与已实现数据混列，须分属不同三态（契约 §4.2、§5、§7）。
- 市场规模须标统计范围、基期、预测年份（契约 §7.1）。
- 订单须标 L1–L5 级别（契约 §5）；公司页订单跟踪见公司模板。
- 资质须区分 TC/PC/AC/OC（契约 §6）；不得把型号认证等同于运营资质。
