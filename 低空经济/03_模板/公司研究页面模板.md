# 公司研究页面模板

> 本模板适用于 `type: player` 的公司页，存放于 `05_知识库/03_品牌库/`。
> 非公司页请使用 `03_模板/通用知识页面模板.md`。
> 维护规则以 `06_维护契约.md` 为准；本模板仅提供结构与占位符，**不包含任何真实事实**。

## 使用方法

1. 复制本文件到 `05_知识库/03_品牌库/`，重命名为 `<公司简称>.md`。
2. 填写 frontmatter，删除所有 `<>` 占位符与 `# 注释`。
3. 按正文短节填写，每条实质性声明按契约 §4 标注 `[事实]` / `[推断]` / `[待验证]`。
4. 订单表按契约 §5 标 L1–L5；资质表按契约 §6 标 TC/PC/AC/OC。
5. 财务表按契约 §7.5 标期间、单位、口径、币种；无数据写"数据缺失"。
6. `related` ≥2 项；完成后在 `09_操作日志.md` 追加 `update` 条目。

### 扩展字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `listed` | 是 | 是否上市；非上市公司须在正文显式标注"无完整公开财务数据"边界 |
| `ticker` | 是 | 上市代码；未上市留空字符串 |
| `stage` | 是 | 公司当前业绩兑现阶段，取值见契约 §2 / 设计规格 §7 |
| `order_maturity` | 是 | 代表性订单最高成熟度，取值见契约 §5 |
| `cert_progress` | 是 | 已取得的适航/运营资质，子集 `[TC, PC, AC, OC]`；未取得留空数组 |

## 三态标注速查

| 标注 | 适用 | 语法 |
| --- | --- | --- |
| 事实 | high/medium 来源确认的客观数据 | `> [事实]` + 来源 |
| 推断 | 基于事实的推论 | `> [推断]` + 证据等级 + 依据 |
| 待验证 | 无可靠来源的假设 | `> [待验证]` + 验证行动 |

## 易错点提醒

- 订单 L1–L2 不得与 L3 合并报数；L3 起才能进入"确定订单"汇总（契约 §5）。
- 取得 TC 不等于取得 PC/AC/OC，"已获认证"须指明哪一证（契约 §6）。
- 合同额 ≠ 确认收入 ≠ 回款 ≠ 利润贡献，须分列（契约 §7.2）。
- 公司整体营收 ≠ 低空业务营收，须区分（契约 §7.4）。
- 财务期间与口径必须一致（契约 §7.5）；非上市公司不用融资宣传替代经营数据。
- 数据更新保留历史对比，不覆盖旧值（契约 §8.3）。
