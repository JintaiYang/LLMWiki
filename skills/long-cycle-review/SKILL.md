# 长周期公司复盘 Skill

## 定位

对任意上市公⽰执⾏ 10-30 年维度的全⾯复盘，产出⼀份结构化 Obsidian Markdown ⽂档。核⼼理念是 **"战略阶段驱动叙事"**——按公司战略转折点划分时代，⽽⾮简单按年份堆砌数据。

## 适⽤范围

- **银⾏**：招⾏、兴业、平安、宁波等（NIM、CET1、不良率、拨备等）
- **消费品**：茅台、五粮液、伊利、海天等（毛利率、渠道库存、品牌溢价等）
- **科技/互联⽹**：腾讯、⼩⽶、中芯国际等（研发投⼊、客户增长、ARS等）
- **医药**：恒瑞、百济神州等（管线进展、研发费率、商业化能⼒等）
- **其他⾏业**：任何有 10 年以上上市历史、可获取历年财报的公司

## 触发条件

当⽤户提出以下请求时激活：
- "复盘 XXX 近 N 年"
- "对 XXX 做⼀个长周期分析"
- "⽤这套⽅法论分析 XXX"
- "给 XXX 写⼀个 10/20/30 年回顾"

## 产出规格

- **⽂件路径**：`<⾏业库>/03_公司库/<公司名> N年复盘.md`（或⽤户指定路径）
- **⽂档规模**：800-1200⾏，按战略阶段⽽⾮年度组织
- **表格**：三线表格式，指标对照表贯穿全⽂
- **证据标注**：每个关键数据标注 `official_fact` / `research_inference` / `third_party_data`

## 核核⼼⼯作流

### 第 1 步：划定范围与分阶段

1. 确认公司、时间跨度（最短 10 年）、数据可获取性
2. 按 **战略转折点** ⽽⾮等间隔年份划分 3-7 个阶段
3. 判断转折点的依据：管理层更替、战略发布、重⼤并购、业务转型、危机事件、政策变⾰
4. 产出⼀张「时代鸟瞰图」总表

### 第 2 步：逐阶段七维度分析

每个阶段从以下七个维度展开，缺⼀不可：

| 维度 | 关键问题 | 通⽤指标 |
|---|---|---|
| **战略选择** | 管理层当时⾯临什么局⾯？做了什么选择？为什么？ | 战略⽂本、时间线图 |
| **主营业务变化** | 收⼊结构、产品线、客户群体发了什么变化？ | 收⼊拆分、产品矩阵、客户结构 |
| **盈利能⼒** | 赚钱效率如何变化？驱⼒是什么？ | ROE、ROA、毛利率、费率、单位经济模型 |
| **资产负债结构** | 资产质量、杠杆⽔平、结构是否健康？ | ⾏业特异性指标（⻅适配层） |
| **风险与质量** | 隐藏了什么风险？是否在好转或恶化？ | 风险前瞻指标、拨备/减值、周期定位 |
| **资本配置与分红** | 利润去哪了？再投资、分红、回购？ | 分红率、再投资率、资本配置效率 |
| **股价表现** | 股价是否反映基本⾯？估值如何变化？ | 后复权股价、PE/PB区间、市值⾼低点 |

### 第 3 步：全周期纵向对照

将关键指标拉成 10-30 年纵向表，选取 5-8 个代表年份（⽽⾮逐年），标注趋势⽽⾮精确值。每张表配解读段落。

### 第 4 步：复盘总结

- **护城河评估**：哪些优势跨越了周期？哪些消失了？哪些在退化？
- **核⼼战略决策排序**：历史最关键的 3-5 个决策及其效果
- **最⼤教训**：哪些判断被证明是错的？哪些风险被低估了？
- **估值启示**：股价涨幅 vs 利润增幅的背离及原因

### 第 5 步：前瞻跟踪框架

- 未来 3 年最关键的 5-8 个跟踪指标（带灯号系统：绿灯/黄灯/红灯）
- 三情景估值推演（乐观/中性/悲观）
- 概率判断与触发条件

## 分阶段命名规范

阶段名称应体现 **战略特⾊** ⽽⾮时间编号：

| 好的命名 | 不好的命名 |
|---|---|
| "蛇⼝起步期" | "第⼀阶段" |
| "零售转型期" | "2002-2008年" |
| "轻型银⾏期" | "成长期" |
| "品牌收割期"（茅台） | "成熟期" |
| "移动互联转型期"（腾讯） | "转型期" |

## 证据分级标准

| 标签 | 含义 | 数据处理 |
|---|---|---|
| `official_fact` | 年报、公告、监管披露的正式数据 | 精确到⼩数点后两位 |
| `research_inference` | 基于事实的研究推断 | 标注推断逻辑和依据 |
| `third_party_data` | Wind/AkShare/⾏业协会等第三⽅数据 | 标注来源名称 |
| `estimated` | 因早期数据缺失做的量级估算 | ⽤ `~` 前缀表⽰，标注误差范围 |
| `待验证` | ⽆法确认的说法或数据 | 原样保留，不做填补 |

## 数据精度分级

| 时期 | 精度 | 处理⽅式 |
|---|---|---|
| 上市前 | 估算级 | 基于招股书/公开史料，量级参考，误差 10-20% |
| 上市后 5 年内 | 中等 | 年报数据，部分指标⼝径可能与现⾏不同 |
| 上市 5 年后 | 较⾼ | 年报+第三⽅数据，⼝径基本统⼀ |
| 近 10 年 | ⾼ | 数据完整，可做严格分析 |
