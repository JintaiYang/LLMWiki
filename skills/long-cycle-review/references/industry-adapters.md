# 行业适配层

> 本文件定义不同行业在七维度分析中的特异性指标。通用指标参见 `long-cycle-review-methodology.md`，此处只列行业特异部分。

---

## 一、银行

### 盈利能力特异指标

| 指标 | 公式 | 优秀标准 | 关注要点 |
|---|---|---|---|
| NIM（净息差） | 利息净收入 / 平均生息资产 | >2.0%（大行）/ >2.5%（股份行） | 趋势 > 绝对值；区分结构性下行 vs 周期性波动 |
| 净利差 | 生息资产收益率 - 计息负债成本率 | >2.0% | 衡量"买卖价差" |
| 成本收入比（CIR） | 业务管理费 / 营业收入 | <35% | 效率指标，越低越好 |
| 非息收入占比 | 非息收入 / 营业收入 | >30% | 轻资本程度 |
| PPOP增速 | 拨备前利润增速 | >营收增速 | 判断盈利质量——利润增速靠拨备释放还是经营改善 |

### 资产负债结构特异指标

| 指标 | 公式 | 关注要点 |
|---|---|---|
| 活期存款占比 | 活期存款 / 总存款 | 低成本负债护城河，>50%为优秀 |
| 零售存款占比 | 零售存款 / 总存款 | 零售客户基础 |
| 存款成本率 | 利息支出 / 平均计息负债 | 负债端定价能力 |
| 贷款/总资产 | 贷款净额 / 总资产 | 资产结构 |
| 零售贷款占比 | 零售贷款 / 总贷款 | 收益率与风险权重的平衡 |
| 同业负债占比 | 同业负债 / 总负债 | 稳定性，<30%为安全 |

### 风险与质量特异指标

| 指标 | 公式 | 优秀标准 | 关注要点 |
|---|---|---|---|
| 不良率 | 不良贷款 / 贷款总额 | <1.5% | 时点指标，需结合新生成不良 |
| 关注类比例 | 关注类贷款 / 贷款总额 | <3% | 不良前瞻指标 |
| 逾期90天以上比例 | 逾期90天+ / 贷款总额 | <1.5% | 比不良率更客观 |
| 不良/逾期90天剪刀差 | 不良贷款 / 逾期90天+ | >100% | 认定严格度，>100%表示认定宽松的已覆盖 |
| 拨备覆盖率 | 拨备余额 / 不良贷款 | >150% | 安全垫厚度 |
| 拨贷比 | 拨备余额 / 贷款总额 | >2.5% | 拨备充足度的另一种度量 |
| 信用成本率 | 当期拨备计提 / 平均贷款 | — | 利润弹性来源 |
| 新生成不良率 | 当期新生成不良 / 期初贷款 | <1% | 最前瞻的不良指标 |

### 资本配置特异指标

| 指标 | 公式 | 优秀标准 | 关注要点 |
|---|---|---|---|
| CET1（核心一级资本充足率） | 核心一级资本 / 风险加权资产 | >10.5%（监管+缓冲） | 增长天花板，决定能否内生增长 |
| 资本充足率（CAR） | 总资本 / 风险加权资产 | >14% | 整体资本充足度 |
| RWA增速/总资产增速 | 风险加权资产增速 / 总资产增速 | <1 | 资本消耗效率，<1表示轻资本化 |
| 内生增长率 | CET1留存支撑的RWA增速上限 | >贷款增速 | 能否不融资靠自身增长 |
| 杠杆率 | 一级资本 / 表内外总资产 | >6% | 简单杠杆，不受风险权重影响 |

### 股价与估值特异指标

| 指标 | 关注要点 |
|---|---|
| PB | 银行主要估值方法，ROE越高PB越高 |
| PE | 辅助参考，因利润受拨备影响波动大 |
| 股息率 | 银行股重要回报来源，>4%有吸引力 |
| PB-ROE 联动 | PB = ROE / 要求回报率（稳态）；判断当前PB是否匹配ROE |

### 银行复盘分阶段参考

| 阶段类型 | 典型战略 | 典型转折事件 |
|---|---|---|
| 起步期 | 区域→全国扩张 | 上市、一卡通等基础产品 |
| 零售转型期 | 零售银行战略 | 信用卡、财富管理发布 |
| 二次转型期 | 降资本消耗、提定价 | 管理层更替、Basel III实施 |
| 轻型银行期 | 数字化、轻资本 | App上线、MAU战略 |
| 价值银行期 | 大财富管理 | AUM突破里程碑 |
| 息差承压期 | 守住护城河 | NIM跌破2%、LPR下调 |

## 二、消费品（白酒/食品饮料/日化）

### 盈利能力特异指标

| 指标 | 公式 | 优秀标准 | 关注要点 |
|---|---|---|---|
| 毛利率 | (营收 - 营业成本) / 营收 | >60%（高端白酒）/ >40%（快消） | 品牌定价权的直接体现 |
| 吨价 | 营收 / 销量 | 持续上升 | 结构升级与提价能力 |
| 单瓶/单吨利润 | 净利润 / 销量 | 持续上升 | 单位经济模型改善 |
| 预收款/合同负债增速 | 同比 | >营收增速 | 渠道打款意愿，领先指标 |
| 广告费用率 | 广告宣传费 / 营收 | 稳定或下降 | 品牌投入效率 |

### 资产负债结构特异指标

| 指标 | 公式 | 关注要点 |
|---|---|---|
| 存货周转天数 | 365 / (营业成本 / 平均存货) | 白酒越长越好（陈化增值），快消越短越好 |
| 合同负债（预收款） | 期末余额 | 渠道健康度领先指标 |
| 经销商数量 | 期末数量 | 渠道扩张/收缩 |
| 在产品/自制半成品 | 期末余额 | 白酒基酒储备，未来产能 |
| 固定资产/总资产 | — | 轻资产 vs 重资产模式 |

### 风险与质量特异指标

| 指标 | 关注要点 |
|---|---|
| 渠道库存 | 预收款增速 < 营收增速 = 库存积压信号 |
| 批价/零售价 | 批价下跌 = 需求走弱或渠道抛货 |
| 品牌力 | 提价后销量是否受影响（价格弹性） |
| 食品安全事件 | 行业级风险（如塑化剂、三聚氰胺） |
| 政策风险 | 消费税改革、限制三公消费等 |
| 基酒储备 | 白酒特有——基酒年限决定未来中高端产品产能 |

### 资本配置特异指标

| 指标 | 关注要点 |
|---|---|
| 分红率 | 消费品通常 50%+，茅台 51.9% |
| 资本开支/折旧 | <1 表示不再大规模扩产 |
| 品牌维护投入 | 广告费用率趋势——下降可能是短期利润增厚但长期品牌退化 |
| 产能扩张 | 新增产能计划与达产时间 |

### 股价与估值特异指标

| 指标 | 关注要点 |
|---|---|
| PE | 消费品主要估值方法，PE 20-40 倍常见 |
| EV/EBITDA | 跨资本结构比较 |
| 股息率 | 消费品稳定分红，>3% 有吸引力 |
| 市值/品牌价值 | 品牌是否被低估或高估 |

### 消费品复盘分阶段参考

| 阶段类型 | 典型战略 | 典型转折事件 |
|---|---|---|
| 品牌建立期 | 产品奠基、渠道铺设 | 上市、核心产品发布 |
| 渠道扩张期 | 经销商网络扩张 | 渠道改革、区域→全国 |
| 品牌升级期 | 结构升级、提价 | 消费升级、高端化战略 |
| 危机调整期 | 渠道出清、品牌修复 | 行业危机（塑化剂等）、政策冲击 |
| 品牌收割期 | 利润释放、高分红 | 成熟期，增速放缓但盈利稳定 |

## 三、科技/互联网

### 盈利能力特异指标

| 指标 | 公式 | 关注要点 |
|---|---|---|
| 毛利率 | (营收 - 营业成本) / 营收 | 技术壁垒与定价权 |
| 研发费用率 | 研发费用 / 营收 | >10% 为高研发投入；研发产出效率更重要 |
| ARPU | 单用户收入 | 用户变现能力 |
| LTV/CAC | 客户终身价值 / 获客成本 | >3 为健康 |
| 收入增速 | 同比 | 科技公司成长性 > 盈利性 |
| 自由现金流 | 经营现金流 - 资本开支 | 成熟期科技公司核心指标 |

### 资产负债结构特异指标

| 指标 | 关注要点 |
|---|---|
| 现金及等价物 | 科技公司通常现金充裕 |
| 商誉/净资产 | 并购溢价风险，>30% 需警惕 |
| 研发资本化比例 | 资本化高 = 当期利润好看但资产虚增 |
| 轻资产程度 | 固定资产/总资产，科技通常 <20% |
| 用户资产 | MAU/DAU、付费用户数 |

### 风险与质量特异指标

| 指标 | 关注要点 |
|---|---|
| 技术替代风险 | 新技术是否颠覆现有产品 |
| 客户集中度 | 前五大客户占比 |
| 供应链依赖 | 关键供应商或技术依赖 |
| 数据安全/隐私 | 合规风险 |
| 人才流失率 | 核心技术人员稳定性 |
| 专利/知识产权 | 护城河可验证性 |

### 股价与估值特异指标

| 指标 | 适用场景 |
|---|---|
| PE | 成熟期、稳定盈利的科技公司 |
| PS | 高成长、亏损期 |
| EV/Revenue | SaaS、互联网 |
| DCF | 自由现金流稳定的成熟期 |
| 用户估值 | 市值/MAU，互联网早期 |

### 科技公司复盘分阶段参考

| 阶段类型 | 典型战略 | 典型转折事件 |
|---|---|---|
| 技术奠基期 | 核心技术突破、产品验证 | 创始产品发布、IPO |
| 规模扩张期 | 用户/客户增长、市场份额 | 关键产品迭代、市场突破 |
| 平台化期 | 生态构建、平台效应 | 开放平台、生态系统战略 |
| 变现成熟期 | 商业化、利润释放 | 盈利模式跑通、利润率提升 |
| 转型期 | 第二曲线 | 技术变革、新业务转型 |

## 四、医药

### 盈利能力特异指标

| 指标 | 公式 | 关注要点 |
|---|---|---|
| 研发费用率 | 研发费用 / 营收 | 创新药 >15%，仿制药 <10% |
| 商业化收入增速 | 新药上市后收入增速 | 管线变现能力 |
| 毛利率 | 分产品线毛利率 | 创新药 >80%，仿制药 40-60% |
| 海外授权收入 | License-out 金额 | 创新能力的国际认可 |
| 单产品收入占比 | 最大产品 / 总收入 | 产品集中度风险 |

### 风险与质量特异指标

| 指标 | 关注要点 |
|---|---|
| 管线进展 | 临床阶段（I/II/III期/NDA） |
| 临床失败风险 | III期失败率 ~50% |
| 集采风险 | 仿制药价格大幅下降 |
| 医保谈判 | 创新药进入医保后的降价幅度 |
| 专利到期 | 核心产品专利悬崖 |
| CMO/CDMO 产能 | 产能利用率与扩张计划 |

### 股价与估值特异指标

| 指标 | 适用场景 |
|---|---|
| PE | 有稳定盈利的药企 |
| PS | 研发期、亏损期 |
| DCF + rNPV | 管线估值（风险调整净现值） |
| 市值/管线数量 | 管线估值粗算 |
| EV/EBITDA | 成熟药企跨地区比较 |

### 医药公司复盘分阶段参考

| 阶段类型 | 典型战略 | 典型转折事件 |
|---|---|---|
| 仿制药积累期 | 仿制药为主、积累现金流 | 上市、首批仿制药获批 |
| 创新转型期 | 加大研发、布局创新药 | 首个创新药获批、研发费用率跃升 |
| 创新收获期 | 创新药放量、商业化 | 核心产品进入医保、收入爆发 |
| 国际化期 | 海外临床、License-out | 海外授权、FDA获批 |
| 第二曲线期 | 新技术平台（ADC/CGT等） | 新技术平台验证 |

## 五、制造业/工业

### 盈利能力特异指标

| 指标 | 公式 | 关注要点 |
|---|---|---|
| 毛利率 | 分产品线 | 成本控制与定价能力 |
| 单位成本 | 营业成本 / 产量 | 规模效应验证 |
| 产能利用率 | 实际产量 / 设计产能 | >80% 为健康 |
| 在手订单 | 期末未交付订单 | 收入前瞻指标 |
| ROIC | NOPAT / 投入资本 | 再投资效率，重资产行业核心 |

### 资产负债结构特异指标

| 指标 | 关注要点 |
|---|---|
| 固定资产/总资产 | 重资产程度 |
| 资本开支/折旧 | 扩张 vs 维持 |
| 存货周转天数 | 库存管理效率 |
| 应收账款周转天数 | 回款能力，产业链话语权 |
| 在建工程 | 未来产能扩张 |

### 风险与质量特异指标

| 指标 | 关注要点 |
|---|---|
| 产能过剩风险 | 行业产能利用率 |
| 原材料价格 | 成本端波动 |
| 客户集中度 | 前五大客户占比 |
| 技术迭代 | 生产线是否面临淘汰 |
| 环保/安全 | 合规风险与资本开支压力 |

## 六、行业适配使用方法

1. **确定行业类型**：先判断公司属于哪个行业大类
2. **选取特异指标**：从对应行业表中选取 8-15 个核心特异指标
3. **混合通用+特异**：通用指标（ROE/ROA/毛利率等）+ 行业特异指标组成完整指标体系
4. **设定优秀标准**：用行业适配表中的"优秀标准"列做横向对比
5. **选择估值方法**：按行业特性选择主估值方法（银行→PB-ROE；消费品→PE；科技→PS/DCF；医药→rNPV）
6. **确定分阶段逻辑**：参考行业复盘分阶段表，结合公司实际情况调整

如果公司是跨行业经营（如平安=保险+银行+科技），按主要收入来源行业为主框架，辅以其他行业特异指标。
