# 证据与数据规范

## 一、证据分级体系

### 1.1 证据标签定义

| 标签 | 含义 | 适用场景 | 数据处理方式 |
|---|---|---|---|
| `official_fact` | 年报、公告、监管披露的正式数据 | 上市后年报数据、监管报表、公司公告 | 精确到小数点后两位，标注来源年份 |
| `research_inference` | 基于事实的研究推断 | 战略逻辑分析、因果关系判断、趋势归因 | 必须标注推断逻辑和依据的事实 |
| `third_party_data` | 第三方数据源 | Wind/AkShare 行情数据、行业协会统计 | 标注来源名称和获取日期 |
| `estimated` | 因早期数据缺失做的量级估算 | 上市前数据、早期口径不全的指标 | 用 `~` 前缀表示，标注误差范围 |
| `待验证` | 无法确认的说法或数据 | 媒体报道、未经核实的信息 | 原样保留，不做填补，标注待验证原因 |

### 1.2 标注格式

**段落级标注**（用于分析性文字）：

```markdown
**战略逻辑**（`research_inference`）：
管理层判断①对公业务竞争激烈；②零售银行是蓝海...
```

**数据级标注**（用于表格和数据引用）：

```markdown
| ROE | ~15%（`estimated`，基于招股书推算） | 13.44%（`official_fact`，2025年报） |
```

**混合标注**（一段文字中同时包含事实和推断）：

```markdown
2008年招行NIM达到3.0%（`official_fact`），这是加息周期与零售高收益资产的叠加效果（`research_inference`）。
```

### 1.3 什么不能作为事实

以下来源**一律不能**标注为 `official_fact`：

- 券商研报中的预测和估值
- 新闻媒体的解读和评论
- 管理层在业绩会上的前瞻性指引（属于"管理层声称"）
- 社交媒体上的信息
- 未标明出处的行业数据

管理层的指引和声称应标注为：

```markdown
管理层在2025年业绩会上表示"预计NIM将企稳"（`管理层声称`，待后续年报验证）
```

## 二、数据精度分级

### 2.1 四级精度体系

| 精度级别 | 适用时期 | 数据来源 | 误差范围 | 处理方式 |
|---|---|---|---|---|
| **估算级** | 上市前或早期 | 招股书、公开史料、行业回忆 | 10-20% | 用 `~` 前缀，仅做量级参考 |
| **中等** | 上市后 5 年内 | 年报，但部分指标口径与现行不同 | 5-10% | 标注口径差异 |
| **较高** | 上市 5 年后 | 年报 + 第三方数据 | 2-5% | 可做趋势分析 |
| **高** | 近 10 年 | 年报 + 第三方数据，口径统一 | <2% | 可做严格分析和横向对比 |

### 2.2 精度标注方式

在每阶段盈利能力分析的开头，用引用块声明精度：

```markdown
> 2002年上市前数据来自招股说明书及历史公开资料，精度为估算级。
```

```markdown
> 2002-2006年数据来自年报，部分指标（如资本充足率）口径与Basel III后有差异，精度为中等。
```

### 2.3 口径差异处理

当不同时期的指标口径不一致时：

1. **保留原值**：历史数据按当年年报原值记录，不做追溯调整
2. **标注口径**：在表格脚注或正文中说明口径差异
3. **不做拼接**：如果口径差异过大，不要将不同口径的数据放在同一列中做趋势分析

常见口径差异：

| 指标 | 口径变化 | 影响时期 |
|---|---|---|
| CET1 | Basel III 前/后（2013年实施） | 2013 年前数据 |
| 不良贷款 | 五级分类标准变化 | 2003-2005 年前后 |
| 非息收入 | 营改增后口径变化 | 2016 年前后 |
| 金融投资 | 三分类（AC/FVOCI/FVTPL）变化 | 2018 年 IFRS9 实施后 |
| 保险收入 | IFRS17 实施 | 2023 年后 |

## 三、缺失值处理规则

### 3.1 核心原则

**绝不以推测值填补缺失数据。**

### 3.2 缺失值符号

| 符号 | 含义 | 使用场景 |
|---|---|---|
| `—` | 该年份数据未获取或不存在公开披露 | 表格中缺失的数据点 |
| `~值` | 估算值，基于间接信息推算 | 上市前数据、早期估算 |
| `待补充` | 数据应存在但尚未获取 | 标注后续完善方向 |
| `待验证` | 数据存疑，需核实 | 媒体报道、不一致的数据源 |

### 3.3 何时可以用估算值

仅在以下情况下可以使用 `~` 估算值：

1. 上市前数据，且基于招股说明书或可信公开史料
2. 早期口径缺失但可通过相关指标间接推算（如用利息净收入/总资产粗算NIM）
3. 第三方数据与年报数据存在小幅差异，取年报为准

估算值必须标注：
- 估算依据（"基于招股书XX页数据推算"）
- 误差范围（"误差约10-20%"）

### 3.4 数据源冲突处理

当不同来源的数据不一致时：

1. **优先级**：年报 > 监管披露 > 第三方数据库（Wind/AkShare）> 行业报告 > 新闻媒体
2. **处理方式**：取高优先级来源数据，在脚注中标注冲突
3. **例外**：如果年报数据明显有误（如印刷错误），可采用第三方数据并标注原因

## 四、来源优先级体系

### 4.1 来源层级

| 层级 | 来源类型 | 可信度 | 使用方式 |
|---|---|---|---|
| L1 | 公司年报/季报、招股说明书 | 最高 | 直接引用，标注 `official_fact` |
| L1 | 监管机构公告（交易所、金融监管总局等） | 最高 | 直接引用，标注 `official_fact` |
| L2 | 公司公告（非定期报告）、投资者关系页面 | 高 | 直接引用，标注 `official_fact` |
| L2 | 公司业绩会纪要（官方分发） | 高 | 管理层声称标注为 `管理层声称` |
| L3 | 行业协会统计数据 | 较高 | 标注 `third_party_data` |
| L3 | 第三方金融数据库（Wind/AkShare/Bloomberg） | 较高 | 标注 `third_party_data` |
| L4 | 券商研报 | 中 | 仅作参考，不作为事实依据 |
| L5 | 新闻媒体报道 | 低 | 仅作线索，需交叉验证 |
| L6 | 社交媒体、论坛信息 | 极低 | 不使用 |

### 4.2 来源标注格式

在文档 frontmatter 的 `sources` 中列出主要来源：

```yaml
sources:
  - "{{公司}} {{年}}年年报"
  - "Wind/AkShare 历史行情数据"
  - "公开史料：{{资料名称}}"
```

在正文中引用数据时，可在关键数据后用括号标注来源：

```markdown
2025年NIM为1.87%（2025年年报，`official_fact`）
```

## 五、数据采集规范

### 5.1 采集顺序

1. 先获取最新年报（通常为最重要、最完整的数据源）
2. 逐步回溯历年年报，优先获取阶段分界年的年报
3. 对上市前数据，获取招股说明书
4. 对行业数据，获取行业协会或监管机构的统计报告
5. 对股价数据，使用第三方数据库（AkShare/Wind）

### 5.2 采集注意事项

- **财年 vs 自然年**：部分公司财年与自然年不一致（如阿里财年4月-次年3月），必须标注
- **追溯调整**：年报中的历史数据可能经过追溯调整，优先使用当年原值
- **合并口径**：注意合并报表 vs 母公司报表，分析用合并报表
- **单位统一**：全部统一为人民币亿元，汇率按当年年末中间价换算
- **百分比精度**：比率类指标保留两位小数（如 13.44%），绝对值类保留整数（如 1,502 亿元）

### 5.3 数据验证

对关键数据做交叉验证：

1. **内部一致性**：资产=负债+所有者权益；收入-成本-费用-税=净利润
2. **趋势一致性**：ROE 变化趋势应与 ROA × 杠杆倍数一致
3. **横向一致性**：与同行业可比公司对比，如果偏离过大需核实
4. **时间一致性**：相邻年份数据不应出现不合理跳跃（除非有合理解释如并购）

## 六、数据呈现规范

### 6.1 表格格式

- 使用 Markdown 标准表格
- 数值列右对齐（`---:`）
- 文本列左对齐（`---`）
- 百分比不带百分号在表头（表头写"ROE"，单元格写"13.44%"）
- 估算值用 `~` 前缀：`~15%`
- 缺失值用 `—`
- 最后一列通常为"趋势"列，用一句话概括方向

### 6.2 ASCII 图表

用于展示核心指标的长周期走势：

```text
3.0% ──●  2008年峰值
       \
2.5% ──●──●──●  2002-2013年
            \
2.0% ──●──●──●  2014-2022年
                \
1.87% ──────●  2025年
```

规范：
- Y 轴标注数值和单位
- `●` 标注数据点
- `──` 连接同一趋势段
- `\` 表示趋势转折
- 右侧标注年份和简要说明

### 6.3 解读段落

每张表格下方必须配一段解读，包含：
1. 趋势概括（"XX从A%下降到B%，降幅C个百分点"）
2. 驱动力分析（"主要原因是..."）
3. 可逆性判断（"其中结构性变化不可逆，周期性波动有恢复可能"）
4. 证据标注（`research_inference`）
