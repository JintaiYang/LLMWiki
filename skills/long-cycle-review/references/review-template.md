## 模板使用注意事项

1. **阶段数量灵活**：3-7 个阶段均可，按战略转折点而非等间隔划分
2. **七维度可精简**：如某维度在某阶段无重要变化，可合并到相邻段落但不可完全跳过
3. **纵向表年份选取**：5-8 个代表年份，优先选阶段分界年、峰值年、谷底年
4. **ASCII 图表**：核心指标长周期走势用 ASCII 折线图，直观展示趋势
5. **证据标签贯穿全文**：每个关键数据和推断都要标注证据类型
6. **副标题点睛**：文档主标题的副标题应一句话概括公司 N 年的核心故事
