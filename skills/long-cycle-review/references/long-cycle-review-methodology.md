# 长周期复盘核心方法论

## 一、核心理念：战略阶段驱动叙事

### 1.1 为什么不按年份堆砌？

10-30 年的公司历史如果逐年罗列数据，会产出一份数据字典而非研究报告。长周期复盘的价值在于 **识别战略转折点、理解管理层的选择逻辑、评估选择的长期效果**。

### 1.2 分阶段的三条原则

1. **转折点驱动**：阶段分界线应放在战略事件而非整数年份。例：招行 2002 年提出零售转型、2014 年提出轻型银行，这些是分界线。
2. **命名体现战略特色**：阶段名应概括该阶段的核心战略选择，如"零售转型期"而非"第二阶段"。
3. **3-7 个阶段为宜**：少于 3 个则粒度不够，多于 7 个则失去"鸟瞰"价值。

### 1.3 如何识别战略转折点？

以下任一事件通常标志着一个新阶段的开始：

| 事件类型 | 例子 |
|---|---|
| 管理层更替 | 招行 2013 年马蔚华退休→田惠宇接任；茅台 2018 年李保芳上任 |
| 战略发布 | 招行 2002 年"做中国最好的零售银行"；腾讯 2018 年"930变革" |
| 重大并购/剥离 | 联想收购 IBM PC（2005）；吉利收购沃尔沃（2010） |
| 业务模式转型 | 招行 2014 年轻型银行；茅台 2012 年限制三公消费后的渠道转型 |
| 危机事件 | 2008 金融危机；2012 白酒塑化剂；2020 疫情 |
| 政策变革 | 2015 利率市场化；2016 营改增；2023 银行费率改革 |
| 上市/IPO | A股或H股上市通常标志资本补充和新战略阶段的开始 |

## 二、七维度分析法

每个战略阶段从以下七个维度展开分析。这是复盘的核心骨架。

### 维度 1：战略选择与历史背景

**要回答的问题**：
- 管理层当时面临什么局面（行业格局、竞争压力、资源约束）？
- 做了什么战略选择？
- 为什么做这个选择（而非其他选择）？
- 这个选择的长期效果如何？

**产出格式**：
- 时间线图（ASCII 或文字流程图，标注关键事件和转折点）
- 战略逻辑段落（标注 `research_inference`，解释"为什么"）
- 历史背景段落（提供行业和政策上下文）

**写作要点**：
- 必须回到当时的信息环境判断，不能用后见之明
- 要区分"管理层的主动选择"和"被环境逼迫的被动调整"
- 如果有备选方案被放弃，简要说明为什么放弃

### 维度 2：主营业务变化

**要回答的问题**：
- 收入结构发生了什么变化？（分产品线、分地区、分客户类型）
- 核心产品/服务有什么演进？
- 客户群体是否发生了迁移？
- 商业模式是否有本质变化？

**通用指标**：

| 指标 | 说明 | 数据来源 |
|---|---|---|
| 收入构成 | 各业务线收入占比 | 年报附注分部数据 |
| 产品矩阵 | 核心产品演进 | 年报、公司公告 |
| 客户结构 | 客户类型/集中度变化 | 年报、招股书 |
| 渠道变化 | 销售渠道演进 | 年报、行业报告 |

**行业特异指标**：参见 `industry-adapters.md`

### 维度 3：盈利能力

**要回答的问题**：
- 赚钱效率如何变化？ROE/ROA 趋势如何？
- 盈利的驱动力是什么？量价利拆解后哪个因素主导？
- 盈利质量如何？利润是否依赖一次性收益或拨备释放？
- 与同业相比，盈利能力是领先还是落后？

**通用指标**：

| 指标 | 公式 | 关注点 |
|---|---|---|
| ROE | 归母净利润 / 期初期末平均净资产 | 长期趋势 > 绝对值 |
| ROA | 归母净利润 / 期初期末平均总资产 | 资产效率 |
| 毛利率 | (营收 - 营业成本) / 营收 | 竞争力与定价权 |
| 净利率 | 归母净利润 / 营收 | 盈利终端效率 |
| 费用率 | 销售/管理/研发费用 / 营收 | 经营杠杆 |
| 收入增速 | 同比 | 成长性 |
| 利润增速 | 同比 | 成长性与盈利质量 |

**银行特异指标**：NIM、净利差、成本收入比、非息收入占比、PPOP 增速

**写作要点**：
- 必须做"量价利拆解"：利润增长 = 规模增长 × 单位收益率 × 费率变化 × 风险成本变化
- ROE 变化要做归因分析（杜邦拆解），标注各因素的贡献度
- 如果 ROE 短期飙升，要判断是"真实改善"还是"拨备释放/一次性收益"

### 维度 4：资产负债结构

**要回答的问题**：
- 资产结构是否在优化或恶化？
- 杠杆水平是否可持续？
- 资产周转效率如何变化？
- 是否有表外风险或隐性负债？

**通用指标**：

| 指标 | 说明 |
|---|---|
| 总资产/总负债 | 规模变化 |
| 资产周转率 | 营收 / 平均总资产 |
| 资产负债率 | 杠杆水平 |
| 存货周转率 | 库存管理效率（制造业/消费品） |
| 应收账款周转率 | 回款效率 |
| 商誉/净资产 | 并购溢价风险 |

**银行特异指标**：存贷比、活期存款占比、零售贷款占比、同业负债占比、金融投资三分类

**消费品特异指标**：存货周转天数、预收款（合同负债）趋势、经销商数量变化

### 维度 5：风险与质量

**要回答的问题**：
- 公司面临的最大风险是什么？是否在好转或恶化？
- 是否有隐藏的风险（表外、关联交易、期限错配）？
- 风险前瞻指标发出了什么信号？
- 行业周期处于什么位置？

**通用风险框架**：

| 风险类型 | 通用指标 | 关注点 |
|---|---|---|
| 经营风险 | 毛利率变化、客户集中度 | 竞争力是否在退化 |
| 财务风险 | 资产负债率、流动比率、利息保障倍数 | 偿债能力 |
| 周期风险 | 收入增速 vs 行业增速 | 是否在周期顶部/底部 |
| 治理风险 | 管理层稳定性、关联交易 | 制度化程度 |
| 合规风险 | 监管处罚、诉讼 | 合规文化 |

**银行特异指标**：不良率、关注类比例、逾期 90 天以上比例、拨备覆盖率、新生成不良率、信用成本率

**消费品特异指标**：渠道库存（预收款/合同负债）、品牌力（提价能力）、食品安全事件

### 维度 6：资本配置与分红

**要回答的问题**：
- 利润去哪了？再投资、分红、回购的比例如何？
- 再投资的回报率如何？是否在创造价值？
- 分红是否可持续？分红率趋势如何？
- 是否有增发/配股等稀释股东权益的行为？

**通用指标**：

| 指标 | 公式 | 关注点 |
|---|---|---|
| 分红率 | 现金分红 / 归母净利润 | 趋势比绝对值重要 |
| 再投资率 | 1 - 分红率 | 留存利润比例 |
| 资本开支/折旧 | Capex / D&A | 扩张 vs 维持 |
| ROIC | NOPAT / 投入资本 | 再投资效率 |
| 增发稀释 | 增发股数 / 总股本 | 股东权益稀释 |

**银行特异指标**：CET1、资本充足率、RWA 增速/总资产增速、内生增长率

**写作要点**：
- 银行要看"内生增长是否可行"——CET1 能否仅靠留存利润支撑 RWA 增长
- 消费品要看"品牌投入是否维持"——广告费用率趋势
- 科技公司要看"研发投入是否有效"——研发费用率 vs 研发产出（专利/产品）

### 维度 7：股价表现

**要回答的问题**：
- 股价是否反映了基本面？
- 估值如何变化？PE/PB 区间如何波动？
- 股价涨幅与利润增幅是否匹配？如果不匹配，原因是什么？
- 历史估值高点/低点对应什么基本面环境？

**通用指标**：

| 指标 | 说明 |
|---|---|
| 后复权股价 | 消除分红和拆股影响 |
| 市值 | 绝对规模变化 |
| PE (TTM) | 估值倍数区间 |
| PB | 估值倍数（适用于重资产行业） |
| PS | 估值倍数（适用于高成长/亏损公司） |
| 股息率 | 现金回报率 |
| 年化总回报 | 含分红再投资 |

**写作要点**：
- 股价用后复权数据，消除分红和拆股影响
- 要做"股价涨幅 vs 利润增幅"的背离分析
- 估值高点/低点要标注对应的基本面环境和市场情绪
- 三种估值方法的适用性：PE（稳定盈利）、PB（重资产/金融）、PS（高成长/亏损）、DCF（自由现金流稳定）

## 三、护城河评估框架

### 3.1 护城河类型

| 类型 | 定义 | 识别指标 | 典型案例 |
|---|---|---|---|
| **无形资产** | 品牌、专利、牌照 | 品牌溢价率、专利数量、牌照价值 | 茅台品牌、招行零售牌照 |
| **转换成本** | 客户更换供应商的代价 | 流失率、续约率 | 银行活期存款、SaaS 订阅 |
| **网络效应** | 用户增加提升价值 | 用户数增长率 vs 价值提升 | 微信社交网络 |
| **成本优势** | 结构性低成本 | 单位成本 vs 同业 | 规模效应、资源禀赋 |
| **规模优势** | 规模带来效率或壁垒 | 市场份额、规模经济曲线 | 宁德时代产能规模 |

### 3.2 护城河穿越周期的评估

对每个护城河要素，评估以下四个维度：

| 维度 | 评估问题 | 状态标注 |
|---|---|---|
| **形成时期** | 这个优势是什么时候建立的？ | 年代/阶段 |
| **最强表现** | 历史上最突出的量化证据 | 指标 + 数值 |
| **当前状态** | 现在还在吗？强度如何？ | 强 / 中 / 弱 / 消失 |
| **趋势判断** | 未来会增强还是退化？ | 增强中 / 稳定 / 退化中 |

### 3.3 护城河退化的信号

- **定价权减弱**：提价后销量下滑、毛利率下降
- **客户流失加速**：核心客户占比下降、续约率降低
- **同业追赶**：竞争对手复制了同样的能力
- **技术替代**：新技术使原有优势不再重要
- **监管变化**：政策打破了原有壁垒（如牌照开放、费率管制）

## 四、全周期纵向对照表设计

### 4.1 年份选取原则

- 选取 5-8 个代表年份，而非逐年罗列
- 优先选取：阶段分界年、峰值年、谷底年、最新年报年
- 例：2002（上市）、2008（危机峰值）、2013（转折）、2018（阶段末）、2022（最近峰值）、2025（最新）

### 4.2 指标分类

每张纵向对照表聚焦一个维度，不要混合太多指标：

| 表名 | 指标范围 |
|---|---|
| 盈利能力变迁 | ROE、ROA、毛利率/净利率、收入增速、利润增速 |
| 资产/经营结构变迁 | 资产周转率、杠杆率、核心结构指标 |
| 风险质量变迁 | 风险前瞻指标、拨备/减值、周期定位 |
| 资本配置变迁 | 分红率、再投资率、资本补充 |
| 估值变迁 | PE、PB、市值、股息率 |

### 4.3 表格格式规范

```markdown
| 指标 | 2002 | 2008 | 2013 | 2018 | 2022 | 2025 | 30年趋势 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| ROE | ~15% | ~26% | ~18% | ~16% | ~17% | 13.44% | 高位下行 |
```

- 估算值用 `~` 前缀
- 缺失值用 `—` 表示，**绝不以推测值填补**
- 最后一列"趋势"用一句话概括方向
- 表下必须配一段解读段落

## 五、复盘总结的四个产出

### 5.1 护城河评估

按 3.2 框架逐一评估，最终给出一个总结判断：
- 护城河 **仍在 / 退化中 / 已消失**
- 如果在退化，退化的原因是"同业追赶"还是"技术替代"还是"监管变化"

### 5.2 核心战略决策排序

选出历史最关键的 3-5 个战略决策，按重要性排序：

| 排序 | 决策 | 时间 | 效果 | 可验证性 |
|---|---|---|---|---|
| 1 | 最重要的决策 | 年份 | 量化效果 | 高/中/低 |

可验证性标准：
- **高**：有直接的量化指标可以验证（如收入占比、客户增长、ROE 变化）
- **中**：有间接证据但因果链不完全确定
- **低**：主要靠推断，缺乏直接量化证据

### 5.3 最大教训

| 教训 | 时间 | 表现 | 启示 |
|---|---|---|---|

教训应聚焦"被低估的风险"和"被高估的能力"，避免泛泛而谈。

### 5.4 估值启示

核心公式：**长期回报 = 利润增长 + 估值变化 + 分红**

- 如果利润增长 N 倍但股价涨幅远小于 N 倍，说明估值压缩吃掉了利润增长
- 分析估值高点/低点对应的基本面环境和市场情绪
- 判断当前估值在历史分位中的位置

## 六、前瞻跟踪框架

### 6.1 跟踪指标灯号系统

选取未来 3 年最关键的 5-8 个指标，设定三色灯号：

| 优先级 | 指标 | 绿灯 | 黄灯 | 红灯 |
|---|---|---|---|---|
| P0 | 最关键指标 | 量化标准 | 量化标准 | 量化标准 |

优先级定义：
- **P0**：直接决定投资论点是否成立的指标
- **P1**：重要但非决定性的指标
- **P2**：辅助判断的指标

### 6.2 三情景估值推演

| 情景 | 核心假设 | ROE | 合理估值倍数 | 对应股价 | 概率 |
|---|---|---: | ---: | ---: | ---: |
| 乐观 | 量化假设 | XX% | X.X倍 | XX元 | 25% |
| 中性 | 量化假设 | XX% | X.X倍 | XX元 | 50% |
| 悲观 | 量化假设 | XX% | X.X倍 | XX元 | 25% |

概率判断原则：
- 中性情景概率通常 40-60%
- 乐观和悲观情景概率通常各 15-30%
- 必须标注每个情景的"触发条件"——什么情况下会从中性切换到乐观或悲观
