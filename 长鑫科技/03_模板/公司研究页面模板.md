# 公司研究页面模板

> 本模板用于知识库（`05_知识库/`）下的所有研究页面。维护规则详见 [[06_维护契约]]。

## 0. 模板使用说明

- **不得修改 frontmatter 字段集合**；只能在 `tags` / `related` / `next_action` / `source_url` 等可扩展字段内填充。
- 任何具体公司事实必须先落地到 `02_原始资料/` 并登记 `Sxx` 编号，再回填本页。
- 字段值为空的请删除对应行或保留空值；禁止填入未核验的数字。
- `evidence_level` 与正文证据等级必须一致；公司财务/经营数字默认 `low`，必须有 `Sxx` 才能升级。
- 引用 `[[双链]]` 仅使用文件名（不含路径）。

## 1. frontmatter 字段定义

| 字段 | 取值 | 必填 | 说明 |
|------|------|------|------|
| `type` | 见 `template_for` | 是 | 决定页面类型，对应维护契约 Section 2 |
| `status` | `seed` / `growing` / `mature` | 是 | 种子/成长期/成熟期 |
| `company` | `长鑫科技/长鑫存储（CXMT）` | 是 | 全部页面统一公司标识 |
| `stock_code` | `待确认` | 是 | 监管/官方文件核验前一律 `待确认` |
| `market` | `待确认` | 是 | A 股 / 港股 / 美股 / 未上市 — 核验前一律 `待确认` |
| `tags` | 数组 | 是 | 至少包含研究主题标签 |
| `source_url` | URL 字符串 | 否 | 当前页面主要来源（如有一级来源） |
| `evidence_level` | `low` / `medium` / `high` | 是 | 与正文证据等级一致 |
| `updated` | `YYYY-MM-DD` | 是 | 与正文最后一次修订日期一致 |
| `related` | 数组（页面文件名） | 是 | 至少 2 条相关双链 |
| `next_action` | 字符串 | 是 | 下一具体动作描述 |

## 3. 通用写作规范

- 中文为主，技术术语保留英文（DDR5、LPDDR5、HBM、wafer starts、CapEx、bit shipment 等）。
- 表格优先于长段落；每个数字字段必须可追溯到 `Sxx`。
- 不引用 KMS 片段作为事实；只能作为 `待验证` 线索。
- 文末必须存在 `关联页面` / `待验证` / `下一步` 三个章节。
- 同一事实同时引用多个来源时，逐条标注；不得合并为"多源支持"。
- 任何时间敏感字段（价格、产能、节点、出口管制清单）必须标注 `as-of` 日期。

## 4. 模板引用约定

- 复制本文件后，将 `template_for` 改为具体类型，删除 `template_for` 字段。
- `updated` 改为实际修订日期。
- 在 `tags` 中至少包含 1 个研究主题标签（如 `DRAM`、`资本开支`、`周期`）。
- 模板本身的字段集合、章节结构、写作规范不允许就地修改；如需修改模板，须同步更新 [[06_维护契约]] 与本模板，并在 09_操作日志 顶部插入新条目。
