# 资料节点 Sxx：（来源标题）

> 维护规则详见 [[06_维护契约]]。本模板用于 `02_原始资料/` 下所有资料节点文件。

## 1. frontmatter 字段定义

| 字段 | 取值 | 必填 | 说明 |
|------|------|------|------|
| `source_id` | `Sxx`（两位数字） | 是 | 与 `02_原始资料/原始资料索引.md` 索引对齐 |
| `title` | 字符串 | 是 | 来源原文标题或一句概括 |
| `org` | 字符串 | 是 | 发布机构/原始来源 |
| `category` | 见上文 | 是 | 与 `credibility` 保持一致 |
| `date_attempted` | `YYYY-MM-DD` | 是 | 本任务实际访问日期 |
| `date_published` | `YYYY-MM-DD` 或 `unknown` | 是 | 原文发布日期；不可知时填 `unknown` 并在缺口表登记 |
| `url_or_path` | 字符串 | 是 | 可访问 URL 或内部路径；不可访问填 `无法访问` |
| `credibility` | 见上文 | 是 | 评估后的可信度 |
| `status` | 见上文 | 是 | 访问/下载状态 |
| `tags` | 数组 | 是 | 至少包含 `来源编号` 与 `长鑫科技` |

## 2. 实际访问范围

- 列出本研究节点实际访问到的内容（页面、字段、文件、PDF 页码等）。
- 区分"已访问"与"仅获得搜索片段"两种状态。
- 任何"全文未访问""仅预览""片段摘要"必须在正文显式标注。
- 引用形式以 Markdown 链接为主；若原始资料为 PDF/Excel，请按 `02_原始资料/<子类>/<文件名>.pdf` 放置，并在本站使用普通 Markdown 链接而非 `[[WikiLink]]`。

## 3. 可支持的论断

> 用 1–3 条短句列出本节点**能**支持的事实类型。每条须明确：
> - 事实类型（如：CXMT 在 A 股挂牌的官方公告）
> - 证据等级（如：监管 / 官方 / 行业机构）
> - 报告期 / 引用字段

## 4. 不可支持的论断

> 显式列出本节点**不**能支持的典型陈述（默认值越严越好），防止下游误用。常见需要列出的禁止陈述：

- CXMT 的具体数字（营收、净利、毛利、产能、良率、CapEx、研发、客户结构等）
- CXMT 的证券代码、上市状态、上市日期
- CXMT 的产品/工艺/制程节点当前水平
- CXMT 的市场份额、目标价
- 与具体可比公司（SK 海力士、美光、三星）的对标
- 任何"业内估计""等于 XX""与 YYY 类似"等推断

## 5. 已知/未知的核验缺口

| 缺口 | 当前状态 | 何时可关闭 |
|------|----------|------------|
| 原文 URL 是否稳定可访问 | 已访问 / 未访问 / 仅片段 | 重新访问并保留截图 |
| 原文发布机构与作者 | 已识别 / 未识别 | 抓取页面 meta 或 PDF 封面 |
| 原始发布日期 | 已确认 / 未知 | 抓取页面时间戳或 PDF 元数据 |
| 内容是否仍在线 | 已知 / 不确定 | 用低权限或匿名窗口复测 |
| 与 CXMT 直接相关的关键事实 | 已核验 / 仅片段 | 用监管/官方原文交叉验证 |

## 6. 在研究页面中的引用规范

- 引用本节点时必须写出 `资料节点 Sxx`，并标注证据等级标签。
- 任何引用了本节点的研究页面须在 `related` 或正文处链回本节点。
- 禁止把 Sxx 节点中的"行业线索""碎片信息"作为公司事实陈述。
- 推荐引用示例：

  > 上交所披露查询页曾以 `COMPANY_CODE=688981` 进行检索，该代码归属尚未确认，本研究目前不将任何 `688981` 名下的披露归属到 CXMT（资料节点 S01）。

## 8. 字段更新与覆盖规则

- 同一 `source_id` 节点被新访问覆盖时，必须在 `09_操作日志.md` 顶部插入新条目，旧版正文不得改写，仅可在末尾追加 `## 后续访问记录` 章节。
- 节点标题与 frontmatter 字段集合不得修改；新增字段须在 `02_原始资料/原始资料索引.md` 的索引表列名中同步登记。
