# 护城河类型

公司页 frontmatter 里的 `moat` 是分类标签，不是测量值。一家公司可以同时有两种，页面只标这次入选时最主要的一种。

| 类型 | 含义 | 财务报表上通常看见什么 | 本库例子 |
| --- | --- | --- | --- |
| 定价权 | 提价后需求掉得有限 | 毛利率高且不降 | 贵州茅台、山西汾酒、海天味业、公牛集团 |
| 特许经营 | 牌照、路线或资源别人拿不到 | 毛利率高，增长慢，资本开支相对稳定 | 长江电力、华能水电、粤高速A |
| 转换成本 | 客户换掉你要改系统、改流程、改耗材 | 毛利率稳定，收入不一定高速增长 | 迈瑞医疗、金山办公、恒生电子、国电南瑞 |
| 规模与份额 | 成本或供货能力使后来者难以达到同样份额 | 毛利率可以不高，但ROE和现金流稳定 | 美的集团、福耀玻璃、宁德时代、三花智控 |
| 网络或平台 | 点位、网点、市场本身是资产 | 利润随使用量波动 | 分众传媒、爱尔眼科、小商品城 |
| 负债端特许 | 只用于银行。低成本、稳定的负债是原料 | 不看毛利率，看ROE是否稳，其余去银行库 | 招商银行、宁波银行 |
| 成本优势 | 同一商品里成本更低 | 毛利率随价格涨跌，周期里仍比同行厚 | 新和成 |
| 单品种或窄品类 | 财务极好，但复购或管线还没证明能重复 | 毛利率和ROE都很高，利润体量可能仍小 | 艾力斯、羚锐制药、惠泰医疗 |

## 不能单独当护城河的数字

- 一年的高ROE。可能是周期顶点，马克斯的问题要先问。
- 一年的高毛利率。林园看的是变化方向。
- 利润规模。林园要求赚钱总量不能低，但规模大的代工仍然可能没有定价权。
- 银行的高ROE。要回到存款成本和不良是否可信，不能用工商企业的毛利率表。
