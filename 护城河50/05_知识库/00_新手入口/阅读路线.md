# 阅读路线

## 1. 先看共同标准

读 [[05_知识库/01_选股逻辑/大师选股逻辑]]。这一页只保留不考虑价格时的标准：生意能不能讲清，利润是不是现金，护城河在变宽还是变窄。书里的原话和公式在 [[05_知识库/01_选股逻辑/书中的财务指标]]。

## 2. 再看这次怎么筛

读 [[05_知识库/01_选股逻辑/本次筛选规则]]。机械条件会把周期顶和单品爆发也选进来，所以还有一轮手工删除。三档的含义在这一页。

## 3. 用名册进入公司

[[05_知识库/03_公司库/护城河50名册]] 按档位列出 50 家。公司页里的财务表可以横比，判断段要单独读。银行页不要看毛利率。

## 4. 看没进来的，以及和行业库的接口

[[05_知识库/14_风险/未入选与证伪]] 解释五粮液、片仔癀、万华、比亚迪、光模块和同花顺为什么不在名单里。

白酒三家的渠道细节去白酒库：茅台、汾酒、泸州老窖。两家银行的监管指标去银行库：招商银行、宁波银行。链接写在对应公司页。
