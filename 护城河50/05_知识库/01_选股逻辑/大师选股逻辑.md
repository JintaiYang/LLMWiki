# 大师选股逻辑

本页只保留不考虑估值时的标准。书里的原话、公式和前后变化写在 [[05_知识库/01_选股逻辑/书中的财务指标]]。市盈率、市净率、魔法公式里的盈利收益率、老唐的五折买点都在那一页，但不进入本库的筛选。

共同问题有五个：

1. 这门生意能不能用一句话说清它靠什么赚钱。
2. 利润是不是现金，而不是应收、资产处置或会计政策。
3. 护城河是在变厚，还是毛利率、份额、客户粘性正在掉。
4. 三五年后行业地位大概率还在不在。
5. 高回报是不是只靠加杠杆堆出来。银行的杠杆是原料，要换一套指标。

## 每人留下的非估值标准

| 人 | 主要文本 | 不看价格时看什么 |
| --- | --- | --- |
| 格雷厄姆 | 《聪明的投资者》第14章 | 过去是否稳：工业企业流动比率、长期债务相对营运资本、10年有利润、长期分红。金融企业不适用流动比率 |
| 巴菲特 | 伯克希尔股东信，尤其1986、1989年 | 已证明的盈利，低杠杆下的股权回报，所有者盈余。所有者盈余要减去维持竞争地位所需的资本开支 |
| 芒格 | 《穷查理宝典》；巴菲特1989年信记录了他推动的转向 | 定价权，有形资本回报，赚到的钱能不能拿走。没有固定ROE截止线 |
| 费雪 | 《怎样选择成长股》 | 利润率是否高于同行并在改善；增长会不会不断增发稀释股东。其余靠调查销售、研发和管理层 |
| 彼得·林奇 | 《彼得·林奇的成功投资》 | 先分类。长期持有要稳定或上升的税前利润率；存货增速超过销售额是危险信号。周期股在盈利顶点往往看起来“财务很好” |
| 格林布拉特 | 《股市稳赚》 | 用 EBIT 看经营利润，用净营运资本加净固定资产看这门生意占了多少有形资本。金融股被他排除在公式之外 |
| 霍华德·马克斯 | 《投资最重要的事》《周期》 | 不提供选股比率。高ROE要先问是不是处在周期有利的一端 |
| 段永平 | 雪球问答，后编为《段永平投资问答录》 | 对的生意、对的人。看负债、净现金、现金流是否长期低于利润、开支是否合理、真实利润、扣除商誉后的净资产。ROE只用来排除 |
| 李录 | 《文明、现代化、价值投资与中国》；2006年哥伦比亚大学课 | 能力圈、护城河会不会被侵蚀、管理层在护城河变化时如何配置资本。用市盈率之前先问盈利是不是周期顶点或一次性收益 |
| 林园 | 《林园炒股秘籍》；2007年北大演讲 | 毛利率水平与变化。2007年说18%以下不考虑，且必须稳定或上升。约2018年更强调不要大幅下降。利润总额不能低。银行的账他明确说算不清 |
| 唐朝 | 《手把手教你读财报》《价值投资实战手册》《手把手教你读财报2》 | 三大前提：利润为真、可持续、维持当前盈利不需要大量资本投入。普通企业看经营现金流对净利润、销售收现、现金对有息负债。银行另看存款成本、净息差来源、不良是否可信、拨备和资本 |

## 本库怎么用这些标准

机械筛选吸收的是能从三年业绩报表里看到的部分：连续盈利、ROE大致在15%附近、毛利率不下滑、利润规模不是很小。

手工筛选吸收的是报表不够用的部分：这是不是周期顶，是不是单品或景气，有没有定价权，银行能不能换口径，资本开支是不是吃掉了利润。

管理层、商誉、合同负债、批价、不良率，本快照没有。这些留在公司页的待验证，或留给白酒库和银行库。
