# 未入选与证伪

高分不等于入选。下面这些公司在 2025 年业绩报表上的 ROE 或毛利率，常常高于名册里的一部分公司。不入选是因为三年数据还不能把“好生意”和“好年份”分开，或者护城河已经出现方向性变坏。

数字除特别说明外，来自 2026-10-13 的东方财富业绩报表，单位为亿元或百分比。

## 旧龙头，这次没有留下

| 公司 | 快照里看见的变化 | 处理 |
| --- | --- | --- |
| 五粮液 | 2025年净利润89.5，2023年302.1；ROE降到6.9。毛利率仍约77.5 | 不入选。白酒库说明营收下降里有收入确认的会计差错，同时也把这看成渠道动销变弱。见 [五粮液](../../../白酒/05_知识库/03_品牌库/五粮液.md)。会计差错没有把ROE修回到名册门槛之上 |
| 洋河股份 | 净利润从100.2降到22.1，ROE 4.6，毛利率仍高于70 | 不入选。高毛利率还在，盈利能力已经不在 |
| 片仔癀 | 毛利率从46.8降到36.4，降幅超过8个百分点；2025年每股经营现金流相对每股收益很弱 | 不入选。林园标准里，毛利率下降是直接的负面 |
| 万华化学 | 毛利率从16.8降到13.6，ROE降到12.4 | 不入选。MDI成本优势仍可能是真的，但本轮毛利率不支持“最好的生意” |
| 比亚迪 | 毛利率约18，ROE从26降到15，净利润仍有326 | 不入选。规模最大的车企之一，价格战下没有定价权 |

## 分数很高，但更像景气或单品

机械筛选的前排里还有锦波生物、特宝生物、兴齐眼药、天孚通信、中际旭创、同花顺。

- 锦波生物、特宝生物、兴齐眼药：毛利率和ROE极高，利润体量小或增长极陡。只留了艾力斯一家作为“已经盈利的创新药”代表，其余先观察产品能否重复。
- 中际旭创、天孚通信：2025年ROE很高，光模块需求是本轮景气。三年不够用来确认份额护城河。
- 同花顺：2025年ROE约38.5，毛利率约91.5。证券软件的使用量跟着成交量，牛市利润不计入生意质量。

## 规模大，但没有定价权

立讯精密毛利率约12，工业富联约7。两者ROE都不差。费雪可能会研究它们的客户和成本，林园的毛利率标准会把它们排除。本库这次站在“要有定价权或明确转换成本”一侧，所以不收。

## 周期资源

煤炭、钢铁、工业金属、养殖、油气、航运、光伏设备、房地产，即使某一年ROE很高，也按周期处理。紫金矿业、中国神华、阳光电源、牧原股份属于这一类。长江电力和华能水电留在名册里，是因为水电特许经营，不是因为它们属于电力设备景气。

## 金融只留两家

四大行、保险和其他城商行没有自动进入。原因不是它们没有特许经营，而是本快照无法区分存款成本和信用成本。招商银行、宁波银行留下，是为了接到已经写好的银行库，不是因为这两家ROE最高。成都银行2025年ROE约15.4，高于招商银行，仍未入选：区域集中度要在银行库里单独证明。

## 什么情况把名册里的公司移出

满足一条就写入本页，并考虑归档：

- 非金融公司的销售毛利率相对三年前下降超过约8个百分点，而且找不出产品结构的暂时原因。
- 净利润转负，或经营现金流连续多年远小于净利润。银行不使用后一条。
- 入选时写明的那条护城河被证伪：份额丢失、制裁切断主市场、核心品种被替代、特许经营合同不再成立。
- 发现利润主要来自会计政策、关联方或并表范围变化。

移出不需要股价下跌。股价上涨也不能单独升档。
