# 业绩快照口径说明

本目录的 CSV 是只读快照。发现错误时另写纠错说明，不改原文件。

## 生成方式

1. AkShare 1.16.99，`stock_yjbb_em(date=...)`。
2. 三个报告期：20231231、20241231、20251231。
3. 提取日：2026-10-13。
4. 只保留代码以 600、601、603、605、688、689、000、001、002、003、300、301、83、87、43、92 开头，且行业字段非空、简称不含 ST 或退的记录。
5. 三年按代码内连接。
6. 护城河 50 的子集由 `scripts/build_company_pages.py` 写出。

## 字段

| CSV 列 | 来源字段 | 单位 |
| --- | --- | --- |
| rev_*_yi | 营业总收入 | 亿元 |
| np_*_yi | 净利润 | 亿元 |
| roe_* | 净资产收益率 | % |
| gm_* | 销售毛利率 | % |

营业总收入不是每家年报的营业收入。银行的销售毛利率为空，CSV 里写成空值，页面写成“不适用”。
