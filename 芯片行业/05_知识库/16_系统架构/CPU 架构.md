# CPU 架构

## 架构类型

| 架构 | 授权模式 | 主要厂商 |
|---|---|---|
| x86 | 封闭授权 | Intel/AMD/海光 IP 授权/威盛 |
| ARM | 指令集/架构授权 | 高通/Ampere/飞腾/Kunpeng |
| RISC-V | 开源 | 阿里/平头哥/中科院 |

## 国产路径

- x86 路线：[[海光信息]]（IP 授权）
- ARM 路线：飞腾/Kunpeng（架构授权或 IP 授权）
- RISC-V 路线：平头哥等自研

- AI CPU/DCU 需求强劲
