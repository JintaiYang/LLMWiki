# 中国半导体产业链

## 总体结构

中国半导体产业按价值链分：

1. **上游支撑**：[[EDA 工具受限]] / [[半导体材料受限]] / [[光刻机受限]]
2. **中游制造**：
   - 设计：[[Fabless 模式]] 为主，数字/模拟/射频等子领域
   - 制造：[[Foundry 模式]] + [[IDM 模式]]
   - 封测：[[长电科技]] / [[通富微电]] / 华天科技
3. **下游需求**：手机/PC/AI 服务器/汽车/IoT/工控等

## 关键环节分布

| 环节 | 代表公司 | 国产化评估 |
|---|---|---|
| EDA | 华大九天（部分点工具） | 低 |
| 设备 | [[北方华创]] / [[中微公司]] | 中低（成熟制程较强） |
| 材料 | 安集科技/鼎龙股份等 | 中低 |
| 设计 | 海思/[[海光信息]]/[[寒武纪]] | 中高（某些子领域） |
| 制造 | [[中芯国际]] / [[华虹半导体]] | 中高（成熟制程） |
| 封测 | [[长电科技]] | 较高 |

## 主要成长动力

- 国产替代：A/B 级趋势来自政策与下游需求
- AI/先进封装：结构性增量
- 新能源汽车：功率半导体需求
