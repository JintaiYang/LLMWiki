# 北方华创

## 公司概览

- 全称：北方华创科技集团股份有限公司（002371.SZ）
- 总部：北京
- 上市地：深圳证券交易所
- 核心业务：[[设备与服务模式]] 下的多品类设备平台

## 业务分类

| 业务 | 代表产品 |
|---|---|
| PECVD / ALD | [[薄膜沉积设备]] |

| 清洗 | 湿法清洗设备 |
| PVD | PVD 设备 |
| 热处理 / 氧化炉 | 扩散/退火设备 |

## 已确认事实

- 国内少数同时布局 PECVD/刻蚀/清洗的公司（A 级：官网/年报）
- 核心团队有海外产业背景（B 级）
- 客户覆盖国内主要 Foundry

## 研究推断

- 平台化有助于摊薄研发费用，享有估值溢价
- 国产替代的最大受益者之一

## 投资判断

- 成立条件：客户扩产 + 国产化采购比例提升
- 风险：新技术验证进度不如预期；单一品类份额天花板
