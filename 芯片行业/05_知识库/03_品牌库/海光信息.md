# 海光信息

## 公司概览

- 全称：海光信息技术股份有限公司（688041.SH / 待验证港股）
- 总部：北京/天津等地
- 上市地：上海证券交易所科创板
- 核心产品：[[CPU 架构]] 上的服务器 CPU + DCU 协处理器

## 已确认事实

- 基于 AMD x86 授权合资路线获得 CPU 设计能力（A 级：公告/招股书）
- DCU 为自研 GPGPU 产品线（待验证具体架构）
- 主要下游：国产服务器/超算/数据中心

## 研究推断

- 海光 CPU/Wayne 服务器在国产化采购中占有重要地位
- 国产 CPU/DCU 的主线受益者

## 投资判断

- 成立条件：国产化采购放量 + 海光自研迭代加速
- 风险：技术迭代依赖度；海外授权方稳定性

## 待验证事项

- 海光 DCU 出货量与下游客户使用反馈
- 授权续期风险（合资模式解读）
